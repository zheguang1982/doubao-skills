# Doubao Skills（豆包自建技能集）

本仓库收录了在豆包（Doubao）中自建的教学类技能（Skills），全部面向中小学语文教学场景，可供复用、分享与改进。

## 技能清单

| 技能 | 说明 |
|------|------|
| fu-laoshi-chinese-lesson-prep | 付老师·语文备课一条龙：输入教材课题与班级学情，一键产出九大模块完整备课物料包（含可编辑 PPT 课件与排版规范的 Word 物料包） |
| shuoke-expression | 10分钟高分说课表达：把生硬教案话术转化为有逻辑、有画面、重学情、重学生成长的高分说课语言 |
| role-embedded-scenario | 角色内嵌式情境创设专家：将学习任务转化为故事/主题内部角色的职责，自动生成高参与度教学情境 |
| yihunci-bianxi-generator | 近义易混词辨析图文+短视频自动生成：输入易混近义词，产出辨析文案、插画绘图 Prompt 与 10 秒视频分镜脚本 |
| 卡通合影照 | 一键生成“真人与Q版卡通同框”的秋日国风创意合影照（风格基准样例图：https://aka.doubaocdn.com/s/TbwtzjgBLU ） |

## 安装方法

将对应技能目录复制到 AI 助手（豆包等）的 skills 目录下，即可加载使用。每个技能目录内均含 `SKILL.md` 说明文件。
