# Doubao Skills（豆包自建技能集）

本仓库收录了在豆包（Doubao）中自建的教学类技能（Skills），全部面向中小学语文教学场景，可供复用、分享与改进。

## 技能清单

| 技能 | 说明 |
|------|------|
| 语文备课一条龙 | 付老师·语文备课一条龙：输入教材课题与班级学情，一键产出九大模块完整备课物料包（含可编辑 PPT 课件与排版规范的 Word 物料包） |
| 高分说课表达 | 10分钟高分说课表达：把生硬教案话术转化为有逻辑、有画面、重学情、重学生成长的高分说课语言 |
| 角色内嵌式情境创设 | 角色内嵌式情境创设专家：将学习任务转化为故事/主题内部角色的职责，自动生成高参与度教学情境 |
| 近义易混词辨析 | 近义易混词辨析图文+短视频自动生成：输入易混近义词，产出辨析文案、插画绘图 Prompt 与 10 秒视频分镜脚本 |
| 智能体融合课优化 | 智能体融合课教学设计评审与优化：按 8 大维度诊断“智能体+学科”融合课教学设计，并重写为可直接参赛/上课的完整版 |
| 智慧中小学教材下载 | 国家中小学智慧教育平台电子教材下载：免登录批量下载智慧中小学平台的电子课本 PDF，支持按学段/学科/版别/年级/册次筛选 |
| 卡通合影照 | 一键生成“真人与Q版卡通同框”的秋日国风创意合影照（风格基准样例图：https://aka.doubaocdn.com/s/TbwtzjgBLU ） |
| 手绘淡彩课件制作 | 手绘钢笔线稿+淡彩水彩风格的完整教学课件 PPT：按用户提供课件主题与内容生成每页带配图的手绘风课件，适配课堂演示 |
| 吹蜡烛许愿 | 关灯·许愿·吹蜡烛网页交互：真实麦克风气流检测、三根蜡烛依次熄灭、火焰实时吹弯、终场礼物迸发，可按寿星姓名定制（1:1 复刻模板） |
| 合成大游戏 | 把任意图片变成可玩“合成大○○”网页游戏：飞书多维表格尺寸规范 + 10 级去底贴图 + 自包含单文件 HTML 游戏 |

## 安装方法

将对应技能目录复制到 AI 助手（豆包等）的 skills 目录下，即可加载使用。每个技能目录内均含 `SKILL.md` 说明文件。
