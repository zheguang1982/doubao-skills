# 近义易混词辨析图文+短视频自动生成

输入 2 个或 3 个同音/近音易混近义词，一键产出辨析文案、竖版辨析插画绘图 Prompt、10 秒动态视频分镜脚本。

## 强制对齐的参考范本

参考范例：淹没/湮没/埋没 竖版三栏插画。

**基础版式规则**：纵向等分布局，米色复古羊皮纸背景，黑色竖排大字词语居左，右侧卡通插画 + 戴小黄帽背书包小男孩气泡解说，底部标注常见搭配词汇。

**画风**：简约 Q 版淡线卡通，低饱和柔和配色，粗黑轮廓，复古做旧纸张纹理。

**单格统一结构**：
【左侧竖排大字词语】+【中间释义插画】+【小男孩对话气泡写核心释义】+【底部一行：常见：xxx、xxx、xxx】

## 执行步骤（固定流程，不可跳过）

### Step 1：校验输入

接收用户输入的词语，校验数量：
- 恰好 2 个或 3 个 → 继续
- 不是 → 提示用户输入【2个或3个易混近义词】，不继续后续步骤

### Step 2：词义拆解

按统一格式整理每个词语的文案：
- **核心释义**：用小学生能听懂的通俗语言，1 句话说清本义
- **使用对象/适用范围**：这个词用在什么人/事/物上
- **常用搭配**：3 个最常见的搭配词或短语

格式：
```
词语A：核心释义 + 使用对象 + 常用搭配
词语B：核心释义 + 使用对象 + 常用搭配
（3词时追加：词语C：核心释义 + 使用对象 + 常用搭配）
```

### Step 3：生成绘图 Prompt

根据词语数量自动选择二分或三分布局，填充下方【绘图 Prompt 模板】。每个词语的“配套场景插画描述”要贴合词义，用具体可视的画面（如“淹没”画水流漫过街道，“权力”画法槌和印章）。

### Step 4：生成 10 秒视频分镜脚本

根据词语数量选择对应时间轴分支，填充下方【视频脚本模板】。每格的“微动动画”必须贴合该词词义（见模板末尾的示例）。

### Step 5：按固定输出格式交付

依次输出：①辨析文案 ②绘图 Prompt ③视频脚本 ④操作提示。

## 约束规则

1. **画风必须复刻参考图**：竖版等分版面、米色旧纸张、Q 版戴小黄帽小男孩、对话气泡、左侧竖排大字。2 词用上下 2 框，3 词用上中下 3 框。
2. **视频固定时长 10 秒**，分镜流畅，动画贴合词语含义。
3. **禁止自由修改版式**，所有文案排版对齐范例。
4. **面向中小学语文教学**，用词通俗简洁，适配小学生理解。
5. 绘图 Prompt 中的文字内容（词语、释义、搭配）必须与 Step 2 的辨析文案完全一致。

## 10 秒视频脚本模板

**总时长**：固定 10 秒
**画面基底**：生成完成的等分竖版辨析插画
**动画风格**：平缓淡入、微动效果，教学向柔和动态，无剧烈运镜
**音频**：可选轻柔古风纯背景音乐（无人声）

### 分支 A：输入 3 个词语

```
00:00 - 00:03（3s）
镜头定位第一格，画面缓缓淡入，场景元素轻微动态（贴合词义），释义对话气泡文字逐字浮现

00:03 - 00:06（3s）
平滑垂直向下镜头移动至第二格，第二格画面元素淡入，配套微动动画，气泡文字浮现

00:06 - 00:09（3s）
平滑垂直向下镜头移动至第三格，第三格画面元素淡入，词义相关微动动画，气泡文字浮现

00:09 - 00:10（1s）
完整三格画面定格，画面轻微放大收束，视频收尾
```

### 分支 B：输入 2 个词语

```
00:00 - 00:04（4s）
镜头定位上方第一格，画面缓缓淡入，场景元素轻微动态，释义对话气泡文字逐字浮现

00:04 - 00:08（4s）
平滑垂直向下镜头移动至下方第二格，第二格画面元素淡入，配套微动动画，气泡文字浮现

00:08 - 00:10（2s）
完整两格画面定格，画面轻微放大收束，视频收尾
```

### 元素微动示例（按词义匹配）

- 淹没：水流缓缓波动
- 湮没：风沙渐渐覆盖古迹
- 埋没：泥土慢慢盖住宝物
- 权力：法槌缓慢起落
- 权利：天平轻轻摆动
- 权益：购物袋轻轻晃动
- 必须：闹钟响起、人物点头
- 必需：生活用品逐一摆放
- 其他词语：自行联想贴合词义的平缓动态，避免剧烈运动
