# 关灯・许愿・吹蜡烛（1:1 复刻）

## 用途

用户要"关灯 → 许愿 → 对着麦克风吹气 → 蜡烛依次熄灭"的网页交互时，直接交付 `assets/template.html`，**原样复刻，一字不改**。

页面能力：真实麦克风气流检测（区分吹气与说话/音乐）、三根蜡烛按风力依次熄灭、火焰被气流实时吹弯、关灯换暗场底图、浮尘与星愿粒子、愿望回显、BGM 与静音开关。

## 核心规则（严格复刻，禁止改动）

1. **唯一产物**：以 `assets/template.html` 为产物，复制到任务目录 `index.html` 后原样交付。**不得**重写、重构、"优化"、"美化"、拆分或合并文件。
2. **火焰位置**：烛芯坐标（左 `37.19%` / 中 `50.70%` / 右 `63.67%`，bottom `66.9%`）、四层火焰结构（halo/outer/mid/core）、`@property` 注册、气流吹弯参数（tilt v*38、shear v*16、stretch 1+v*0.6、shudder），全部以模板为准，**禁止重新调参或目测重放**。
3. **图片素材**：模板引用 CDN 远程地址（日间底图 `https://aka.doubaocdn.com/s/1EvjUfgcEn`、夜间底图 `https://aka.doubaocdn.com/s/HT4LYQVLv6`），**原样保留，禁止重新生成、替换或改动图片内容**。
4. **音频/字体**：BGM（`https://aka.doubaocdn.com/s/pd3CfrJwgf`）与字体镜像链接保持原样。
5. **交互与文案**：麦克风检测参数（fftSize 1024、45 帧底噪校准、低频 40–420Hz、高频 2600–7200Hz、`lo<hi+8` 滤说话）、熄灭阈值（.34/.62/1.0）、点烛节奏（760/1040/1290ms）、粒子系统、四步文案，全部以模板为准。

## 交付流程

1. 复制 `assets/template.html` 为任务目录下的 `index.html`。
2. 用 `diff` 校验复制后与模板完全一致。
3. 交付时告知用户：**必须发布成 https 或 localhost 访问，`file://` 下麦克风与音频自动播放会被浏览器拦截**（页面会自动降级为"按住代替吹气"）。
4. 用户索要在线链接时，引导其在预览界面点「发布」按钮，不代为发布。

## CDN 失效时的兜底（仅此场景可替换资源）

`assets/media/` 下有备份：`scene_day.jpg`（日间底图）、`scene_night.jpg`（夜间底图）、`bgm.wav`（BGM）。

仅当上述 CDN 链接失效时：把对应备份上传到可用 CDN，用新 URL **只替换** `template.html` 里对应那一行引用，其余内容一律不动。

## 验证要点

- 复制后与模板逐字节一致（`diff -q` 无差异）。
- 页面运行时控制台无报错；关灯后三根蜡烛依次点亮、吹气能吹弯火苗并依次熄灭、全灭后停在暗场并回显愿望。
- 需要浏览器实测时，用干净标签页验证，勿复用旧会话。
