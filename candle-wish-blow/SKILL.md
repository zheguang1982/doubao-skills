# 关灯・许愿・吹蜡烛（16:9 大屏版）

## 用途

用户要"关灯 → 许愿 → 对着麦克风吹气 → 蜡烛依次熄灭"的生日交互页，直接用 `assets/template.html` 定版模板交付。**不要重新设计视觉、不要重新生成底图、不要改写火焰与粒子实现**——这套模板的火焰坐标是量过底图烛芯像素的，改一处就会错位。

页面流程与画面：

1. **日间**——明亮的餐厅，长桌上只有气球、纸旗、彩纸屑，桌中央空旷（蛋糕不在）。
2. **点击「关灯」**——一记黑场闪过，换到同一机位的夜景，**蛋糕在暖橙烛光里现身**，三根蜡烛（橙粉／薄荷绿／紫罗兰）依次在蛋糕顶上点亮，生日快乐 MIDI 音序同时响起。
3. **许愿**——写一句愿望，或只留在心里。
4. **吹气**——真实麦克风气流检测，火苗被吹弯、三根蜡烛按风力依次熄灭，青烟升起。
5. **全灭**——停在暗场，回显愿望，可「再来一次」。

页面能力：16:9 舞台自适应、真实麦克风气流检测（区分吹气与说话/音乐）、火焰被气流实时吹弯（`--tilt/--shear/--stretch/--shudder`）、生日歌 MIDI 音序合成、浮尘与星愿粒子、愿望回显、静音开关、空格/回车推进（大屏遥控用）。

## 核心规则（定版模板，禁止大改）

1. **唯一产物**：`assets/template.html` 复制到任务目录 `index.html` 后交付。不要拆分、合并、"美化"或替换实现。
2. **16:9 舞台**：`.frame` 用 `width:min(100vw, 100dvh*16/9)` + `aspect-ratio:16/9` 整体落进屏幕；非 16:9 屏幕自动出黑边；竖屏时舞台铺满、`.scene` 按 16:9 等比裁切放大。
3. **火焰坐标绑定底图**：底图、火焰、青烟都装在 `.scene`（永远 16:9），火焰用百分比定位，所以屏幕怎么变都不会和烛芯错位。**禁止**给 `.plate` 加 `background-size:cover` 或用 `background-position` 挪画面——那会破坏百分比映射。
   - 当前坐标（左/中/右）：`left 46.41% / 50.26% / 54.18%`，`bottom 59.70% / 59.95% / 59.75%`
   - 火焰尺寸：`.flame{width:.88%; aspect-ratio:1/2.2}`
   - 三处必须同步：HTML 的 3 个 `.flame` inline `style`、JS 的 `FX`、JS 的 `FY`（`FY` 是"距底边百分比" = 100 − 烛芯 y%）。
4. **图片素材**：日间 `https://aka.doubaocdn.com/s/L2qHj7u5gr`、夜间（带蛋糕）`https://aka.doubaocdn.com/s/uu4pCYsnCC`，均为 1920×1080。**原样保留**。
5. **音乐**：生日快乐 MIDI 音序，`MELODY` 数组是 [MIDI 音高, 拍数]，`BEAT=0.46`，Web Audio 现场合成（三角波 + 二倍频正弦泛音），无外部音频文件。关灯时 `startMusic()` 响应点击手势启动；全灭后降到 0.08 音量；「再来一次」`stopMusic()`。
6. **交互与文案**：麦克风参数（fftSize 1024、45 帧底噪校准、低频 40–420Hz、高频 2600–7200Hz、`lo<hi+8` 滤说话）、熄灭阈值（.34/.62/1.0）、点烛节奏（900/1180/1450ms）、粒子系统、四步文案，全部以模板为准。
7. **布局**：`.hud` 是横向条——左侧 kicker/标题/说明/愿望输入/回显，右侧风力计/提示/按钮；`#tip` 必须在 `.row` 之前（放下方会被裁掉）。只有竖屏媒体查询才退回上下居中结构。

## 交付流程

1. 复制 `assets/template.html` 为任务目录下的 `index.html`。
2. 需要改文案（寿星姓名、愿望占位、结束语）时只动 HUD 里的文字与 `toWish/toBlow/done/reset` 里的字符串，别碰火焰与音频。
3. 交付时告知用户：**必须发布成 https 或 localhost 访问，`file://` 下麦克风会被浏览器拦截**（页面会自动降级为"按住代替吹气"，画面与音乐仍正常）。
4. 用户索要在线链接时，引导其在预览界面点「发布」按钮，不代为发布。

## 换底图时怎么改（唯一允许重制素材的场景）

新底图必须 **16:9**、蛋糕居中且三根蜡烛竖直插在蛋糕顶上、蜡烛顶端**没有画好的火苗**（火苗由 CSS 提供）。换图后必须重新量烛芯坐标：

1. 用 Python + Pillow 扫描烛身的彩色像素（`max(r,g,b)>90` 且饱和度 >0.3），得到三根蜡烛的 x 中心与蜡面顶端 y。
2. 或者叠一张"每 1% 一条参考线"的网格图直接读坐标，肉眼校对到 ±0.2%。
3. 火焰底边取"蜡面顶端再往下 0.3%"（让火苗压住烛芯，不留黑线悬空）。
4. 同步改 HTML inline `left/bottom`、JS `FX`、JS `FY` 三处，然后截图核对火苗是否正好长在蜡烛头上。

## CDN 失效时的兜底

`assets/media/` 下有备份：`scene_day_16x9.jpg`（日间）、`scene_night_16x9.jpg`（夜间带蛋糕）。旧竖版素材在 `assets/media/legacy/`，已不再使用。

仅当 CDN 链接失效时：把备份上传到可用 CDN，用新 URL **只替换** `template.html` 里 `--day` / `--night` 那一行，其余不动。

## 验证要点

- 打开页面：16:9 舞台完整落屏，日间无蛋糕，只有气球与空桌。
- 点「关灯」：黑场闪过 → 夜景蛋糕现身 → 三根蜡烛依次点亮 → 生日快乐 MIDI 响起（右上角纽扣可静音）。
- 火苗必须**正好长在蜡烛头上**，不悬空、不偏移（用浏览器截图核对三根）。
- 麦克风吹气：火苗被吹弯、三根蜡烛依次熄灭、青烟升起；无权限时自动出现"按住代替吹气"。
- 1600×900 / 1920×1080 下 HUD 不遮挡蛋糕盘；1024×768 出上下黑边；竖屏（750×1334）场景裁切放大且火苗仍对齐。
- 控制台无报错。
