# 卡通合影照 · 一键生成技能

## 标准样例

风格基准图见 `assets/标准样例_九月你好.jpg`，在线URL：`https://aka.doubaocdn.com/s/TbwtzjgBLU`

所有生成结果必须沿用该样例的构图、背景、色调、人物排布与整体风格。

## 触发条件

用户输入包含“卡通合影照”等关键词，且上传了一张真人照片。无需用户分步指令，一键执行完整流程。

## 执行流程（严格按顺序）

### 第一步：读取并分析真人照片

1. 用 `Read` 工具读取用户上传的真人照片（`thumbnail_size: full`）。
2. 分析并记录以下人物特征，用于后续 prompt 构造：
   - **性别 / 年龄段**（如：中年男士 / 年轻女士）
   - **发型发色**（如：黑色短发 / 棕色长直发）
   - **服装**（如：深色西装外套+白衬衫 / 黄色无袖上衣+扎染阔腿裤）
   - **动作姿势**（必须逐肢体精确描述，禁止只写笼统动作名：左臂/右手/双腿/躯干各在什么位置、做什么动作，如：右手握杖自然垂于身侧、左手抬起举至耳侧）
   - **手势细节**（必须精确记录每只手的手势与位置：哪只手、比什么手势、手指如何摆放、抬到哪个高度/贴近身体哪个部位；如：左手食指与中指竖起成V形剪刀手、其余手指收拢，举至左耳旁，掌心朝前）
   - **表情神态**（如：严肃沉思、正视前方 / 开心大笑、眨眼）
   - **人物朝向**（必须判断：正面 / 侧面朝左 / 侧面朝右）
   - **其他显著特征**（眼镜、配饰、手持物品等）

### 第二步：抠像处理与朝向校正

#### 2.1 抠像处理

对上传的真人照片执行抠像（背景分离）处理：
- 目标：将人物从原背景中干净分离，去除原图背景，保留完整人物轮廓（含发丝、手指、手持物品等细节）。
- 实现方式：通过 `image_edit` 的参考图生成机制自动完成抠像与背景融合——生成时人物被重新绘制并嵌入标准国风场景，原背景不残留。在 prompt 中必须强调“人物从原背景中完美分离，边缘干净自然，无原背景残留，无缝融合到围墙场景中”。
- 若本地环境支持 Python + Pillow，可先用脚本生成透明背景 PNG 作为中间素材；默认直接依赖 image_edit 生成机制完成抠像。

#### 2.2 朝向校正（仅侧面照）

根据第一步判断的人物朝向，执行以下规则：

| 上传照片朝向 | 校正操作 | 最终成品朝向 |
|---|---|---|
| 正面 | 不调整 | 真人正视镜头，卡通正视镜头 |
| 侧面朝左 | 不调整 | 真人朝左，卡通朝右（面对面呼应） |
| 侧面朝右 | **水平翻转**（在 prompt 中指定真人朝左，等效于对参考图做水平镜像） | 真人朝左，卡通朝右（面对面呼应） |

**校正规则（硬约束）：**
- 所有侧面照的最终成品中，**右侧真实人物必须朝向画面左侧，左侧卡通人物必须朝向画面右侧**，两人呈面对面呼应姿态。
- 上传照片为侧面朝右时，必须在 prompt 中明确指定真人朝左，不可直接沿用参考图的朝右方向。
- 正面照不适用朝向规则，保持正视即可。

记录校正结果为 `{{朝向约束语句}}`：
- 侧面照填入：`右侧真实人物面部朝向画面左侧，左侧卡通人物面部朝向画面右侧，两人呈面对面呼应姿态。`
- 正面照填入：`人物正视镜头。`

### 第三步：上传参考图获取 URL

调用 `FileBatchUpload`，同时上传以下两张图：
1. **标准样例图**：本地路径 `assets/标准样例_九月你好.jpg`（用于风格/背景/布局参考）
2. **用户真人照片**：用户上传的本地路径（用于人物外貌/动作参考，已在第二步完成抠像与朝向校正规划）

获取返回的两个 URL，记为：
- `样例URL`
- `真人URL`

### 第四步：调用 image_edit 生成图片

使用 `image_edit` 工具，参数如下：

- `model_version`: `seedream_4.5`（默认）
- `image_reference_url_list`: `[样例URL, 真人URL]`（两张都传入，顺序不可变）
- `width`: `1152`
- `height`: `2048`（9:16 竖版）

#### Prompt 构造模板

将第一步和第二步分析出的人物特征与校正结果填入以下模板，`{{}}` 为占位符：

```
竖版9:16构图，真人与Q版卡通插画同框的创意合影照片，秋日国风治愈风格。上传真人照片已完成抠像处理，人物从原背景中完美分离，边缘干净自然，无原背景残留，无缝融合到以下场景中。背景为中式古典园林鹅黄色围墙，墙顶青灰色中式筒瓦屋檐，顶部有柿子树枝垂落，挂满橙红色柿子和绿叶。墙面右侧有竖排黑色书法大字“九月你好”，旁有小字“九月福气久久·”，墙下方有红色方形篆体印章，围墙底部有一圈黑色墙裙。{{朝向约束语句}}动作与手势严格复刻上传照片，不做任何萌化改编、不得改换或增删动作。左侧为Q版卡通{{年龄段}}{{性别}}形象，{{发型发色}}，穿{{服装}}，动作姿势为：{{详细动作描述}}，手势为：{{手势细节}}，表情{{表情描述}}，日系萌系平涂画风，线条干净。该卡通形象为墙面贴画/壁画效果，贴附在鹅黄色墙面上，底部以下方黑色墙裙为界，不落地、不超过墙裙上方，卡通下半身在墙裙线以上自然收束，如同画在墙上的插画。右侧为写实摄影质感的{{年龄段}}{{性别}}，{{发型发色}}，穿{{与左侧同款服装}}，动作姿势与左侧卡通完全一致：{{重复详细动作描述}}，手势同样完全一致：{{重复手势细节}}，表情{{重复表情描述}}，姿态自然。除上述固定背景元素与照片人物自身穿戴手持外，画面中禁止出现任何额外装饰、道具、花纹、飘带、光斑、星星、花朵、气球、爱心或多余文字。自然柔和秋日自然光，暖黄色调，温馨治愈，真人与卡通融合自然，右侧真人站立落地，左侧卡通贴附墙面不落地，两者并排。
```

#### 关键约束（必须遵守）

1. **真人动作严格一致**：右侧写实真人的动作、表情、姿势、样态必须逐肢体逐细节与用户上传照片保持一致（朝向按第二步校正规则调整）。四肢摆放、身体角度、面部表情均需原样复刻，**严禁擅自改换动作**——不得把剪刀手改成张开五指/比心/挥手，不得把原手势换成别的，不得增删动作。
2. **卡通动作严格一致**：左侧Q版卡通的动作、表情、姿势、样态同样必须逐细节与上传照片保持一致（朝向按面对面规则调整），仅将形象转为卡通，**动作不可做萌化改编**（不可把剪刀手改成比心/托腮/挥手等任何其他手势）。
3. **手势严格复刻（硬约束）**：左右手手势必须与照片完全一致——哪只手比什么手势就保持什么手势，手指数量、指向、抬举高度、贴近部位全部照搬，不得改换、不得增加、不得删减、不得左右互换。卡通与真人手势必须与照片相同且彼此相同。
4. **同款服装**：卡通与真人必须穿完全相同的服装（颜色、款式、配饰一致）。
5. **压制额外装饰（硬约束）**：除固定背景元素（黄墙、青瓦、柿子枝、书法字、印章、黑色墙裙）与照片中人物自身穿戴/手持物品外，**禁止添加任何原照片与背景中不存在的装饰**——如飘带、蝴蝶结、星星、光斑、花朵、气球、爱心、额外文字、图腾纹样、地毯、台阶、摆件等一律不得出现。人物服装、发型、首饰、道具不得擅自增加或改变。
6. **抠像干净**：人物必须从原背景中完美分离，边缘干净自然，无原背景残留，无缝融合到国风围墙场景中。
7. **侧面朝向规则**：所有侧面照的最终成品中，右侧真人必须朝向画面左侧，左侧卡通必须朝向画面右侧，两人面对面呼应。上传照片侧面朝右时必须在 prompt 中校正为朝左。
8. **背景固定**：黄墙、青瓦、柿子树、“九月你好”书法字、红色印章、黑色墙裙为固定背景元素，不可省略或替换。
9. **布局固定**：左侧卡通、右侧真人，并排，不可调换位置。
10. **卡通贴墙不落地**：左侧Q版卡通形象必须为墙面贴画/壁画效果，贴附在鹅黄色墙面上，底部以下方黑色墙裙为上界，不落地、不延伸到墙裙以下，卡通下半身在墙裙线以上自然收束。右侧真人正常站立落地。
11. **竖版9:16**：尺寸固定为 1152×2048。

## 常见问题处理

- **用户未上传照片**：提示用户上传一张真人照片后再生成。
- **用户要求换背景文字**：在 prompt 中将“九月你好”替换为用户指定文字，其余背景元素保留。
- **用户要求换季节主题**：仅在用户明确要求时调整，默认固定为秋日柿子+九月你好。
- **生成结果动作/手势不符**：重新生成，在 prompt 中逐肢体逐手势详细描述上传照片的具体位置与动作（哪只手、什么手势、抬举高度、贴近部位），并再次强调“严格复刻、禁止改换手势、禁止增删动作”。
- **生成结果出现多余装饰**：重新生成，在 prompt 中强化“禁止添加任何额外装饰/道具/花纹/飘带/光斑/星星/花朵/气球/爱心/多余文字，仅保留固定背景元素与人物自身穿戴手持”。
- **生成结果朝向错误**：检查第二步朝向判断是否正确，侧面朝右时必须在 prompt 中明确指定真人朝左，重新生成。
- **抠像不干净/有原背景残留**：在 prompt 中强化“人物从原背景完美分离、边缘干净、无残留”的描述，重新生成。
