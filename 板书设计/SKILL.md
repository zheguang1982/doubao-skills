# 板书设计 Skill
> 版本：v1.0.0 — 以"自作主张老师"板书风格为基准，深绿黑板+彩色粉笔手绘+主题插画居中+逻辑箭头串联+红色点题，一键从教材PDF生成成品板书图。

## 技能标识
`板书设计`

## 适用场景
- 用户提供统编版小学语文电子教材PDF和教师用书PDF（或指定具体课文）
- 需要为某一课生成一张可直接照抄到黑板的板书设计图
- 适用于：精读阅读课文、习作指导课、口语交际课、古诗词教学
- 输出：一张9:16竖版粉笔手绘风格板书设计图片

## 核心功能
用户提供**电子教材PDF + 教师用书PDF**（或指定课文名称），本技能自动完成：
1. 从PDF中提取指定课文的核心教学内容（课题、作者、主要内容、写作方法、情感主旨）
2. 按照本技能定义的板书风格规范，设计板书布局（中心插画+左右分栏+底部点题）
3. 调用图像生成工具（seedream_5.0_pro）生成成品板书设计图
4. 交付9:16竖版图片，可直接打印参考或照抄黑板

---

## 输入规范
调用时需用户提供以下信息：
1. **教材PDF路径**：统编版语文电子教材PDF文件
2. **教师用书PDF路径**：对应册次/单元的教师用书PDF文件（用于提取教学重难点、板书建议）
3. **指定课文**：用户想要设计板书的课文名称（如《落花生》《桂花雨》《将相和》）
4. **课型**（可选）：精读课文/习作/口语交际/古诗词——默认按教材课型判断

> 若用户只提供了课文名称和教材PDF而未提供教师用书，可仅凭教材内容完成设计；教师用书用于提升教学重难点和板书建议的准确性。

## 板书风格基准（11张参考图提炼）

> 以下风格规范全部来自用户提供的11张真实课堂板书照片（落花生×2版、桂花雨、浣溪沙、珍珠鸟、冀中的地道战、将相和、什么比猎豹的速度更快、习作提纲、习作我的心爱之物、口语交际制定班级公约），生成图片必须严格复刻此风格。

### 一、视觉基底

- **黑板背景**：深墨绿色（#1a3a3a 附近）真实黑板质感，带细微粉笔灰纹理和使用痕迹，**不是纯黑**
- **粉笔质感**：所有文字和插画均为彩色粉笔手绘效果，有颗粒感、飞白、不均匀涂抹感，**不是印刷体、不是矢量平涂**
- **字体**：手写粉笔字风格，自然流畅、略带歪扭，像真实老师在黑板上写的，**严禁出现印刷体、宋体、楷体电脑字**
- **画幅**：9:16竖版（对应真实黑板竖版拍摄比例），边缘可见木框/金属边框

### 二、色彩系统（严格按功能配色）

| 颜色 | 粉笔色值参考 | 用途 |
|---|---|---|
| **白色** | #f0f0f0 | 主文字、故事情节、事实性内容、关键词 |
| **黄色/金黄** | #f0d040 | 人物品质标签、重要概念框、重点词标注 |
| **红色** | #e05050 | 核心主旨、道理、情感结论、题眼字（如"和"） |
| **绿色** | #60c060 | 自然景物插画、阅读方法提示、结构标签 |
| **蓝色** | #5090d0 | 箭头连接线、水流/瀑布等景物、过程步骤 |
| **粉色/紫色** | #d080c0 | 写作手法标签（借物喻人、借物抒情）、情感词 |
| **橙色/棕色** | #d08040 | 木质元素、地道剖面、豹子斑纹等 |

**配色原则**：白色占60%（主文字），彩色占40%（功能标注），红色仅用于底部点题和核心词（不超过3处），整体协调不花哨。

### 三、布局结构（通用骨架）

```
┌─────────────────────────────┐
│        课题 + 作者（顶部居中）   │  ← 大号白色粉笔字
│                             │
│   ┌─────────────────────┐   │
│   │                     │   │
│   │    中心主题插画       │   │  ← 课文核心意象的粉笔插画
│   │  （占画面中心40%）    │   │
│   │                     │   │
│   └─────────────────────┘   │
│                             │
│  左侧分析        右侧分析     │  ← 左右分栏，箭头连接中心
│  （品质/方法）   （特点/细节） │
│                             │
│  ┌─────────────────────┐   │
│  │  核心主旨/道理（红色） │   │  ← 底部红色粉笔字点题
│  └─────────────────────┘   │
└─────────────────────────────┘
```

**具体规则**：
1. **顶部**：课题序号+标题（大号白色粉笔字居中），作者名写在标题右侧稍小
2. **中心插画**：选取课文最核心的视觉意象（落花生→花生植株、桂花雨→桂花枝条、珍珠鸟→小鸟停枝、地道战→地道剖面、将相和→"将""相"圆圈、猎豹→猎豹奔跑图），用粉笔简笔画风格绘制，占画面中心约35-40%面积
3. **左侧栏**：写分析性、概括性内容（人物品质、写作方法、结构标签），用黄色或粉色粉笔标注类别词，白色写具体内容
4. **右侧栏**：写细节性、支撑性内容（事物特点、具体事件、数据），用白色粉笔书写，关键数据用蓝色标注
5. **连接元素**：用箭头（→）、括号（{}）、圆圈（○）、心形、方框等粉笔图形串联左右两侧与中心插画，体现逻辑关系
6. **底部**：用红色粉笔写核心主旨/道理/情感升华，1-2句话居中，这是全板书的"点睛之笔"

### 四、不同课型的布局变体

#### 1. 精读阅读课（最常见）
- 中心插画=课文核心意象
- 左侧=写作手法/人物品质/结构分析
- 右侧=事物特点/情节发展/具体描写
- 底部=红色点题（道理/情感/主旨）
- 写作手法标签用粉色粉笔突出（如"借物喻人""借物抒情""对比"）

#### 2. 习作指导课
- 中心=习作主题词（如"心爱之物"，用心形框住）
- 左栏=审题要点、选材类别框
- 右栏=选材类别框（动物/植物/玩具/生活用品）
- 底部=拟题示例
- 或用"开头→中间→结尾"树状结构图，中间展开三个分支

#### 3. 口语交际课
- 中心=主题词（如"班级问题"，用圆形框住）
- 四周辐射四个方面（学习/纪律/卫生/文明）
- 左侧=定义、作用（黄色标签）
- 右侧/下方=步骤流程（蓝色箭头连接）

#### 4. 古诗词教学
- 中心=诗意意象插画（如松树、兰草、溪流）
- 左侧=词前小序、上阕写景（粉色标签）
- 右侧=下阕抒情、名句（粉色标签）
- 底部=红色点题（情感/人生态度）

## 完整执行流程

### 阶段1：读取教材，提取课文核心内容
1. 用PDF读取工具打开电子教材PDF，定位到用户指定的课文
2. 提取以下关键信息：
   - **课题**：序号+课文标题
   - **作者**：课文作者
   - **主要内容**：课文写了什么（用一句话概括）
   - **结构脉络**：课文分几个部分/段落，各写了什么
   - **写作手法**：借物喻人、借景抒情、对比、列数字、作比较等
   - **关键意象**：课文最核心的视觉元素（花生、桂花、小鸟、地道、猎豹等）
   - **主旨道理**：课文表达的情感/说明的道理
   - **人物形象**（如有）：主要人物及其品质
3. 若有教师用书PDF，提取其板书设计建议、教学重难点，融入设计

### 阶段2：设计板书布局方案
根据课型和课文内容，确定：
1. **中心插画**：选什么意象，怎么画（如《落花生》→花生植株带四个豆荚，每个豆荚里写"种/收/尝/议"）
2. **左栏内容**：写什么分析要点
3. **右栏内容**：写什么细节支撑
4. **连接方式**：用什么箭头/图形串联
5. **底部点题**：红色粉笔写什么主旨句
6. **写作手法标签**：用粉色粉笔标注什么

### 阶段3：生成板书设计图（核心步骤）
调用 `image_gen` 工具（model_version 选 **seedream_5.0_pro**），按以下规范构造Prompt：

**Prompt模板**：
```
一块真实的墨绿色黑板照片，上面用彩色粉笔手绘了一张小学语文板书设计。
黑板上的内容如下：
- 顶部居中用白色粉笔大字写着"[课题序号+课题]"，右侧稍小写着"[作者]"
- 画面中心是[中心插画描述：粉笔简笔画风格的XXX，绿色/棕色/蓝色粉笔绘制]
- 左侧用[颜色]粉笔写着"[左侧分析标题]"，下面白色粉笔列出：
  - [要点1]
  - [要点2]
  - [要点3]
- 右侧用[颜色]粉笔写着"[右侧细节标题]"，下面白色粉笔列出：
  - [细节1]
  - [细节2]
  - [细节3]
- 用[颜色]粉笔箭头连接中心插画和左右两侧，标注逻辑关系
- 底部用红色粉笔居中写着"[核心主旨句]"
- 写作手法标签"[手法名]"用粉色粉笔写在对应位置
所有文字都是自然手写粉笔字风格，有粉笔颗粒质感和飞白效果，不是印刷体。
黑板边缘可见木质边框。真实课堂黑板照片质感，光照自然。
```

**关键参数**：
- model_version: `seedream_5.0_pro`
- width: 1152, height: 2048（9:16竖版）
- 必须强调"手写粉笔字""真实黑板质感""彩色粉笔"等关键词
- 文字内容必须准确无误（课题名、作者、关键术语）

### 阶段4：校验与交付
1. 生成后检查图片中的文字是否清晰可读、有无错别字
2. 检查布局是否符合本技能规范（中心插画+左右分栏+红色点题）
3. 如文字错误或布局偏差，重新生成（调整Prompt）
4. 交付最终图片

## 板书内容设计原则

1. **简洁性**：板书不是把课文抄上去，而是提炼最核心的3-5个要点
2. **逻辑性**：箭头和连线体现因果、递进、对比关系
3. **视觉性**：中心插画必须一眼看出课文写的是什么
4. **点题性**：底部红色主旨句必须是全课的灵魂
5. **可照抄**：老师看着这张图能直接在黑板上画出来，不能太复杂

### 板书内容提炼checklist
设计板书前，必须从教材中提取以下要素：
- [ ] 课题序号和标题
- [ ] 作者
- [ ] 课文核心意象（画什么插画）
- [ ] 2-4个主要情节/结构要点
- [ ] 1-2个写作手法
- [ ] 核心人物品质（如有）
- [ ] 底部主旨句（1-2句话）

---

## 内容质量标准

1. **风格还原度**：生成的图片必须像真实老师在黑板上用彩色粉笔写的，不能像PPT、不能像印刷海报
2. **文字准确性**：课题、作者、关键术语必须与教材一致，无错别字
3. **布局合理性**：中心插画突出，左右分栏平衡，底部点题醒目
4. **教学适用性**：板书内容是教学重难点的提炼，不是课文原文堆砌
5. **色彩规范性**：严格按本技能色彩系统使用粉笔颜色，不随意配色

## 调用示例

> 用户输入：这是五年级上册第一单元电子教材和教师用书，帮我设计《落花生》的板书
>
> 技能流程：
> 1. 从教材PDF提取《落花生》内容：许地山作，借物喻人，写种花生→收花生→尝花生→议花生，道理是"人要做有用的人"
> 2. 设计布局：中心画花生植株带四个豆荚（种/收/尝/议），左侧写"朴实无华/默默无闻/不图虚名"，右侧写"味道很美/可以榨油/价钱便宜/不好看/很有用"，粉色标注"借物喻人""对比"，底部红色写"道理：人要做有益于他人和社会的人，不要做只讲体面而对社会没有一点贡献的人"
> 3. 调用seedream_5.0_pro生成9:16板书图
> 4. 交付图片

> 用户输入：教材PDF在桌面，帮我出《将相和》的板书
>
> 技能流程：
> 1. 提取《将相和》内容：司马迁《史记》，完璧归赵→渑池会面→不和→负荆请罪，将=廉颇（知错就改/英勇善战），相=蔺相如（机智勇敢/不畏强暴），核心字"和"
> 2. 设计布局：中心画"将""相"两个红圈，中间串联四个事件方框，左侧写廉颇品质，右侧写蔺相如品质，底部黄色"顾全大局"+红色大字"和"
> 3. 生成9:16板书图
> 4. 交付图片
