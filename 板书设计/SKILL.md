# 板书设计 Skill
> 版本：v2.0.0 — 理论升级：以**三维关键词提炼法**为骨架（文章内容What / 写作手法How / 主题思想Why），全板文字严格控制在60字以内，每个要点只写关键词不写句子；中心视觉支持**手绘情境图**或**思维导图**二选一；深绿黑板+彩色粉笔手绘+红色点题，一键从教材PDF生成精简成品板书图。

## 技能标识
`板书设计`

## 适用场景
- 用户提供统编版小学语文电子教材PDF和教师用书PDF（或指定具体课文）
- 需要为某一课生成一张可直接照抄到黑板的板书设计图
- 适用于：精读阅读课文、习作指导课、口语交际课、古诗词教学
- 输出：一张9:16竖版粉笔手绘风格板书设计图片

## 核心功能
用户提供**电子教材PDF + 教师用书PDF**（或指定课文名称），本技能自动完成：
1. 从PDF中提取指定课文的核心教学内容
2. 用**三维关键词提炼法**将内容压缩为关键词（全板≤60字）
3. 选择中心视觉形式（手绘情境图 / 思维导图），设计板书布局
4. 调用图像生成工具（seedream_5.0_pro）生成成品板书设计图
5. 交付9:16竖版图片，可直接打印参考或照抄黑板

---

## 输入规范
调用时需用户提供以下信息：
1. **教材PDF路径**：统编版语文电子教材PDF文件
2. **教师用书PDF路径**：对应册次/单元的教师用书PDF文件（用于提取教学重难点、板书建议）
3. **指定课文**：用户想要设计板书的课文名称（如《落花生》《桂花雨》《将相和》）
4. **课型**（可选）：精读课文/习作/口语交际/古诗词——默认按教材课型判断
5. **中心视觉偏好**（可选）：手绘情境图 / 思维导图——默认由AI根据课文文体自动判断（叙事性课文用情境图，说明/方法/习作类用思维导图）

> 若用户只提供了课文名称和教材PDF而未提供教师用书，可仅凭教材内容完成设计；教师用书用于提升教学重难点和板书建议的准确性。

## 板书风格基准（11张参考图提炼）

> 以下风格规范全部来自用户提供的11张真实课堂板书照片（落花生×2版、桂花雨、浣溪沙、珍珠鸟、冀中的地道战、将相和、什么比猎豹的速度更快、习作提纲、习作我的心爱之物、口语交际制定班级公约），生成图片必须严格复刻此风格。

### 一、视觉基底

- **黑板背景**：深墨绿色（#1a3a3a 附近）真实黑板质感，带细微粉笔灰纹理和使用痕迹，**不是纯黑**
- **粉笔质感**：所有文字和插画均为彩色粉笔手绘效果，有颗粒感、飞白、不均匀涂抹感，**不是印刷体、不是矢量平涂**
- **字体**：手写粉笔字风格，自然流畅、略带歪扭，像真实老师在黑板上写的，**严禁出现印刷体、宋体、楷体电脑字**
- **画幅**：9:16竖版（对应真实黑板竖版拍摄比例），边缘可见木框/金属边框

### 二、色彩系统（严格按功能配色）

| 颜色 | 粉笔色值参考 | 用途 |
|---|---|---|
| **白色** | #f0f0f0 | 主文字、关键词、情节节点 |
| **黄色/金黄** | #f0d040 | 人物品质标签、重要概念框、文章内容维度标题 |
| **红色** | #e05050 | 核心主旨、题眼字、底部点题 |
| **绿色** | #60c060 | 自然景物插画、思维导图分支、结构标签 |
| **蓝色** | #5090d0 | 箭头连接线、情节线、过程步骤 |
| **粉色/紫色** | #d080c0 | 写作手法标签（借物喻人、对比、伏笔） |
| **橙色/棕色** | #d08040 | 木质元素、情境图中的人物/器物 |

**配色原则**：白色占60%（关键词），彩色占40%（功能标注），红色仅用于底部点题和题眼字（不超过3处），整体协调不花哨。

### 三、布局结构（通用骨架）

```
┌─────────────────────────────┐
│        课题 + 作者（顶部居中）   │  ← 大号白色粉笔字
│                             │
│   ┌─────────────────────┐   │
│   │                     │   │
│   │  中心视觉（情境图/导图）  │  ← 占画面中心35-40%
│   │                     │   │
│   └─────────────────────┘   │
│                             │
│  文章内容(黄)    写作手法(粉)  │  ← 左右分栏，各≤4个关键词
│  关键词+情节线    手法名+关键词 │
│                             │
│  ┌─────────────────────┐   │
│  │  主题思想（红色题眼+短句） │  │  ← 底部红色点题，≤20字
│  └─────────────────────┘   │
└─────────────────────────────┘
```

**具体规则**：
1. **顶部**：课题序号+标题（大号白色粉笔字居中），作者名写在标题右侧稍小
2. **中心视觉**：二选一——
   - **手绘情境图**：课文核心场景的粉笔简笔画（如落花生植株、桂花枝、天河鹊桥），适合叙事性、抒情性课文
   - **思维导图**：中心词+3-4条放射分支，每条分支末端1个关键词，适合说明文、习作方法、口语交际、语文园地
3. **左栏·文章内容**：黄色粉笔写维度标题"内容"，下面白色粉笔列2-4个关键词；如有情节线，用蓝色箭头串联2-5字的节点词（如：救蛇→得宝→劝迁→化石）
4. **右栏·写作手法**：粉色粉笔写维度标题"手法"，下面白色粉笔列1-2个手法名，每个手法后用箭头接1个关键词说明（如：借物喻人→花生→做人）
5. **连接元素**：用箭头（→）、圆圈（○）、方框等粉笔图形串联，体现逻辑关系
6. **底部·主题思想**：红色粉笔写1个题眼大字（如"和""爱""美"）+ 1句不超过20字的主旨句，居中

## 三维关键词提炼法（v2.0.0 核心方法论）

> 板书不是课文缩写，而是**关键词的可视化**。所有内容必须从以下三个维度提炼，每个维度只写关键词，不写完整句子。

### 第一维：文章内容（What）——黄色标签

提取课文"写了什么"的最核心信息，压缩为关键词：

| 提炼方向 | 关键词形式 | 示例（《猎人海力布》） |
|---|---|---|
| 情节脉络 | 2-5字节点，箭头串联 | 救蛇→得宝→听语→劝迁→化石 |
| 人物品质 | 2-4字词语，≤4个 | 热心、善良、舍己 |
| 结构脉络 | 关键词标注 | 起因·经过·结果 |
| 事物特点 | 2-4字词语 | 朴实、有用、不张扬 |

**规则**：情节线每个节点2-5字，全栏关键词不超过4个，不写完整句子。

### 第二维：写作手法（How）——粉色标签

提取课文"怎么写的"核心手法，每个手法配1个关键词说明：

| 手法类型 | 标注形式 | 示例 |
|---|---|---|
| 表现手法 | 手法名→关键词 | 借物喻人→花生→做人 |
| 结构手法 | 手法名→关键词 | 伏笔照应→宝石秘密→变石头 |
| 修辞方法 | 手法名→关键词 | 对比→花生vs桃子石榴 |
| 说明方法 | 手法名→关键词 | 列数字→速度数据 |

**规则**：只列1-2个最核心的手法，不堆砌；每个手法说明不超过6字。

### 第三维：主题思想（Why）——红色点题

提取课文"为什么写"的灵魂，压缩为题眼+短句：

- **题眼字**：1个最能概括全文主旨的字（如《将相和》→"和"，《落花生》→"用"，《珍珠鸟》→"信"）
- **主旨句**：1句不超过20字的话，点明情感/道理/启示

**规则**：题眼字用红色大号粉笔字，主旨句用红色中号粉笔字，不超过20字，不写长段落。

### 字数硬约束（强制执行）

| 区域 | 字数上限 | 说明 |
|---|---|---|
| 左栏·文章内容 | ≤20字 | 含情节线节点和品质词 |
| 右栏·写作手法 | ≤15字 | 含手法名和说明词 |
| 底部·主题思想 | ≤20字 | 含题眼字和主旨句 |
| **全板合计** | **≤60字** | 不含课题、作者、维度标签 |

> 超过字数必须继续压缩，宁可少写不可多写。板书是"提词器"不是"讲义"。

## 中心视觉二选一

### A. 手绘情境图（默认用于叙事/抒情课文）

- 选取课文最核心的一个场景或意象，用粉笔简笔画绘制
- 占画面中心约35-40%面积
- 示例：《落花生》→花生植株带豆荚；《桂花雨》→桂花枝条；《牛郎织女》→天河鹊桥；《将相和》→"将""相"两个圆圈
- 情境图中可嵌入关键词（如花生豆荚里写"种/收/尝/议"）

### B. 思维导图（默认用于说明/方法/习作类课文）

- 中心1个圆圈写核心主题词，向外放射3-4条分支
- 每条分支末端1个关键词或1个小方框
- 分支用不同颜色粉笔区分维度
- 示例：习作"故事新编"→中心"新编"，分支：设想结局/想象情节/编写故事；口语交际"讲民间故事"→中心"讲故事"，分支：丰富细节/大胆想象/代入角色/变换顺序

## 不同课型的布局变体

#### 1. 精读阅读课（最常见）
- 中心视觉=手绘情境图（课文核心意象）
- 左栏=文章内容（情节线关键词+人物品质词）
- 右栏=写作手法（1-2个手法名+关键词说明）
- 底部=主题思想（红色题眼字+≤20字主旨句）

#### 2. 习作指导课
- 中心视觉=思维导图（中心主题词+方法分支）
- 左栏=审题关键词（2-3个）
- 右栏=写法关键词（2-3个）
- 底部=红色点题（习作要求核心词）

#### 3. 口语交际课
- 中心视觉=思维导图（中心主题词+方法/方面分支）
- 左栏=要求关键词（2-3个）
- 右栏=方法关键词（2-3个）
- 底部=红色点题（交际目标核心词）

#### 4. 古诗词教学
- 中心视觉=手绘情境图（诗意意象）
- 左栏=内容关键词（上阕/下阕意象词）
- 右栏=手法关键词（1-2个）
- 底部=主题思想（红色题眼字+情感短句）

## 完整执行流程

### 阶段1：读取教材，提取课文核心内容
1. 用PDF读取工具打开电子教材PDF，定位到用户指定的课文
2. 提取以下关键信息：
   - **课题**：序号+课文标题
   - **作者**：课文作者
   - **主要内容**：课文写了什么（一句话概括，用于后续压缩）
   - **结构脉络**：课文分几个部分
   - **写作手法**：1-2个最核心的手法
   - **关键意象**：课文最核心的视觉元素（用于情境图）
   - **主旨道理**：课文表达的情感/道理（用于压缩为题眼+短句）
   - **人物形象**（如有）：主要人物品质
3. 若有教师用书PDF，提取其教学重难点，融入关键词提炼

### 阶段2：三维关键词提炼（核心步骤）
按"三维关键词提炼法"将内容压缩：

1. **文章内容维**：
   - 提炼情节线（2-5字节点，箭头串联，≤5个节点）
   - 提炼人物品质/事物特点（2-4字词语，≤4个）
   - 本栏总字数≤20字

2. **写作手法维**：
   - 确定1-2个核心手法名
   - 每个手法配1个≤6字的关键词说明
   - 本栏总字数≤15字

3. **主题思想维**：
   - 确定1个题眼字
   - 写1句≤20字的主旨句
   - 本栏总字数≤20字

4. **字数校验**：三维合计≤60字，超出则继续压缩

### 阶段3：选择中心视觉，设计布局
1. 根据课型和文体选择中心视觉：
   - 叙事/抒情/古诗词 → 手绘情境图
   - 说明/习作/口语交际/语文园地 → 思维导图
2. 确定情境图内容或思维导图分支
3. 确定左右分栏的关键词排列方式
4. 确定底部题眼字和主旨句

### 阶段4：生成板书设计图
调用 `image_gen` 工具（model_version 选 **seedream_5.0_pro**），按以下规范构造Prompt：

## 板书内容设计原则

1. **关键词化**：板书只写关键词，不写完整句子；每个词2-6字，全板≤60字
2. **三维结构**：内容（What）、手法（How）、主题（Why）三个维度缺一不可
3. **逻辑性**：箭头和连线体现因果、递进、对比关系
4. **视觉性**：中心视觉（情境图或思维导图）必须一眼看出课文核心
5. **点题性**：底部红色题眼字+主旨句是全板灵魂
6. **可照抄**：老师看着这张图能在5分钟内画到黑板上，不能太复杂

### 板书内容提炼checklist
设计板书前，必须完成以下提炼：
- [ ] 课题序号和标题
- [ ] 作者
- [ ] 中心视觉选择（情境图 / 思维导图）及具体内容
- [ ] 文章内容维：情节线关键词（≤5个节点，每节点2-5字）
- [ ] 文章内容维：品质/特点关键词（≤4个，每词2-4字）
- [ ] 写作手法维：1-2个手法名+关键词说明

## 内容质量标准

1. **风格还原度**：生成的图片必须像真实老师在黑板上用彩色粉笔写的，不能像PPT、不能像印刷海报
2. **关键词纯度**：板书中不得出现完整句子（底部主旨句除外），所有要点必须是2-6字的关键词
3. **三维完整性**：文章内容、写作手法、主题思想三个维度必须齐全，不得缺维
4. **字数合规**：全板关键词总字数≤60字（不含课题、作者、维度标签）
5. **文字准确性**：课题、作者、关键术语必须与教材一致，无错别字
6. **布局合理性**：中心视觉突出，左右分栏平衡，底部点题醒目
7. **色彩规范性**：严格按本技能色彩系统使用粉笔颜色，不随意配色

## 调用示例

> 用户输入：这是五年级上册第一单元电子教材和教师用书，帮我设计《落花生》的板书
>
> 技能流程：
> 1. 从教材PDF提取《落花生》内容：许地山作，借物喻人，种→收→尝→议，道理是"人要做有用的人"
> 2. **三维关键词提炼**：
>    - 内容维：种→收→尝→议；朴实、有用、不张扬（14字）
>    - 手法维：借物喻人→花生→做人；对比→花生vs果实（13字）
>    - 主题维：题眼"用"；主旨"做有用的人，不做只讲体面的人"（16字）
>    - 合计43字，合规
> 3. 中心视觉=手绘情境图（花生植株带四个豆荚，豆荚里写种/收/尝/议）
> 4. 调用seedream_5.0_pro生成9:16板书图
> 5. 交付图片

> 用户输入：教材PDF在桌面，帮我出《将相和》的板书
>
> 技能流程：
> 1. 提取《将相和》内容：司马迁《史记》，完璧归赵→渑池会面→不和→负荆请罪，将=廉颇，相=蔺相如
> 2. **三维关键词提炼**：
>    - 内容维：完璧→渑池→不和→请罪；廉颇·知错就改；相如·机智勇敢（22字）
>    - 手法维：伏笔照应→和→不和→和（10字）
>    - 主题维：题眼"和"；主旨"顾全大局，以和为贵"（12字）
>    - 合计44字，合规
> 3. 中心视觉=手绘情境图（"将""相"两个红圈，中间串联事件方框）
> 4. 生成9:16板书图
> 5. 交付图片

> 用户输入：帮我出习作《故事新编》的板书
>
> 技能流程：
> 1. 提取习作要求：以《龟兔赛跑》为例，先设想结局，再想象新情节
> 2. **三维关键词提炼**：
>    - 内容维：设想结局→想象情节→编写故事；结局·都赢/都输/兔赢/龟赢（24字）
>    - 手法维：反转情节→意外变化；合理想象→有新意（14字）
>    - 主题维：题眼"新"；主旨"旧故事新讲，有趣有新意"（13字）
>    - 合计51字，合规
> 3. 中心视觉=思维导图（中心"新编"，放射分支：设想结局/想象情节/编写故事）
> 4. 生成9:16板书图
> 5. 交付图片
