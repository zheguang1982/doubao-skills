# 板书设计 Skill
> 版本：v2.1.0 — 进一步精简：板面上**不出现**"内容""手法""主题"等维度标签；关键词以**关联词**形式呈现，用箭头、线条、流程图、思维导图等可视化方式串联；全板文字严格控制在50字以内（不含课题作者和底部主旨句）；深绿黑板+彩色粉笔手绘+红色点题。

## 技能标识
`板书设计`

## 适用场景
- 用户提供统编版小学语文电子教材PDF和教师用书PDF（或指定具体课文）
- 需要为某一课生成一张可直接照抄到黑板的板书设计图
- 适用于：精读阅读课文、习作指导课、口语交际课、古诗词教学
- 输出：一张9:16竖版粉笔手绘风格板书设计图片

## 核心功能
用户提供**电子教材PDF + 教师用书PDF**（或指定课文名称），本技能自动完成：
1. 从PDF中提取指定课文的核心教学内容
2. 内部按"三维关键词提炼法"压缩为关联词（文章内容/写作手法/主题思想，但**板面上不标注这三个维度**）
3. 选择中心视觉形式（手绘情境图 / 思维导图），用箭头、线条、流程图等可视化方式串联关键词
4. 调用图像生成工具（seedream_5.0_pro）生成成品板书设计图
5. 交付9:16竖版图片，可直接打印参考或照抄黑板

---

## 输入规范
调用时需用户提供以下信息：
1. **教材PDF路径**：统编版语文电子教材PDF文件
2. **教师用书PDF路径**：对应册次/单元的教师用书PDF文件（用于提取教学重难点、板书建议）
3. **指定课文**：用户想要设计板书的课文名称（如《落花生》《桂花雨》《将相和》）
4. **课型**（可选）：精读课文/习作/口语交际/古诗词——默认按教材课型判断
5. **中心视觉偏好**（可选）：手绘情境图 / 思维导图——默认由AI根据课文文体自动判断

> 若用户只提供了课文名称和教材PDF而未提供教师用书，可仅凭教材内容完成设计。

## 板书风格基准

> 以下风格规范全部来自用户提供的真实课堂板书照片，生成图片必须严格复刻此风格。

### 一、视觉基底

- **黑板背景**：深墨绿色（#1a3a3a 附近）真实黑板质感，带细微粉笔灰纹理和使用痕迹，**不是纯黑**
- **粉笔质感**：所有文字和插画均为彩色粉笔手绘效果，有颗粒感、飞白、不均匀涂抹感，**不是印刷体、不是矢量平涂**
- **字体**：手写粉笔字风格，自然流畅、略带歪扭，像真实老师在黑板上写的，**严禁出现印刷体**
- **画幅**：9:16竖版，边缘可见木框/金属边框

### 二、色彩系统（严格按功能配色）

| 颜色 | 粉笔色值参考 | 用途 |
|---|---|---|
| **白色** | #f0f0f0 | 关键词、情节节点、事实性内容 |
| **黄色/金黄** | #f0d040 | 重点词、概念框、品质词 |
| **红色** | #e05050 | 题眼字、底部点题、核心结论 |
| **绿色** | #60c060 | 景物插画、思维导图分支、正向标签 |
| **蓝色** | #5090d0 | 箭头、连接线、流程图、过程步骤 |
| **粉色/紫色** | #d080c0 | 手法关键词、情感词 |
| **橙色/棕色** | #d08040 | 木质元素、人物器物插画 |

**配色原则**：白色为主（关键词），彩色为辅（功能标注和连线），红色仅用于底部点题和题眼字。

### 三、布局结构（通用骨架）

```
┌─────────────────────────────┐
│        课题 + 作者（顶部居中）   │  ← 大号白色粉笔字
│                             │
│   ┌─────────────────────┐   │
│   │                     │   │
│   │  中心视觉（情境图/导图）  │  ← 占画面中心35-40%
│   │                     │   │
│   └─────────────────────┘   │
│                             │
│   关键词用箭头/线条/流程图    │  ← 无维度标签！
│   串联，围绕中心视觉辐射      │  ← 用可视化方式体现关系
│                             │
│  ┌─────────────────────┐   │
│  │  红色题眼字 + 主旨短句  │   │  ← 底部红色点题
│  └─────────────────────┘   │
└─────────────────────────────┘
```

**核心规则**：
1. **顶部**：课题序号+标题（大号白色粉笔字居中），作者名稍小写在右侧
2. **中心视觉**：二选一——手绘情境图（叙事/抒情）或思维导图（说明/方法/习作）
3. **关键词呈现**：围绕中心视觉，用箭头（→）、线条、流程图、圆圈、方框等**可视化元素**串联关键词；**板面上不写"内容""手法""主题""写作方法"等维度标签词**，维度只是设计时的内部思考框架，不是板书上的文字
4. **关联词化**：关键词之间用箭头连接形成关联词（如"借物→喻人""伏笔→照应""辉煌→毁灭"），而非孤立罗列
5. **底部**：红色粉笔写1个题眼大字 + 1句简短主旨（≤15字），居中

## 三维关键词提炼法（内部方法论，不标注于板面）

> 设计板书时，内部从三个维度思考提炼，但**板面上绝不出现这三个维度的标签**。三个维度的关键词通过箭头、线条、颜色自然融合在版面中。

### 提炼维度（内部使用）

| 维度 | 思考方向 | 呈现方式（板面上） | 示例 |
|---|---|---|---|
| **文章内容** | 写了什么？情节、人物、事物 | 用流程图/箭头串联关键词，或围绕情境图标注 | 救蛇→得宝→劝迁→化石 |
| **写作手法** | 怎么写的？用了什么方法 | 用箭头连接"手法→效果"关联词，粉色粉笔 | 借物→喻人；对比→突出 |
| **主题思想** | 为什么写？情感、道理 | 底部红色题眼字+短句 | 题眼"节"+民族气节 |

**关键区别**：v2.0.0在板面上写"内容""手法"等标签——v2.1.0**删除这些标签**，关键词直接用可视化元素（箭头、线条、流程图）呈现，老师和学生看箭头就知道逻辑关系。

### 关联词呈现方式（v2.1.0核心）

关键词不是孤立的词语，而是**用箭头/线条连接的关联词**，形成可视化的逻辑链：

| 可视化方式 | 适用场景 | 示例 |
|---|---|---|
| **流程图（横向箭头）** | 情节发展、事件顺序 | 救蛇→得宝→劝迁→化石 |
| **因果箭头** | 手法→效果、原因→结果 | 借物→喻人；辉煌→毁灭 |
| **思维导图（放射分支）** | 方法类、分类类 | 中心词→分支1/分支2/分支3 |
| **对比连线** | 两个事物对比 | 花生←→桃子石榴 |
| **圆圈圈点** | 核心概念、题眼 | "将"○和"相"○ |
| **树状分支** | 结构分解 | 总→分1/分2/分3 |

### 字数硬约束（v2.1.0 收紧）

| 区域 | 字数上限 | 说明 |
|---|---|---|
| 中心视觉周围的关键词 | ≤35字 | 含所有情节线、品质词、手法关联词 |
| 底部·主题思想 | ≤15字 | 含题眼字和主旨短句 |
| **全板合计（不含课题作者）** | **≤50字** | 不含课题、作者、任何维度标签 |

> 比v2.0.0的60字进一步收紧。宁可少写不可多写，板书是"提词器"不是"讲义"。每个关键词2-5字，关联词用箭头连接。

## 中心视觉二选一

### A. 手绘情境图（默认用于叙事/抒情/古诗词）

- 选取课文最核心的一个场景或意象，用粉笔简笔画绘制
- 占画面中心约35-40%面积
- 关键词用箭头从情境图向外辐射或串联
- 示例：《落花生》→花生植株带豆荚（豆荚里写种/收/尝/议）；《圆明园》→残柱废墟

### B. 思维导图（默认用于说明/方法/习作/口语交际）

- 中心1个圆圈写核心主题词，向外放射3-4条分支
- 每条分支末端1个关键词，分支用不同颜色
- 关键词之间用箭头体现递进/因果关系

## 不同课型的呈现方式

#### 1. 精读阅读课
- 中心视觉=手绘情境图
- 关键词用流程图（情节箭头）+ 关联词（手法→效果）围绕情境图分布
- 底部=红色题眼字+短句
- **板面不写"内容""手法"等标签**

#### 2. 习作指导课
- 中心视觉=思维导图（中心主题词+方法分支）
- 关键词用分支+箭头连接（如：提纲→分段→写具体）
- 底部=红色题眼字+短句

#### 3. 口语交际课
- 中心视觉=思维导图（中心主题词+方法分支）
- 关键词用放射分支呈现
- 底部=红色题眼字+短句

#### 4. 古诗词教学
- 中心视觉=手绘情境图（诗意意象）
- 关键词用箭头串联诗句核心意象
- 底部=红色题眼字+情感短句

## 完整执行流程

### 阶段1：读取教材，提取课文核心内容
1. 用PDF读取工具打开电子教材PDF，定位到指定课文
2. 提取：课题、作者、主要内容、写作手法、关键意象、主旨道理、人物形象
3. 若有教师用书PDF，提取教学重难点融入设计

### 阶段2：内部三维提炼（板面不标注维度）
1. **内容关键词**：提炼情节线（2-5字节点，箭头串联，≤5个节点）+ 品质/特点词（≤3个）
2. **手法关联词**：1-2个"手法→效果"关联词（如"借物→喻人"），用粉色粉笔
3. **主题关键词**：1个题眼字 + 1句≤15字主旨
4. **字数校验**：关键词合计≤35字 + 底部≤15字 = 全板≤50字

### 阶段3：选择中心视觉，设计可视化布局
1. 根据文体选择中心视觉（情境图 / 思维导图）
2. 确定关键词之间的连接方式（流程图箭头/因果箭头/放射分支/对比连线）
3. **确认板面不出现"内容""手法""主题""写作方法"等维度标签**
4. 确定底部题眼字和主旨短句

## 板书内容设计原则

1. **关键词化**：只写关键词，不写完整句子（底部主旨除外）；每词2-5字
2. **无标签化**：板面上不写"内容""手法""主题"等分类标签，用箭头和颜色自然区分
3. **关联词化**：关键词之间用箭头连接，形成"借物→喻人""辉煌→毁灭"等关联词
4. **可视化**：用流程图、箭头、思维导图、圆圈、线条等呈现逻辑关系
5. **精简**：全板≤50字（不含课题作者和底部主旨）
6. **点题**：底部红色题眼字+短句是灵魂
7. **可照抄**：老师5分钟内能画到黑板上

### 板书内容提炼checklist
- [ ] 课题序号和标题
- [ ] 作者
- [ ] 中心视觉（情境图/思维导图）
- [ ] 情节线关键词（箭头串联，≤5个节点）
- [ ] 品质/特点关键词（≤3个）
- [ ] 手法关联词（1-2个"手法→效果"）
- [ ] 题眼字（1个）
- [ ] 主旨短句（≤15字）
- [ ] **板面无维度标签**（不出现"内容""手法""主题"等词）
- [ ] **字数校验**：关键词≤35字 + 底部≤15字 = ≤50字

---

## 内容质量标准

1. **风格还原度**：像真实老师在黑板上用彩色粉笔写的，不是PPT/印刷海报
2. **关键词纯度**：无完整句子（底部主旨除外），全是2-5字关键词
3. **无标签化**：板面上不得出现"内容""手法""主题""写作方法""审题""写法"等分类标签
4. **关联词化**：关键词之间有箭头/线条连接，不是孤立罗列
5. **字数合规**：全板≤50字（不含课题作者和底部主旨）
6. **文字准确性**：课题、作者、关键词与教材一致，无错别字
7. **布局合理性**：中心视觉突出，关键词围绕中心分布，底部点题醒目

## 调用示例

> 用户输入：帮我设计《落花生》的板书
>
> 技能流程：
> 1. 提取《落花生》：许地山作，借物喻人，种收尝议，道理"做有用的人"
> 2. **内部三维提炼**（板面不标注维度）：
>    - 内容：种→收→尝→议；朴实·有用（10字）
>    - 手法：借物→喻人；对比→突出（8字）
>    - 主题：题眼"用"；做有用的人（7字）
>    - 合计25字，远低于50字上限
> 3. 中心视觉=手绘情境图（花生植株带豆荚，豆荚里写种/收/尝/议）
> 4. 关键词用箭头串联，围绕花生植株分布，板面无"内容""手法"标签
> 5. 调用seedream_5.0_pro生成9:16板书图
> 6. 交付图片

> 用户输入：帮我出《将相和》的板书
>
> 技能流程：
> 1. 提取《将相和》：司马迁《史记》，完璧→渑池→不和→请罪
> 2. **内部三维提炼**：
>    - 内容：完璧→渑池→不和→请罪；知错就改·机智勇敢（16字）
>    - 手法：伏笔→照应（4字）
