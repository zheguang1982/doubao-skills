# 配置结构说明 (config-schema)

`config.json` 是技能的唯一数据源。产物 HTML 是一次性生成物，**改配置重新生成**，不要手工编辑产出的 HTML。

## 字段总览

| 字段 | 必填 | 说明 | 默认值 |
|---|---|---|---|
| `event_name` | ✅ | 讲座主题（活动名） | — |
| `topics` | ✅ | 实践方向，1~6 项数组 | — |
| `guest` | — | 嘉宾姓名（邀请谁） | `嘉宾`（占位） |
| `event_date` | — | 日期，格式 `YYYY-MM-DD`，只支持单个确定日期；不填则显示"日期待定" | `待定` |
| `time` | — | 开始时间 | `19:30` |
| `brand` | — | 主办方 / 工作室名 | `豆包` |
| `session` | — | 场次名（屏1小标签、屏4标题、票根"场次"行共用）；**留空 `""` 则不显示场次**：屏1只剩主办方、屏4标题简化为"想参加什么？"、票根不再出"场次"行 | `专题讲座` |
| `role` | — | 称谓：嘉宾 / 讲师 / 主播 / 老师…（同步影响屏1标签、票根身份） | `嘉宾` |
| `slogan` | — | 信息卡大字，活动的一句话主张，不是活动名重复 | `这一天，为你而来` |
| `invite_line` | — | 邀请语，一句话说清值得来的理由 | `一场只聊实战的分享，位置给你留着。` |
| `signature` | — | 落款，以邀请人视角、口语化 | `负责给你搭台的我` |
| `invite_title` | — | H5 顶部醒目标题（屏1大标题 + 页面 title） | `讲座邀请函` |

## topics 数组示例

```json
"topics": [
  {"name": "AI 备课", "desc": "十分钟备好一节课"},
  {"name": "课堂互动", "desc": "AI 助手的实时应用"},
  {"name": "作业批改", "desc": "AI 批改效率翻倍"}
]
```

- `name`：选项卡标题，必填
- `desc`：6~12 字，写"讲了能得到什么"，而不是重复标题；可选
- 3 个左右观感最好；给到 4 个以上时，最后一项适合放"我全都要"这类兜底

## 完整示例

```json
{
  "guest": "王老师",
  "event_name": "AI 赋能语文教学",
  "event_date": "2026-10-16",
  "time": "19:30",
  "brand": "刘飞飞名师工作室",
  "session": "专题讲座",
  "slogan": "让 AI 成为课堂的得力助手",
  "role": "讲师",
  "invite_line": "一场只聊实战的 AI 教学实践分享，主讲位留给你。",
  "signature": "负责给你搭台的我",
  "topics": [
    {"name": "AI 备课", "desc": "十分钟备好一节课"},
    {"name": "课堂互动", "desc": "AI 助手的实时应用"},
    {"name": "作业批改", "desc": "AI 批改效率翻倍"}
  ]

```

## 日期处理约定

- 星期由脚本按真实日历自动计算，**不要手写**——页面上是确定好的一天，对方只能确认不能改期。
- `event_date` 支持三种形态：
  - `YYYY-MM-DD`（如 `2026-10-16`）：完整日期，自动算星期
  - `YYYY-MM-XX`（如 `2026-10-XX`）：**X 占位日**——月份确定、具体日未定时用，屏1/屏5 显示"2026年10月X日（星期待定）"，屏3 大日期卡显示"10月 / X / 星期待定"；确定具体日后改成完整日期重新生成即可
  - 缺失或 `待定`：屏1/屏3/屏5 统一显示"日期待定 / 时间待定"占位，产物仍完整可用
- 月份 / 日 / 星期会分别填入屏3的大日期卡。
- `time` 可写具体时间，也可写相对说法（如"课服第二节""放学后"），会原样拼进日期行。

## 校验行为（脚本内置）

- 必填字段缺失 → 报错退出
- 模板缺锚点 / 替换后残留锚点 → 报错退出
- 产物含外部 http/https 引用 → 告警（外部引用应为 0）
- 产物回读与内存不一致 → 报错退出
