# 手绘淡彩课件制作

基于参考图风格（手绘钢笔线稿 + 淡彩水彩上色），为教学课件生成完整PPT。用户提供课件主题和内容后，自动梳理大纲、直接批量生成全部页面配图、合成飞书幻灯片并交付。每页都是一张带有可视化图像的知识图解（可包含人物、图标、结构图、思维导图、装饰品等灵活元素），并配有可直接照读的演讲者备注。

## 风格核心特征

- **画风**：手绘钢笔线稿 + 淡彩水彩上色，黑色清晰轮廓线，低饱和度水彩晕染，白色/米白干净背景
- **配色**：主色橙色（强调、箭头、重点文字）+ 黑色线稿 + 棕色/深灰文字，少量蓝色/绿色/粉色辅助
- **可视化元素（灵活配置）**：
  - **人物**：可选固定女教师形象（黑色短发波波头、圆框眼镜、橙色连衣裙、黑色高跟鞋），也可用学生、古人、卡通角色等，甚至可以没有人物
  - **图标**：简约线稿图标，每个概念配一个具象物品
  - **结构图**：阶梯图、流程图、循环图、对比图、层级图等
  - **思维导图**：中心发散式、树状分支式、放射状等
  - **装饰品**：植物、文具、星星、气泡、箭头、下划线等手绘装饰
- **文字**：手写体风格，棕色/橙色，用箭头/引线连接图标，标题左上角黑色大字+橙色下划线，概念标注简洁（2-8字）
- **页面类型**：
  - **封面页**：大标题+可视化主视觉（人物/书籍/装饰元素）
  - **目录页**：阶梯式/卡片式目录+装饰元素
  - **内容页**：左上角标题+可视化主体（人物/结构图/思维导图）+周围概念图标+手写标注+箭头
  - **章节引题页**：左侧大标题+右侧可视化元素（问号/放大镜/人物/装饰），留白多
  - **小结页**：环形/道路式/思维导图式总结+关键词标签
  - **结尾页**：大标题+温暖可视化元素（人物/孩子们/植物/装饰）

## 完整工作流程

### Step 1 · 内容解析与大纲规划

用户提供主题和内容后，先梳理：
- **确定页数**：用户指定则以用户为准；未指定则由AI根据主题深度、内容量、受众需求自主确定合理页数（简短主题8-12页，中等主题15-20页，复杂主题20-30页或更多），不强制固定页数，并说明页数规划理由
- **梳理结构**：按逻辑分为导入/正文/收束，正文可分多个板块，每个板块有引题页+内容页+小结页
- **每页内容**：确定每页标题、核心概念（2-6个）、每个概念对应的具象图标、手写标注文字
- **演讲者备注**：为每页准备3-5句可直接照读的讲稿

输出一份轻量大纲（可在思考中完成），格式：
```
第N页 - 页面类型 - 标题 - 核心概念列表 - 备注要点
```

### Step 2 · 批量生成配图

- **模型**：使用 `image_gen` 工具，`model_version=seedream_5.0_pro`
- **尺寸**：16:9 横版，width=2048, height=1152
- **直接批量生成全部**：每次调用最多传6个request，分多批一次性生成全部页面，不需要先出样确认
- **Prompt 规范**：每个Prompt必须包含：
  1. 画风描述："16:9横版知识图解插画，钢笔线稿+淡彩水彩手绘风格，纯白色背景"
  2. 页面类型与标题："左上角手写体大标题"XXX"，下方橙色手绘下划线"
  3. 可视化主体（灵活选择）：根据内容选择人物/结构图/思维导图/装饰元素作为画面主体，有人物时描述其动作表情，无人时描述结构图或思维导图的布局
  4. 构图与内容：周围概念图标分布+手写标注+箭头线连接
  5. 配色："暖橘色+深蓝+浅蓝+米黄，黑色钢笔线稿，淡彩水彩透明感，手绘风格，画面留白充足"
- **文字标注**：Prompt中需要生成的文字用中文引号""标注
- **可视化要求**：每页必须有可视化图像元素（人物/图标/结构图/思维导图/装饰品至少一种），禁止纯文字页

### Step 3 · 下载图片到本地

- 创建工作目录（如 `ppt_<主题>/images/`）
- 用 `Invoke-WebRequest` 或 `curl` 将所有生成图下载到本地，命名为 `01.png`、`02.png`...（两位数序号）
- Windows PowerShell 不支持 `&` 后台语法，用 `for` 循环逐个下载

### Step 4 · 创建/准备飞书幻灯片

- **新建PPT**：`lark-cli slides +create --title "<课件标题>"`，获取 `xml_presentation_id` 和 `url`
- **编辑已有PPT**：先回读获取所有 `slide_id`，然后逐个删除旧页面（`+delete-slide`），准备空PPT
- 用 `present_files` 发送开工通知

### Step 5 · 上传图片获取 file_token

- 逐个上传：`lark-cli slides +media-upload --presentation <id> --file images/NN.png`
- 记录每个文件的 `file_token`，保存为 `序号=token` 的映射
- 可批量循环上传，注意超时（单张约2-5秒）

### Step 6 · 生成每页 XML

每页XML结构极简（全屏图片+演讲者备注）：
```xml
<slide>
  <data>
    <img src="<file_token>" topLeftX="0" topLeftY="0" width="960" height="540"/>
  </data>
  <note>
    <content textType="body">
      <p>3-5句可直接照读的演讲者备注</p>
    </content>
  </note>
</slide>
```

- 图片是16:9（2730x1536），PPT画布是960x540（也是16:9），比例对齐不裁剪，完整显示
- 用Python脚本批量生成XML文件（避免PowerShell here-string引号转义问题），参考 `scripts/gen_slides_xml.py`
- 每页XML存为 `new_slide_NN.xml`

### Step 7 · 逐页校验并写入

- **静态校验**：每页XML先跑 `python xml_lint.py --input new_slide_NN.xml`，`error_count` 必须为0
- **写入幻灯片**：`lark-cli slides +add-slide --presentation <id> --slide "@new_slide_NN.xml"`
- 可先校验1页确认格式正确，然后批量循环写入剩余页面
- 记录每页返回的 `slide_id`

### Step 8 · 全文回读校验与交付

1. **回读全文**：`lark-cli slides +xml-get --presentation <id> --output final_deck.xml`
2. **全文校验**：`python xml_lint.py --input final_deck.xml`，确认 `slide_count` 正确、`error_count=0`
3. **成稿交付**：用 `present_files` 交付最终幻灯片链接，附制作介绍（页数、结构、风格、亮点）

### Windows 环境注意事项

- PowerShell 不支持 `&` 后台运行语法，用 `for` 循环或 `Start-Job`
- 批量生成XML用Python脚本文件，不要用 `python -c @"..."@`（here-string会吃掉属性引号）
- 中文路径和文件名正常支持
- 长任务（批量上传/写入）会自动移到后台，用 `TaskOutput` 等待完成

### lark-cli 关键命令

```bash
# 创建空白PPT
lark-cli slides +create --title "标题"

# 上传图片
lark-cli slides +media-upload --presentation <id> --file <path>

# 添加页面
lark-cli slides +add-slide --presentation <id> --slide "@file.xml"

# 删除页面
lark-cli slides +delete-slide --presentation <id> --slide-id <slide_id>

# 回读全文
lark-cli slides +xml-get --presentation <id> --output <file>

# 静态校验
python <skill_path>/scripts/xml_lint.py --input <file>
```

## 约束

- 严格遵循手绘钢笔线稿+淡彩水彩风格，不擅自改变画风、配色
- 每页必须有可视化图像元素（人物/图标/结构图/思维导图/装饰品至少一种），**禁止纯文字页**
- 人物形象灵活配置：可用固定女教师形象，也可用其他人物，甚至可以没有人物，根据内容需要选择
- 每页左上角必须有标题+橙色下划线（章节引题页和结尾页除外）
- 概念数量控制在2-6个，过多时建议拆分或合并
- 文字标注简洁（2-8字），避免长句，防止生图文字乱码
- 使用 `image_gen`（Seedream 5.0 Pro）直接批量生成全部页面，不需要先出样确认
- 默认16:9横版（width=2048, height=1152），除非用户明确要求其他比例
- 每页必须有3-5句演讲者备注
- 全文必须通过静态校验（error_count=0）才能交付
