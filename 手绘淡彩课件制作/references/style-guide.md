# 手绘淡彩课件配图 · 风格指南与 Prompt 模板

本文件是生成配图时的详细参考依据，包含画风规范、配色、角色、两种构图类型的完整 Prompt 模板。

---

## 一、画风详细规范

### 线稿
- 黑色钢笔手绘线，线条有轻微抖动感（不完全笔直），模拟手绘质感
- 轮廓线较粗（1.5-2px），内部细节线较细（0.5-1px）
- 所有物体都有清晰闭合轮廓，无断线

### 上色
- 淡彩水彩风格，颜色饱和度低，有水彩晕染和纸纹质感
- 填充不均匀，有自然的深浅变化和留白
- 阴影用同色系加深，不用纯黑阴影
- 高光用留白或白色水彩点

### 背景
- 纯白或极浅米白色（#FAFAF7），干净无杂物
- 无渐变背景、无纹理背景、无装饰边框

## 三、角色规范（固定形象）

**核心特征（必须全部保留）：**
- 女性，25-35岁，亲切微笑表情
- 黑色短发波波头（齐下巴长度，发尾微内扣）
- 圆框眼镜（黑色细框）
- 橙色连衣裙（短袖，及膝长度，A字版型）
- 黑色高跟鞋（细跟，5-7cm）
- 肤色白皙，脸颊有淡淡红晕

**动作根据构图变化：**
- 阶梯递进式：正在向上爬楼梯，一只脚踩在上一级台阶，一只手向前伸，身体微微前倾，目光向上
- 中心辐射式：站立在画面中心，双臂向两侧平伸张开，手掌朝前，身体正面朝向观众

## 四、阶梯递进式构图 · Prompt 模板

**适用场景**：层级、递进、发展、从低到高、从基础到前沿、时间演进、能力进阶

**画面结构**：
- 标题在左上角，黑色大字
- 楼梯从左下角向右上角延伸，共 N 级台阶（N=概念数量，3-5级为宜）
- 角色在楼梯中下部，正在向上爬
- 每级台阶上放一个对应概念的具象物品图标
- 每级台阶旁用棕色手写体标注概念名称（2-6字）
- 橙色箭头从左下指向右上，表示递进方向
- 台阶侧面可标注层级说明（如"基础层""进阶层""前沿层"）

**完整 Prompt 模板（填充占位符后使用）：**

## 五、中心辐射式构图 · Prompt 模板

**适用场景**：分类、并列、维度、围绕中心展开、多方面展示

**画面结构**：
- 角色站立在画面正中心，双臂向两侧平伸张开
- 从中心向四周（左上、右上、左下、右下，或更多方向）辐射出 N 个概念
- 每个方向有一个具象物品图标 + 棕色手写体概念名称
- 橙色箭头从中心角色指向每个图标，表示关联
- 中心左侧或下方可标注总主题名称
- 角色下方可有水滴形标签（可选，标注品牌/来源）

## 六、文字规范

- **标题**：左上角，黑色，较大字号（约占画面高度1/15），可用破折号连接主副标题
- **概念标注**：棕色手写体，2-6个字，位于图标旁边，用箭头或引线连接
- **层级说明**：棕色小字，位于台阶侧面或图标下方，可稍长（8-15字）
- **总主题**：中心左侧，棕色较大字体，概括全部内容
- **所有文字必须用中文引号""标注在 Prompt 中**，防止生图模型忽略

## 七、图标选择指南

每个概念必须配一个**具象、可识别**的物品图标，避免抽象图形：

| 概念类型 | 推荐图标 |
|---------|----------|
| 科技/AI | 电脑、服务器、机器人、芯片、卫星 |
| 生活应用 | 手机、平板、家电、日用品 |
| 学习/教育 | 书本、铅笔、灯泡、毕业帽 |
| 自然/环境 | 树叶、水滴、地球、太阳 |
| 交通/出行 | 汽车、自行车、飞机、地图 |
| 商业/经济 | 钱币、购物袋、商店、图表 |
| 人物/社交 | 人物头像、对话气泡、握手 |
| 时间/进程 | 时钟、日历、箭头、阶梯 |

图标风格必须统一：线稿+淡彩，与整体画风一致。

## 八、常见问题与调整

| 问题 | 调整方法 |
|------|----------|
| 文字乱码/缺失 | 缩短文字（≤6字），用中文引号标注，在 Prompt 中强调"文字清晰可读" |
| 角色形象不一致 | 在 Prompt 中重复角色核心特征（眼镜、波波头、橙裙、高跟鞋），使用参考图模式 |
| 颜色太艳/不像水彩 | 强调"低饱和度""水彩晕染""纸纹质感""淡彩"，降低颜色描述的饱和度 |
| 概念太多挤不下 | 建议合并为3-5个核心概念，或拆成两张图 |
| 背景不干净 | 强调"纯白背景""无装饰""无渐变""无纹理" |
| 线条太直不像手绘 | 强调"手绘抖动感""钢笔手绘线""不完全笔直" |

## 九、生图工具调用参数

- **工具**：`image_edit`（参考图模式）
- **模型**：`seedream_5.0_pro`
- **参考图**：阶梯递进式用 `assets/参考图1-阶梯递进式.png`；中心辐射式用 `assets/参考图2-中心辐射式.png`
- **尺寸**：width=2048, height=1152（16:9）
- **Prompt 原则**：参考图已保证画风，Prompt 聚焦描述内容变化（标题、概念、图标、布局），不重复描述画风
