# 付老师·语文备课一条龙Skill
> 版本：v2.0.0 — 理论升级：以**马扎诺教育目标分类法**锚定教学目标、以**韦伯知识深度框架（DOK）**标定课堂活动认知复杂度、以**SOLO分类法**刻画学习结果理解层级，形成"目标—活动—评价"一致性闭环；最终物料包交付为 Word(.docx)；完整教案须详实、以"任务—关键活动"组织教学（非列表骨架），多课时分别产出独立完整教案；文件排版规范（详见"格式与排版规范"）。

## 技能标识
`语文备课一条龙`

## 适用场景
统编版中小学语文常规备课（支持 1 课时或 2 课时），适配一线语文教师快速产出全套可落地教学物料，尤其适合基础中等偏弱、专注力持续短、对长文本有畏难情绪的班级，主打「情境化任务+小组互动+轻量游戏」的教学风格。本技能不只是"出教案"，而是以当代学习科学三大经典分类框架为骨架，让每一课的目标可测、活动可辨、评价可依。

## 核心功能
用户仅需输入 **「教材课题信息 + 班级学情说明」** 两项素材，即可一键生成完整闭环备课物料包（支持 1 课时或 2 课时；多课时时每份课时教案独立、完整、含各自板书与讲课稿），**最终交付物为排版规范的 Word（.docx）文件**（含全部九大模块），并配套自动生成的可编辑教学课件 PPT；全程无需分步指令；自动沿用《背影》备课的统一排版、内容深度与设计风格，支持成果自动归档与历史版本回溯。

## 理论基石：三大框架如何串成一条闭环

> 本技能的所有教学设计决策，都必须能在以下三个框架中"对号入座"。这不是装饰性理论名词，而是每一份物料的内在骨架：**目标写清楚要激活马扎诺的哪个认知层级；活动标清楚学生要走到DOK的哪一层；评价用SOLO五级量规判断学生理解到了哪一步。**

### 一、马扎诺教育目标分类法（Marzano's New Taxonomy）——锚定"目标"层

马扎诺将人的学习分为**三个系统 + 一个知识领域**，由高到低、由动机到认知：

| 系统层级 | 核心功能 | 在语文课中的典型表现 |
|---|---|---|
| **自我系统** | 判断"值不值得学"：重要性、效能感、情感反应、学习态度 | 导入激趣、联结生活经验、让学生感到"这课与我有关"、树立"我能读懂"的信心 |
| **元认知系统** | 设定目标、监控过程、检查清晰度与准确性 | 让学生明确本课要解决的核心问题、边读边自问"我读懂了吗"、批注后自评"我的理由站得住吗" |
| **认知系统·信息提取** | 从长时记忆中调取信息（再认、回忆、执行） | 读准字音、默写词语、回忆课文主要情节、背诵关键句 |
| **认知系统·领会** | 以摘要、表征方式建构意义 | 概括段意、用自己的话复述、画思维导图、辨别关键信息与无关信息 |
| **认知系统·分析** | 探究信息结构：匹配、分类、错误分析、概括、具体化 | 赏析写法、比较人物、辨析词义、评价选材、发现矛盾处并追问 |
| **认知系统·知识应用** | 在具体情境中运用知识：决策、问题解决、实验、调查 | 仿写片段、改写结局、扮演角色回应、为课文人物写一封信、跨文本迁移写作 |
| **知识领域** | 学习的内容本身 | 信息类知识（字词、文体、主旨）、心智技能（朗读方法、批注方法、概括方法）、动作技能（书写、朗诵体态） |

**使用要求**：阶段2撰写教学目标时，每条目标必须标注其主导激活的马扎诺系统（如"【马扎诺·认知系统-分析】学生能够……"），确保目标不是口号，而是明确指向某一类可观察的心智操作。自我系统目标负责"把学生拉进课堂"，元认知目标负责"让学生学会监控自己的理解"，认知系统目标负责"让学生走到学科思维的深处"。

### 二、韦伯知识深度框架（Webb's Depth of Knowledge, DOK）——标定"活动"层

DOK描述的是**学生完成一项任务所需要的思维复杂度**，而不是任务的难易度。课堂活动必须至少覆盖 DOK1 与 DOK2，并视学情与文体酌情进入 DOK3、DOK4：

| DOK层级 | 名称 | 语文课堂典型活动 | 在本技能中的落点 |
|---|---|---|---|
| **DOK 1** | 回忆与复述（Recall & Reproduction） | 看拼音写词语、朗读课文、背诵指定段落、说出课文写了哪几件事、解释关键词义 | 破冰导入、字词过关、默读圈画、情节梳理 |
| **DOK 2** | 技能与概念（Skills & Concepts） | 概括段意、比较两个语段异同、用自己的话复述、梳理写作顺序、找中心句、做简单批注 | 内容梳理、词句品读、思维导图、小组讨论 |
| **DOK 3** | 策略性思维与推理（Strategic Thinking） | 赏析某个细节为何传神、推断人物未说出口的心理、评价作者的选择、跨段落综合论证一个观点、有依据地反驳一种解读、仿写并说明理由 | 核心探究、人物形象分析、主旨提炼、写法鉴赏、课堂辩论 |
| **DOK 4** | 扩展性思维（Extended Thinking，选做） | 长周期研究：比较同类题材多篇作品、为课文人物写小传、跨媒介改编（如把散文改成剧本）、结合时代背景做小课题 | 拓展档作业、研究性学习、单元整体项目 |

**使用要求**：阶段4教案中，每一个"关键活动"必须在小标题后用括号标注其DOK层级，例如：**关键活动二：品读"背影"细节，体会克制的深情（DOK3）**。整堂课的活动序列应呈现 **DOK1 → DOK2 → DOK3 的爬升**，杜绝整节课停留在DOK1的"问答+齐读"低阶循环；对基础偏弱的班级，DOK3活动必须用DOK1/DOK2搭台阶，不做空中楼阁。

### 三、SOLO分类法（Structure of the Observed Learning Outcome）——刻画"评价"层

SOLO描述学生在回答一个开放性问题时，其反应结构所处的层级，从低到高共五级：

| SOLO层级 | 名称 | 学生表现（以语文课堂为例） | 课堂识别信号 |
|---|---|---|---|
| **前结构 P** | 未达 / 误解 | 答非所问、照搬原文却不理解、把字面意思读错、用常识歪曲文本 | 回答与问题无关，或出现事实性错误 |
| **单一结构 U** | 单点抓取 | 只找到一个细节就下结论；只会念原文某一句；说"我觉得感人"但举不出任何依据 | 回答只有一个孤立信息点，无展开 |
| **多元结构 M** | 多点罗列 | 能说出好几处细节，但彼此割裂；概括时堆砌事件却不讲关系；批注只写"用了比喻" | 信息点有多个，但点与点之间没有连接 |
| **关联结构 R** | 整合贯通 | 能把多个细节串联起来解释一个人物/一种情感；能说出写法与主旨之间的因果；概括完整且抓住主线；批注能"由词及情" | 回答形成内在逻辑，细节服务于整体判断 |
| **扩展抽象 EA** | 迁移升华 | 能由这一篇联想到同类作品、作者其他篇目或自己的生活；能抽象出可迁移的文学规律；能对文本作出合理的个性化评价并自圆其说 | 超越文本本身，走向一般化或迁移 |

**使用要求**：阶段8课堂小测与阶段6作业中，凡涉及简答、赏析、仿写、表达类题目，必须配套一张**SOLO五级评价量规表**（见"格式与排版规范"），让教师一眼判断学生答案落在哪一层、该往哪里推。本技能的课堂目标默认指向**关联结构（R）**为及格线，鼓励学有余力者向**扩展抽象（EA）**攀爬；对基础偏弱的班级，先稳在多元结构（M）向关联结构（R）过渡。

### 四、三框架如何对齐（一致性闭环）

```
马扎诺（目标层）          韦伯DOK（活动层）           SOLO（评价层）
─────────────────      ─────────────────      ─────────────────
自我系统·激趣   ──→   DOK1 回忆/复述    ──→   前结构P / 单一结构U
认知·信息提取   ──→   DOK1 回忆/复述    ──→   单一结构U
认知·领会       ──→   DOK2 技能/概念    ──→   多元结构M
认知·分析       ──→   DOK3 策略思维     ──→   关联结构R
认知·知识应用   ──→   DOK3 / DOK4       ──→   扩展抽象EA
元认知·监控     ──→   贯穿全程的自评    ──→   对照量规自我定位层级
```

每一份备课物料都必须能回答三个问题：
1. **目标**：这节课要把学生的自我/元认知/认知系统激活到马扎诺的哪一层？
2. **活动**：每个关键活动把学生推到了DOK的哪一级？活动序列是否有爬升？
3. **评价**：用SOLO量规，什么样的回答算U、算M、算R、算EA？

## 输入规范
调用时需用户提供以下2项核心信息，缺失时主动询问：
1. **教材课题**：明确统编版教材学段、册数、单元、课文名称（例：统编版八年级上册第四单元《背影》；或：统编版四年级下册第一单元《乡下人家》）
2. **班级学情**：班级整体基础水平、专注力特点、核心学习难点等（例：基础中等偏弱、专注力短、大半学生对长课文有畏难情绪）

> 如用户未说明课型（阅读课 / 习作课 / 识字写字课 / 口语交际课 / 略读课），默认为**精读阅读课**；如为习作或口语交际课，活动设计与SOLO表现描述须相应调整（习作课侧重"构思—起草—修改—互评"的写作认知过程，识字课侧重"音—形—义—用"的DOK1/DOK2夯实）。

## 完整执行流程
全流程共9个标准输出模块，按顺序自动依次生成，无需用户分步触发；其中教材信息、课标对应环节自动调用通用搜索工具核验准确性。全部文本物料先组织为一份结构化 Markdown（作为可编辑源文件），最后由 `scripts/build_docx.py` 统一转换为排版规范的 **Word（.docx）物料包**，PPT 课件作为配套文件一并产出。

### 阶段1：教材分析模块
1. 调用 `general_search` 工具，核验对应课文的统编版教材单元定位、单元语文要素、《义务教育语文课程标准（2022年版）》对应学段要求，引用2022年版语文课程标准中对应学段、学习任务群的相关表述，并说明与本课的关联。
2. 单元位置：本课所在单元主题、语文要素、单元内篇目关系及前后勾连。
3. 梳理本课核心知识点：字词基础、文体特征、核心写法、情感主旨四大维度。
4. 明确教学重点、教学难点，区分课时可落地目标与长期素养目标。
5. **理论预判（新增）**：基于文体与学情，预设本课DOK爬升路线（如"以DOK2为主，核心探究段落进入DOK3"），并标注本课最典型的SOLO期望层级（默认R层），作为阶段2—阶段8设计的总蓝图。
6. 结构化输出：课标对应要求 → 单元位置 → 核心知识点 → 教学重难点 → 本课DOK/SOLO理论定位。

### 阶段2：教学目标与学科大概念
#### 2.1 教学目标（马扎诺框架 + 核心素养双标注）
依据2022年版语文课程标准，按**核心素养四个维度**（文化自信、语言运用、思维能力、审美创造）拆分，同时每条目标必须标注其**主导激活的马扎诺系统层级**。

每条目标必须：
- 使用可观测、可测评的行为动词（如：能说出、能概括、能分析、能比较、能仿写、能评价、能监控并修正自己的批注等）。
- 指向具体知识点或能力点。
- 避免空泛表述。
- **必须包含至少1条自我系统目标**（让学生感到重要/有趣/与我有关）和**1条元认知目标**（让学生学会监控自己的理解过程），其余为认知系统目标。

**格式要求**：以核心素养维度为小标题，每个维度下列1—3条目标，每条以"学生能够……"开头，并在句末用方括号标注马扎诺层级，例如：

> - 学生能够通过圈画文中"望父买橘"的动作描写，说出父亲背影中蕴含的克制与深情。**【马扎诺·认知系统-分析】【核心素养·审美创造】**
> - 学生能够在批注过程中边读边自问"我这个判断有没有原文依据"，并至少修正一处自己初读时的想当然判断。**【马扎诺·元认知系统】【核心素养·思维能力】**
> - 学生能够联系自己与父亲之间一件说不出口的小事，体会"爱不一定用语言表达"的普遍经验。**【马扎诺·自我系统】【核心素养·文化自信】**

#### 2.2 学科大概念
- 结合本课知识点，提炼**1—2个学科大概念**（如：叙事散文通过细节描写与情感聚焦表达深沉情感）。
- 用简洁语言说明该大概念如何串联本课各小节知识，并对应到马扎诺认知系统的"分析"层——大概念不是知识点的拼盘，而是学生分析课文时可以反复调用的思维工具。
- 提供**学生版解读话术**：用通俗易懂的语言向学生解释这一大概念，便于课堂直接使用。

**格式要求**：以「大概念名称 + 串联逻辑（马扎诺分析层如何使用这把钥匙）+ 学生版话术」三段式呈现；学生版话术用引用块标注，语言口语化、可直接念给学生听，避免术语堆砌。

### 阶段3：学情适配设计思路
1. 基于用户提供的学情，针对性设计整体教学策略，核心遵循「化长为短、情境代入、任务驱动、小组互助、高频互动」四大原则。
2. 固定采用「总情境任务+分关卡闯关」的模式，拆解长课文为多个8-10分钟的小任务，降低畏难情绪。
3. 明确小组分工机制，设置不同难度任务适配不同水平学生，保障全员参与。
4. **DOK分层设计（新增）**：同一任务内设计"基础版（DOK1—DOK2，保底全员）/进阶版（DOK2—DOK3，鼓励中等以上）/挑战版（DOK3—DOK4，供学有余力者）"三档出口，让不同水平学生都能在自己的最近发展区内向上攀爬一级。
5. **SOLO预判（新增）**：根据学情预估班级典型落点——基础偏弱班典型预期为"多元结构M向关联结构R过渡"，基础中等班预期"稳在R层"，较好班预期"部分学生可达EA层"；此预判贯穿作业与小测量规设计。

### 阶段4：完整教案生成（按实际课时数，每课时45分钟，内容须详实）

> 本阶段严格参照《藤野先生》备课包的完整教案写法：**以"任务"为教学单元、任务下设计"关键活动"、全程叙述性散文体、严禁清单/表格骨架**；若本课为 **2 课时**，须产出**两份各自独立、完整**的课时教案（各自任务、各自板书、各自讲课稿）。**每一个关键活动必须在小标题后用括号标注其DOK层级与对应马扎诺层级**，让理论骨架显性化。

1. **课时判定与呈现**：先明确本课课时数——默认 1 课时；用户输入"2课时/两课时"或课文体量大、需分课时落实时，按 **2 课时**处理。每个课时独立产出一份**完整教案**，不合并、不互代；多课时时依次以「第一课时教学过程（45分钟）」「第二课时教学过程（45分钟）」呈现，各含独立教学过程、板书设计与教师讲课稿。
2. **整体结构（详案，叙事体）**：每份课时教案按序展开——教学目标（含马扎诺标注）→ 教学方法 → 课堂走神应对话术预设 → 教学过程（分任务，每活动标DOK）→ 板书设计 → 教师讲课稿。**整份教案用连续叙述 + 任务组织，禁止把教案写成"环节目标/教师活动/学生活动"的清单或表格骨架**（任务内部个别说明性内容如"操作方式""设计意图"可用短句辅助，但全文主体必须是可读的散文叙述）。
3. **教学过程 = 多个"任务"串联，任务下设"关键活动"（叙事散文体，非列表）**：
   - 每课时把 45 分钟拆成 **4—5 个"任务"**（如：任务一·破冰导入 / 任务二·核心探究 / 任务三·人物形象提炼 / 任务四·小结铺垫），任务标题用四级标题并标注精准时长，如 `#### 任务一：破冰导入（8分钟）`。
   - **每个任务下设计 2—3 个相互关联、递进的关键活动**：活动是任务的分解步骤，前一活动为后一活动搭台阶，共同推进该任务的目标达成，各活动用时可不等分。
   - **活动必须提炼小标题并标注DOK层级，分段表述**：每个活动以加粗小标题起首，并在标题后括号内标注 **（DOKx / 马扎诺·xxx）**，例如：**关键活动二：品读"攀月台"动作链，体会克制的父爱（DOK3 / 马扎诺·认知系统-分析）**。小标题下用一段叙述散文展开，活动与活动之间以过渡句衔接，避免堆砌罗列。
   - **DOK爬升要求**：同一课时内，关键活动的DOK层级必须整体呈现 DOK1 → DOK2 → DOK3 的爬升曲线；前一个任务通常以DOK1/DOK2"打底"，核心探究任务进入DOK3，小结或迁移任务可短暂回落到DOK2以巩固。整节课不得全部停留在DOK1。
   - **每个任务环节末尾单独阐释"设计意图"**：以加粗 **设计意图：** 起句，用 1—2 句话点明该任务为何这样设计（对应哪条学情/目标、激活了马扎诺哪个系统、把学生推到了DOK哪一级），单独成段，醒目但不淹没在叙述中。
   - **每个活动内部用叙述性散文展开**，自然融入以下内容（不强行分条、不列空骨架）：
     - **情境 / 任务产出**：本活动做什么、怎么组织（小组/全班/同桌）、学生产出什么（名片、学习单、思维导图、批注卡等）；
     - **教师导语与关键提问**：直接写出可念出口的引导语、过渡语、由浅入深的问题链（**具体措辞**，严禁"引导学生思考"之类空话）；问题链本身应呈现DOK爬升：先DOK1的事实性问题，再DOK2的概括性问题，再DOK3的推理性/评价性问题；
     - **关键语段 / 预设与引导**：教师重点点拨的课文语段，以及对学生可能回答的预设与追问方向——**对每个学生回答预设其可能落在哪一SOLO层级**（如"若学生只说'父亲很爱儿子'而举不出细节，说明停在U层，需追问'哪一个动词让你读出了爱？'把他推向M层；若学生能把'攀''缩''倾'三个动作连起来说，即达R层"）；
     - **学生活动与产出**：学生具体做什么、怎么展示、用时多少；
     - **板书 / 笔记时机**：本活动在哪个节点在黑板或笔记上落点；
     - **走神应对**（按需）：该任务/活动易走神时，预设温和拉回话术。
   - 任务之间用**教师过渡语**自然衔接；任务末可用一两句"教师小结"收束，并向任务/下课时核心问题铺垫。
4. **板书设计**：每份课时教案末尾给出该课时「最终版板书」——脉络式纯文本结构，用代码块统一呈现（方便照抄黑板），并说明随课堂生成的落点；**2 课时时分别给出「第一课时板书」「第二课时板书」**。板书中应能看出DOK爬升的痕迹（如左侧是DOK1的字词与情节，右侧是DOK3的赏析与主旨）。
5. **教师讲课稿（详案配套，建议必出）**：课时教案后附「教师讲课稿」，按任务重写**可直接念出口**的导入语、过渡语、提问、小结与结语（含预设学生回答后的应对），与教学过程一一对应，供无备课基础时照着上。讲课稿中凡涉及追问，须写出"学生答到X层时，教师如何推他到Y层"的SOLO推进话术。
6. **互动与走神**：教学过程嵌入 2—3 个轻量课堂互动小游戏（在任务内的"关键活动"中展开）；问题链 4—5 个由浅入深、低门槛起步；走神应对预设默读、讨论、讲解三类场景的温和拉回话术，避免当众批评，以任务牵引、趣味钩子、个体轻唤为主。
7. **课时衔接（仅多课时）**：上一课时末尾须有"小结与铺垫/预习"，向下一课时核心问题自然过渡；下一课时开头以"复习导入"回扣上节课板书与遗留问题。

### 阶段5：配套课件PPT大纲
1. **风格标准**：活泼卡通风，柔和暖色调，圆角卡片式排版，适配初中生审美，避免沉闷。
2. **标准页数**：14-16页（如学情简单或课文短小可压缩至12页，如课文较长或为2课时可扩至18页，由AI根据实际内容自定，不机械套数），覆盖封面、学习目标、情境导入、闯关任务、游戏环节、知识点梳理、课堂练习、SOLO量规页、小结、作业全链路。
3. **理论显性化（新增）**：学习目标页须以"马扎诺层级"标签呈现目标；核心探究页须标注本页活动的DOK层级；课堂练习页须附对应SOLO层级提示，让课件本身就是理论框架的可视化。
4. **输出形式**：表格呈现，每页对应「核心要点 + 建议配图方向 + 理论标签（马扎诺/DOK/SOLO）」，互动游戏页单独标注规则与视觉设计方向。

### 阶段6：分层课后作业设计
1. 固定三档分层：基础档（全体必做）、提升档（中等及以上选做）、拓展档（学有余力选做）。
2. **DOK标注（新增）**：每一档作业须标注其对应DOK层级——基础档对应DOK1（字词、背诵、情节梳理），提升档对应DOK2—DOK3（概括、赏析、比较），拓展档对应DOK3—DOK4（迁移写作、小研究、跨文本比较）。
3. **提升档固定为同主题课外阅读迁移题**：配套短篇名家文段，设置内容概括（DOK2）、细节赏析（DOK3）、写法对比（DOK3）三类习题，实现课内到课外的能力迁移。
4. **SOLO作答预期（新增）**：每道简答题后标注"优秀作答应达到的SOLO层级"（如"本题R层为满分：能结合两处以上细节形成因果解释；仅罗列细节为M层"）。
5. 作业难度梯度清晰，避免重复机械训练，总量控制在20分钟以内。

### 阶段7：可打印知识点默写清单
1. **标准题型**：字词默写（看拼音写汉字，DOK1）、课文核心段落默写（DOK1）、核心知识点填空（DOK1—DOK2）。
2. **格式规范**：预留班级、姓名、得分栏，排版适配A4纸直接打印，题量控制在10-15题。
3. 内容100%匹配课堂教学重点，不超纲、不拓展，用于检测基础掌握情况——这是DOK1层的保底检测，不承担高阶思维评价功能。

### 阶段8：配套课堂小测卷 + SOLO评价量规
1. **题量与题型**：共10题，7道选择题 + 3道简答题，满分100分，建议用时15分钟。
2. **考点与DOK分布**：选择题覆盖字词基础（DOK1，约2题）、课文内容梳理（DOK2，约3题）、写法识别（DOK2，约2题）；3道简答题分别指向DOK2（概括，1题）、DOK3（赏析/推理，2题），确保小测卷本身也有认知深度分布，不全部停留在记忆层。
3. **SOLO五级评价量规（新增，必出）**：为每道简答题配一张SOLO量规表，明确前结构P / 单一结构U / 多元结构M / 关联结构R / 扩展抽象EA五级的语文行为表现描述与对应分值区间（详见"格式与排版规范"）。量规须结合本课具体内容（如"《背影》赏析题的R层描述为：能结合'攀''缩''倾'等多个动词，说明父亲动作的艰难与儿子的观察视角，两者形成因果"），不得使用空泛套话。
4. 同步生成**参考答案 + 按点赋分评分标准**，标注得分要点，支持教师快速批改。

### 阶段9：自动生成教学课件（.pptx，每次必做，含真实 AI 插图）
1. 在「阶段5：配套课件PPT大纲」产出大纲（每页「核心要点 + 建议配图方向 + 理论标签」）后，**自动**依据该大纲生成可编辑 PowerPoint 课件；与阶段1–8 物料一并完成，无需用户单独触发或额外操作。
2. **生成插图（自动扣积分，无需确认）**：对大纲每页「建议配图方向」调用图像生成工具（ImageGen，默认使用 seedream_5.0_pro）生成该页插图，保存至输出目录 `assets/`（如 `p01.png`）。依据下方「配图积分授权」规则，积分扣减一律自动同意，不弹窗、不询问；风格统一为活泼卡通 / 扁平教学插画，与暖色调定位一致；图片比例按用户偏好采用 9:16 竖版。
3. **组装**：调用 `scripts/build_pptx.py` 的 `build_courseware(lesson_title, outline, out_path, assets_dir="assets")`。引擎按四色系统（宣纸底 / 朱砂标题条 / 青墨列表点）渲染：封面页（居中大标题 + 插图）+ 内容页（标题条 + 左侧要点 ≤6 行 + 右侧真实插图）；插图缺失时自动回退为占位框，不中断。
4. **校验**：用 python-pptx 重新打开生成的 pptx，确认页数与大纲一致、文件可正常打开。
- 输出文件：`《<课题>》教学课件.pptx`，与备课物料同目录。
- 依赖：执行环境需 `python-pptx`（隔离虚拟环境已装；若缺失则 `pip install python-pptx`）。

### 阶段10：生成 Word 物料包（.docx，最终交付）
1. 九大模块文本先组织为一份**结构化 Markdown 源文件**（标题层级、表格、板书代码块、引用块均按"格式与排版规范"书写），作为可二次编辑的源。
2. 调用 `scripts/build_docx.py` 的 `build_docx(md_path, docx_path)`，将该 Markdown 转换为排版规范的 Word 文档（A4、宋体正文/黑体标题、表格边框+表头底纹、板书等宽底纹、引用块缩进底纹、SOLO量规表标准表头，详见"格式与排版规范"）。
3. **校验**：用 python-docx 重新打开生成的 docx，确认可正常打开、标题与表格数量与源文件一致。
4. 输出文件：`《<课题>》教学物料包.docx`，与课件 PPT 同目录，作为本次备课的**主交付物**。
5. 依赖：执行环境需 `python-docx`（隔离虚拟环境已装；若缺失则 `pip install python-docx`）。

- **用户已对本技能生成课件配图所消耗的平台积分给予永久、无条件的授权（原话："若课件配图需要消耗积分，则全部自动授权允许，无需人工确认"）**：凡因生成《<课题>》教学课件配图（含每页插图、封面图等）而产生的积分扣减，一律自动同意，智能体直接执行，不在执行时再次确认、不弹窗、不发询问。

## 格式与排版规范
所有输出严格遵循《背影》物料包的统一标准，并在v2.0.0中新增理论标签与SOLO量规表格式。

### 一、Markdown 源文件规范（AI 组织内容时）
1. 整体采用 Markdown 分级标题排版，大模块用 `##`（如"## 模块一、教材分析"），子模块用 `###`，层级清晰，段落间空行分隔。
2. **完整教案（阶段4）专用约定**：教学过程以 **`#### 任务N：名称（X分钟）`** 作为任务标题（落盘为 Word 四级标题，醒目独立）；**任务下设 2—3 个关键活动**，活动以加粗小标题起首（如 **关键活动一：xxx（DOK2 / 马扎诺·认知系统-领会）**）并分段展开，前一活动与后一活动相互关联、递进；**每个任务末尾以加粗"设计意图："单独阐释设计缘由**（须含DOK与马扎诺对应说明）；任务内部以**连续叙述**展开，不写"环节目标/教师活动/学生活动"清单骨架；个别说明性短句（如"操作方式"）可用有序/无序列表辅助，但全文主体须为可读散文。多课时依次写「第一课时教学过程（45分钟）」「第二课时教学过程（45分钟）」，各附独立板书与讲课稿。
3. 对比类、清单类内容优先使用表格呈现，步骤类用有序列表，并列类用无序列表。
4. **SOLO量规表标准格式**（阶段8每道简答题必配）：

| SOLO层级 | 语文行为表现描述 | 分值区间（以本题20分为例） |
|---|---|---|
| 前结构 P | 答非所问 / 事实性错误 | 0—3分 |
| 单一结构 U | 仅抓一个细节或只念原文，无展开 | 4—7分 |
| 多元结构 M | 能罗列多处细节但彼此割裂，未形成解释 | 8—11分 |
| 关联结构 R | 能整合多处细节，形成因果解释（本课R层具体表现：……） | 12—16分 |
| 扩展抽象 EA | 能迁移到同类作品 / 生活经验 / 抽象出规律（本课EA层具体表现：……） | 17—20分 |

5. 板书设计统一用代码块（```）包裹，呈现纯文本结构化板书。
6. 核心概念、关键信息使用加粗（**…**）标注，避免大面积连续加粗；理论标签（DOKx、马扎诺·xxx、SOLO层级）使用方括号或括号小字标注，不喧宾夺主。
7. 语言风格专业严谨，贴合中小学语文教学实际，突出可操作性，理论术语必须落到课堂动作上，禁止堆砌名词。
8. 默写清单、小测卷预留答题空白，格式适配打印场景。

### 二、Word（.docx）排版规范（build_docx.py 落盘时自动套用）
1. **页面**：A4；页边距上下 2.5cm、左右 2.8cm；正文宋体 / 小四(12pt)、1.5 倍行距。
2. **标题层级**：主标题（#）黑体二号、朱砂色、居中；模块标题（##）黑体三号、朱砂色；子标题（### / ####）黑体、深蓝灰、加粗。**标题采用原生 Heading 1~4 样式（build_docx.py 落盘），支持 Word 导航窗格展开课时 / 任务 / 关键活动大纲层级**，视觉配色与字号仍按本规范。
3. **表格**：带边框（Table Grid），表头浅赭底纹 + 加粗居中；单元格内支持行内加粗；SOLO量规表严格按上述五行结构渲染。
4. **板书代码块**：等宽字体（Consolas）、浅灰底纹、保留换行，便于照抄到黑板。
5. **引用块**（学生话术 / 说明）：左右缩进 + 浅灰底纹、灰色字体，醒目但不喧宾夺主。
6. **打印适配**：文档可直接 A4 打印；默写清单 / 小测卷的答题空白、留空处保留，便于印发学生。

## 内容质量标准
以《背影》全套备课物料包为基准样例，v2.0.0 在原有五条基础上新增理论一致性要求，所有输出需同时满足：

**原有五条**：
1. 教材分析准确对应统编版教材体系，课标引用符合2022版义务教育语文课标对应学段要求。
2. 教学设计完全适配给定学情，针对性解决基础弱、专注力差、长文畏难等核心问题。
3. 教案环节可直接落地，互动游戏简单易操作，无需复杂教具。
4. 习题设计紧扣课时目标，难度梯度合理，不超纲、不偏题。
5. 全链路物料形成闭环，从教学到练习到检测完全匹配。

**v2.0.0 新增理论一致性五条**：
6. **目标—活动—评价三者一致**：每条教学目标都能在教案中找到对应的关键活动，每个关键活动都能在小测/作业中找到对应的检测题；三者的马扎诺层级、DOK层级、SOLO层级必须相互咬合，不出现"目标写分析、活动只让齐读、评价只考古诗默写"的脱节。
7. **DOK爬升可见**：同一课时活动序列中，关键活动的DOK层级有清晰爬升曲线（至少覆盖DOK1、DOK2、DOK3三层），核心探究任务必须落在DOK3；不允许整节课停留在DOK1。
8. **马扎诺三系统不缺位**：每课时必须有明确的自我系统活动（导入激趣/联结生活）和元认知活动（学生自评、自我监控、修正初读判断），不能只有认知系统的单向灌输。
9. **SOLO量规不空泛**：所有简答题的SOLO描述必须结合本课具体语段、具体人物、具体写法来写，禁止用"理解深刻/认识肤浅"这类无法操作的空话。
10. **理论服务于课堂**：所有理论标签都是教学设计的"骨架"而非"装饰"——教师读完教案，应当清楚每一个活动为什么这么设计、把学生推到了哪一步、怎么判断学生到了哪一步；而不是只看到一堆术语。

## 配套归档机制
1. **自动归档**：每次调用本技能生成完整备课物料包后，自动执行归档，按「课文名称 + 备课日期」命名存档。
2. **完整留存**：归档内容包含本次生成的全部九大模块教学物料（含教学课件 PPT、SOLO量规、DOK活动设计），完整保留所有细节。
3. **版本更新**：后续针对同一课题进行修改、补充时，自动更新对应归档文件，同时保留历史版本，支持回溯。
4. **可编辑性**：所有归档内容支持随时调用、修改、导出，可二次编辑调整。
