# 付老师·语文备课一条龙Skill
> 版本：v1.4.0 — 最终物料包交付为 Word(.docx)；完整教案须详实、以“任务—关键活动”组织教学（非列表骨架），多课时分别产出独立完整教案；文件排版规范（详见“格式与排版规范”）。

## 技能标识
`fu-laoshi-chinese-lesson-prep`
## 适用场景
统编版初中语文常规备课（支持 1 课时或 2 课时），适配一线语文教师快速产出全套可落地教学物料，尤其适合基础中等偏弱、专注力持续短、对长文本有畏难情绪的班级，主打「情境化任务+小组互动+轻量游戏」的教学风格。

## 核心功能
用户仅需输入 **「教材课题信息 + 班级学情说明」** 两项素材，即可一键生成完整闭环备课物料包（支持 1 课时或 2 课时；多课时时每份课时教案独立、完整、含各自板书与讲课稿），**最终交付物为排版规范的 Word（.docx）文件**（含全部九大模块），并配套自动生成的可编辑教学课件 PPT；全程无需分步指令；自动沿用本次《背影》备课的统一排版、内容深度与设计风格，支持成果自动归档与历史版本回溯。

## 输入规范
调用时需用户提供以下2项核心信息，缺失时主动询问：
1. **教材课题**：明确统编版教材册数、单元、课文名称（例：统编版八年级上册第四单元《背影》）
2. **班级学情**：班级整体基础水平、专注力特点、核心学习难点等（例：基础中等偏弱、专注力短、大半学生对长课文有畏难情绪）

## 完整执行流程
全流程共9个标准输出模块，按顺序自动依次生成，无需用户分步触发；其中教材信息、课标对应环节自动调用通用搜索工具核验准确性。全部文本物料先组织为一份结构化 Markdown（作为可编辑源文件），最后由 `scripts/build_docx.py` 统一转换为排版规范的 **Word（.docx）物料包**，PPT 课件作为配套文件一并产出。

### 阶段1：教材分析模块
1. 调用 `general_search` 工具，核验对应课文的统编版教材单元定位、单元语文要素、《义务教育语文课程标准（2022年版）》第四学段对应要求，引用2022年版语文课程标准中对应学段、学习任务群的相关表述，并说明与本课的关联。
2. 单元位置：本课所在单元主题、语文要素、单元内篇目关系及前后勾连。
3. 梳理本课核心知识点：字词基础、文体特征、核心写法、情感主旨四大维度
4. 明确教学重点、教学难点，区分课时可落地目标与长期素养目标
5. 结构化输出：课标对应要求→单元位置→核心知识点→教学重难点

### 阶段2：教学目标与学科大概念
2.1 教学目标
依据2022年版语文课程标准，按核心素养四个维度拆分：**文化自信、语言运用、思维能力、审美创造**。
每条目标必须：
- 使用可观测、可测评的行为动词（如：能说出、能概括、能分析、能比较、能仿写、能评价等）。
- 指向具体知识点或能力点。
- 避免空泛表述。
**格式要求**：以核心素养维度为小标题，每个维度下列1—3条目标，每条以“学生能够……”开头。
2.2 学科大概念
- 结合本课知识点，提炼**1—2个学科大概念**（如：叙事散文通过细节描写与情感聚焦表达深沉情感）。
- 用简洁语言说明该大概念如何串联本课各小节知识。
- 提供**学生版解读话术**：用通俗易懂的语言向学生解释这一大概念，便于课堂直接使用。
**格式要求**：以「大概念名称 + 串联逻辑 + 学生版话术」三段式呈现；学生版话术用引用块标注，语言口语化、可直接念给学生听，避免术语堆砌。

### 阶段3：学情适配设计思路
1. 基于用户提供的学情，针对性设计整体教学策略，核心遵循「化长为短、情境代入、任务驱动、小组互助、高频互动」四大原则
2. 固定采用「总情境任务+分关卡闯关」的模式，拆解长课文为多个8-10分钟的小任务，降低畏难情绪
3. 明确小组分工机制，设置不同难度任务适配不同水平学生，保障全员参与

### 阶段4：完整教案生成（按实际课时数，每课时45分钟，内容须详实）
> 本阶段严格参照《藤野先生》备课包的完整教案写法：**以“任务”为教学单元、任务下设计“关键活动”、全程叙述性散文体、严禁清单/表格骨架**；若本课为 **2 课时**，须产出**两份各自独立、完整**的课时教案（各自任务、各自板书、各自讲课稿）。

1. **课时判定与呈现**：先明确本课课时数——默认 1 课时；用户输入“2课时/两课时”或课文体量大、需分课时落实时，按 **2 课时**处理。每个课时独立产出一份**完整教案**，不合并、不互代；多课时时依次以「第一课时教学过程（45分钟）」「第二课时教学过程（45分钟）」呈现，各含独立教学过程、板书设计与教师讲课稿。
2. **整体结构（详案，叙事体）**：每份课时教案按序展开——教学目标 → 教学方法 → 课堂走神应对话术预设 → 教学过程（分任务）→ 板书设计 → 教师讲课稿。**整份教案用连续叙述 + 任务组织，禁止把教案写成“环节目标/教师活动/学生活动”的清单或表格骨架**（任务内部个别说明性内容如“操作方式”“设计意图”可用短句辅助，但全文主体必须是可读的散文叙述）。
3. **教学过程 = 多个“任务”串联，任务下设“关键活动”（叙事散文体，非列表）**：
   - 每课时把 45 分钟拆成 **4—5 个“任务”**（如：任务一·破冰导入 / 任务二·核心探究 / 任务三·人物形象提炼 / 任务四·小结铺垫），任务标题用四级标题并标注精准时长，如 `#### 任务一：破冰导入（8分钟）`。
   - **每个任务下设计 2—3 个相互关联、递进的关键活动**：活动是任务的分解步骤，前一活动为后一活动搭台阶，共同推进该任务的目标达成，各活动用时可不等分。
   - **活动必须提炼小标题并分段表述**：每个活动以加粗小标题起首（如 **关键活动一：创设情境，引出主题**），小标题下用一段叙述散文展开，活动与活动之间以过渡句衔接，避免堆砌罗列。
   - **每个任务环节末尾单独阐释“设计意图”**：以加粗 **设计意图：** 起句，用 1—2 句话点明该任务为何这样设计（对应哪条学情/目标），单独成段，醒目但不淹没在叙述中。
   - **每个活动内部用叙述性散文展开**，自然融入以下内容（不强行分条、不列空骨架）：
     - **情境 / 任务产出**：本活动做什么、怎么组织（小组/全班/同桌）、学生产出什么（名片、学习单、思维导图等）；
     - **教师导语与关键提问**：直接写出可念出口的引导语、过渡语、由浅入深的问题链（**具体措辞**，严禁“引导学生思考”之类空话）；
     - **关键语段 / 预设与引导**：教师重点点拨的课文语段，以及对学生可能回答的预设与追问方向；
     - **学生活动与产出**：学生具体做什么、怎么展示、用时多少；
     - **板书 / 笔记时机**：本活动在哪个节点在黑板或笔记上落点；
     - **走神应对**（按需）：该任务/活动易走神时，预设温和拉回话术。
   - 任务之间用**教师过渡语**自然衔接；任务末可用一两句“教师小结”收束，并向任务/下课时核心问题铺垫。
4. **板书设计**：每份课时教案末尾给出该课时「最终版板书」——脉络式纯文本结构，用代码块统一呈现（方便照抄黑板），并说明随课堂生成的落点；**2 课时时分别给出「第一课时板书」「第二课时板书」**。
5. **教师讲课稿（详案配套，建议必出）**：课时教案后附「教师讲课稿」，按任务重写**可直接念出口**的导入语、过渡语、提问、小结与结语（含预设学生回答后的应对），与教学过程一一对应，供无备课基础时照着上。
6. **互动与走神**：教学过程嵌入 2—3 个轻量课堂互动小游戏（在任务内的“关键活动”中展开）；问题链 4—5 个由浅入深、低门槛起步；走神应对预设默读、讨论、讲解三类场景的温和拉回话术，避免当众批评，以任务牵引、趣味钩子、个体轻唤为主。
7. **课时衔接（仅多课时）**：上一课时末尾须有“小结与铺垫/预习”，向下一课时核心问题自然过渡；下一课时开头以“复习导入”回扣上节课板书与遗留问题。

### 阶段5：配套课件PPT大纲
1. **风格标准**：活泼卡通风，柔和暖色调，圆角卡片式排版，适配初中生审美，避免沉闷
2. **标准页数**：14-16页，覆盖封面、学习目标、情境导入、闯关任务、游戏环节、知识点梳理、课堂练习、小结、作业全链路
3. **输出形式**：表格呈现，每页对应「核心要点 + 建议配图方向」，互动游戏页单独标注规则与视觉设计方向

### 阶段6：分层课后作业设计
1. 固定三档分层：基础档（全体必做）、提升档（中等及以上选做）、拓展档（学有余力选做）
2. **提升档固定为同主题课外阅读迁移题**：配套短篇名家文段，设置内容概括、细节赏析、写法对比三类习题，实现课内到课外的能力迁移
3. 作业难度梯度清晰，避免重复机械训练，总量控制在20分钟以内

### 阶段7：可打印知识点默写清单
1. **标准题型**：字词默写（看拼音写汉字）、课文核心段落默写、核心知识点填空
2. **格式规范**：预留班级、姓名、得分栏，排版适配A4纸直接打印，题量控制在10-15题
3. 内容100%匹配课堂教学重点，不超纲、不拓展，用于检测基础掌握情况

### 阶段8：配套课堂小测卷
1. **题量与题型**：共10题，7道选择题 + 3道简答题，满分100分，建议用时15分钟
2. **考点覆盖**：字词基础、课文内容梳理、写法赏析、主旨理解，全面对应课时知识点
3. 同步生成**参考答案 + 按点赋分评分标准**，标注得分要点，支持教师快速批改

### 阶段9：自动生成教学课件（.pptx，每次必做，含真实 AI 插图）
1. 在「阶段4：配套课件PPT大纲」产出大纲（每页「核心要点 + 建议配图方向」）后，**自动**依据该大纲生成可编辑 PowerPoint 课件；与阶段1–7 物料一并完成，无需用户单独触发或额外操作。
2. **生成插图（自动扣积分，无需确认）**：对大纲每页「建议配图方向」调用图像生成工具（ImageGen）生成该页插图，保存至输出目录 `assets/`（如 `p01.png`）。依据下方「配图积分授权」规则，积分扣减一律自动同意，不弹窗、不询问；风格统一为活泼卡通 / 扁平教学插画，与暖色调定位一致。
3. **组装**：调用 `scripts/build_pptx.py` 的 `build_courseware(lesson_title, outline, out_path, assets_dir="assets")`。引擎按四色系统（宣纸底 / 朱砂标题条 / 青墨列表点）渲染：封面页（居中大标题 + 插图）+ 内容页（标题条 + 左侧要点 ≤6 行 + 右侧真实插图）；插图缺失时自动回退为占位框，不中断。
4. **校验**：用 python-pptx 重新打开生成的 pptx，确认页数与大纲一致、文件可正常打开。
- 输出文件：`《<课题>》教学课件.pptx`，与备课物料同目录。
- 依赖：执行环境需 `python-pptx`（隔离虚拟环境已装；若缺失则 `pip install python-pptx`）。

### 阶段10：生成 Word 物料包（.docx，最终交付）
1. 九大模块文本先组织为一份**结构化 Markdown 源文件**（标题层级、表格、板书代码块、引用块均按“格式与排版规范”书写），作为可二次编辑的源。
2. 调用 `scripts/build_docx.py` 的 `build_docx(md_path, docx_path)`，将该 Markdown 转换为排版规范的 Word 文档（A4、宋体正文/黑体标题、表格边框+表头底纹、板书等宽底纹、引用块缩进底纹，详见“格式与排版规范”）。
3. **校验**：用 python-docx 重新打开生成的 docx，确认可正常打开、标题与表格数量与源文件一致。
4. 输出文件：`《<课题>》教学物料包.docx`，与课件 PPT 同目录，作为本次备课的**主交付物**。
5. 依赖：执行环境需 `python-docx`（隔离虚拟环境已装；若缺失则 `pip install python-docx`）。

- **用户已对本技能生成课件配图所消耗的平台积分给予永久、无条件的授权（原话：“若课件配图需要消耗积分，则全部自动授权允许，无需人工确认”）**：凡因生成《<课题>》教学课件配图（含每页插图、封面图等）而产生的积分扣减，一律自动同意，智能体直接执行，不在执行时再次确认、不弹窗、不发询问。

- 若某次执行因无图像生成能力而无法渲染真实配图，则保留「配图占位框」（已标注方向），并在交付说明中告知，不视为缺漏。

## 格式与排版规范
所有输出严格遵循本次《背影》物料包的统一标准。

### 一、Markdown 源文件规范（AI 组织内容时）
1. 整体采用 Markdown 分级标题排版，大模块用 `##`（如“## 模块一、教材分析”），子模块用 `###`，层级清晰，段落间空行分隔
2. **完整教案（阶段4）专用约定**：教学过程以 **`#### 任务N：名称（X分钟）`** 作为任务标题（落盘为 Word 四级标题，醒目独立）；**任务下设 2—3 个关键活动**，活动以加粗小标题起首（如 **关键活动一：xxx**）并分段展开，前一活动与后一活动相互关联、递进；**每个任务末尾以加粗“设计意图：”单独阐释设计缘由**；任务内部以**连续叙述**展开，不写“环节目标/教师活动/学生活动”清单骨架；个别说明性短句（如“操作方式”）可用有序/无序列表辅助，但全文主体须为可读散文。多课时依次写「第一课时教学过程（45分钟）」「第二课时教学过程（45分钟）」，各附独立板书与讲课稿。
3. 对比类、清单类内容优先使用表格呈现，步骤类用有序列表，并列类用无序列表
3. 板书设计统一用代码块（```）包裹，呈现纯文本结构化板书
4. 核心概念、关键信息使用加粗（**…**）标注，避免大面积连续加粗
5. 语言风格专业严谨，贴合初中语文教学实际，突出可操作性，避免空泛理论
6. 默写清单、小测卷预留答题空白，格式适配打印场景

### 二、Word（.docx）排版规范（build_docx.py 落盘时自动套用）
1. **页面**：A4；页边距上下 2.5cm、左右 2.8cm；正文宋体 / 小四(12pt)、1.5 倍行距
2. **标题层级**：主标题（#）黑体二号、朱砂色、居中；模块标题（##）黑体三号、朱砂色；子标题（### / ####）黑体、深蓝灰、加粗。**标题采用原生 Heading 1~4 样式（build_docx.py 落盘），支持 Word 导航窗格展开课时 / 任务 / 关键活动大纲层级**，视觉配色与字号仍按本规范。
3. **表格**：带边框（Table Grid），表头浅赭底纹 + 加粗居中；单元格内支持行内加粗
4. **板书代码块**：等宽字体（Consolas）、浅灰底纹、保留换行，便于照抄到黑板
5. **引用块**（学生话术 / 说明）：左右缩进 + 浅灰底纹、灰色字体，醒目但不喧宾夺主
6. **打印适配**：文档可直接 A4 打印；默写清单 / 小测卷的答题空白、留空处保留，便于印发学生

## 内容质量标准
以本次《背影》全套备课物料包为基准样例，所有输出需满足：
1. 教材分析准确对应统编版教材体系，课标引用符合2022版义务教育语文课标第四学段要求
2. 教学设计完全适配给定学情，针对性解决基础弱、专注力差、长文畏难等核心问题
3. 教案环节可直接落地，互动游戏简单易操作，无需复杂教具
4. 习题设计紧扣课时目标，难度梯度合理，不超纲、不偏题
5. 全链路物料形成闭环，从教学到练习到检测完全匹配

## 配套归档机制
1. **自动归档**：每次调用本技能生成完整备课物料包后，自动执行归档，按「课文名称 + 备课日期」命名存档
2. **完整留存**：归档内容包含本次生成的全部九大模块教学物料（含教学课件 PPT），完整保留所有细节
3. **版本更新**：后续针对同一课题进行修改、补充时，自动更新对应归档文件，同时保留历史版本，支持回溯
4. **可编辑性**：所有归档内容支持随时调用、修改、导出，可二次编辑调整

## 调用示例
> 用户输入：统编版七年级上册第一单元《春》，我们班基础中等，男生多活泼好动，不爱背字词
> 
> 技能自动输出全套九模块备课物料包，**最终交付为排版规范的 Word 文件《春》教学物料包.docx**（教材分析 / 教学目标+大概念 / 学情适配 / 完整详案【以“任务—关键活动”组织呈现，可直接照上】/ 课件PPT大纲 / 分层作业 / 默写清单 / 课堂小测 / 随堂过关），并配套生成《春》教学课件.pptx；自动适配学情设计互动游戏与走神应对方案，同步生成归档文件

> 用户输入：统编版八年级下册第二单元《藤野先生》，2课时，我们班基础中等偏弱、专注力短、对长课文有畏难情绪
> 
> 技能按 **2 课时** 处理：完整教案依次产出「第一课时教学过程」「第二课时教学过程」，每份均为**任务—关键活动式详案**（任务下设递进关键活动，含教师导语、问题链、设计意图、学生活动、板书时机、走神应对），各附独立板书与教师讲课稿；其余八模块照常，最终交付《藤野先生》教学物料包.docx + 教学课件.pptx
