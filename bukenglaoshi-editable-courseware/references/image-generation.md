# 生图方法：使用宿主现有能力

先按host-capabilities.md选择实际可用工具。默认不指定模型、API地址、Key或本地脚本路径；直接使用当前软件公开的生图能力。用户明确指定引擎或已有配置时遵从其要求。不把本机环境规则复制进分享包。

## 所有模式共用的提示词准备

从当前课题、教材、年级、页面任务、准确文字、参考图职责、最新意见和否定方向重新组织提示词。生图工具不自动知道聊天上下文，实际调用必须带上必要内容。

共同风格描述固定本套的造型、媒介、线条、色彩关系与人物身份（需要时）；每页主体、教学内容、视角、构图和留白单独写。固定风格不等于每页使用相同物品或底板，也不固定为某个历史项目的风格。

参考图输入可用时，将本项目角色图标记为身份参考，将艺术参考标记为造型/笔触/色块/标题/颜色参考；明确不复制旧文字、身份、物品、场景、装饰组合与构图。工具只支持一张参考时，先使用当前艺术参考的画法，依据本次任务新设计主体、角色和场景，生成本项目封面；检查通过后再把这张新封面作为本套风格/身份锚点。参考输入不可用时复用具体文字画法与项目角色设定，并说明细节一致性较弱。

风格纠偏时，回到本项目当前选定的风格参考，不能继续拿被否定的一版作唯一参考。先比较造型、线条、上色、材质、颜色组织和布局层次的具体差异，按差异改写提示词。

尺寸：默认16:9横向（横版左右构图）；输出尺寸、格式、数量以实际返回为准。工具只支持近似比例时先生成再以不裁切教学文字的方式排版/加边，不拉伸。单页输出不是把多页缩在一张图里。

## image：整页教学图

每页独立生成，包含本页准确标题、正文与必要插画。先分别检查封面和具备学习材料与活动的代表教学内页，再按共同画法和内页排版原则生成其余页面。逐字检查中文、拼音声调、标点和数字。错字局部编辑能力可用时只改该处；否则针对该页重生。若工具持续不能准确成字，可用宿主可用的图片合成/排字能力把准确文字合成进无字插画。整图文字融入像素，不能称为可编辑文本。

## editable-ppt：独立素材

先按page-direction.md完成逐页设计和素材清单，再生成对应背景/场景层、主体插画、必要人物姿势、关键道具与装饰。标题、正文、拼音、答案、标签、精确关系和适合原生制作的容器留给演示文稿对象。不要先生成所有整页图，再试图自动恢复原始图层。每项独立素材一个明确主体或必要的一组对象。要求四周留白8%—12%、主体完整不裁切。

### 透明素材按工具能力处理

1. 宿主支持真实透明输出：直接请求透明背景，并检查实际alpha。
2. 不支持直接透明，但有抠图/分割：生成适合抠图的简单底色，再使用可用工具；底色避开主体颜色，不画棋盘格假透明。
3. 有Python/Pillow且素材为纯底色时，可选scripts/remove_solid_bg.py；它仅移除边界连通纯色。
4. 没有可靠透明能力时，可采用同画布底色的独立插画块或无重叠布局；如实说明背景仍在。

检查人物发丝、手部、服装白色区域和道具；将透明素材放到深浅两种底色检查。两次针对性修正仍失败时改变素材或布局方案。

## both：统一版本

优先用独立素材完成可编辑演示文稿，再从实际最终文稿导出图片。只有需要另外的艺术效果稿或宿主无法渲染时才另生整图；单独生出的图须标为效果稿，不能冒充PPT实际渲染。

## 记录与失败处理

保存本次实际提示词、参考图角色、工具/模型已知信息、实际尺寸和版本；未公开的模型名不猜。不同资产用不同提示词，不靠同一提示词随机重复凑全套。生成后核对实际图片，不以工具调用“成功”代替视觉检查。如用户已配置脚本，使用该脚本的帮助与动态提示词参数，不修改共享脚本。密钥、账号与接口配置不进入课件或分享包。
