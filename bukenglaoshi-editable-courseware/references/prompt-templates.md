# 按任务动态组织提示词

模板只提供字段和参考职责，不是固定内容。每次填入当前任务、page-plan、style-spec、素材清单与最新意见。实际提示词只保存在项目中；不要把当前课题、例题、角色或配色反写成Skill默认值。删除不适用字段，不把占位符直接交给生图工具。

## 参考职责说明

```text
图片{编号}仅作风格参考：观察{本项目选定的线条、造型、上色、材质、色彩组织、标题与空间层次}。
参考图中的文字、数字、公式、教材信息、Logo、水印、人物身份、场景和物品均不是本次内容。不复刻其具体布局或装饰组合。
本次主体、文字、关系与布局以下列任务为准：{当前项目要求}。
```

## A. 无字背景/场景层

```text
用途：{当前课题/项目}第{页}页的{背景/场景层}，输出比例{比例}，用于可编辑PPT。
风格：{本项目style-spec的具体画法、色彩组织与场景层次}。
视觉概念与环境：{本页教学目的对应的场景}。
布局：{留给原生文字、图解和独立主体的区域与比例}；景物分布在{位置}。
分层：这张只含{允许合并的非交互景物}；不含{另行生成的教学主体、人物、道具、容器或图解}。
文字：不生成文字、数字、公式、标签、Logo或水印。准确文案由PPT原生对象添加。
输出：{整页无字底图/独立场景块}；不能画棋盘格假透明。
```

## B. 独立人物/道具/物件

```text
用途：{当前项目}第{页/多页}页的独立{对象类型}，后期单独置入PPT。
风格：{本项目选定的具体画法与色彩关系}。
主体身份与结构：{本项目新设计或用户明确指定的身份、外观、服装/材质、形状和必要结构}。
本次姿态/视角/状态：{服务本页任务的具体动作与道具关系}。
构图：主体完整、四周留裁切安全空间，适合放在{页面位置}。
背景：{真实透明/适合抠图的纯底/同画布底色的插画块}。
排除：本页不需要的第二主体、场景、文字、标签、Logo和水印。
```

## C. 教学场景/关系插画

```text
用途：{当前学科/年级/课题}中的{本页知识关系或观察任务}。
画法：{本项目style-spec}。
内容与结构：{核实后的对象、数量、结构、状态与动作}。
布局：{准确空间关系、观察视角和标签留白位置}。
教学准确性：{本页必须成立的关系与易错点}。
编辑安排：原生制作{文字、公式、刻度、箭头、数据或必要图解}，不把它们烘焙进插画。
限制：本页容易生成的具体错误和不需要内容，不添加Logo或水印。
```

## D. 完整整页图片

```text
用途：{当前项目}第{页}页完整教学图，{比例}，只输出这一页。
页面职责：{封面/教学内页}，不得混淆。
本页目的：{具体目标}。
学生行动与学习材料：{要读/观察/比较/思考/练习什么，准确材料与操作空间}。
课堂排版：标题为导航、正文或核心图解为主体的层级。教学内页不沿用封面式巨字、满屏风景和装饰密度。
准确文字清单：{逐项列出本页实际文案、必要拼音/数字/公式和标点}。
风格系统：{本项目造型、线条、上色、材质、主辅色职责、标题与正文处理}。
限制：只生成准确文字清单，不额外加拼音、题目、标语、署名、Logo或水印。
```

## E. 定向编辑

```text
图片{编号}是编辑目标。只改变：{一个明确问题或一组必要关联改动}。必须保持：{现有文字、人物身份、构图、配色、场景、比例等具体不变项}。新准确文字（涉及改字时）：{正确内容}。
```
