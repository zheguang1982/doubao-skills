# 从当前参考提取风格

参考仅用于当前项目，Skill本身不保存固定作品、课程文字、角色或配色。风格提取的目标是得到一套可描述、可迁移、可检查的卡通视觉系统，支持不同学科、内容与卡通画法。

## 区分风格与内容

| 可观察的风格维度 | 当前项目需要重新设计的内容 |
|---|---|
| 卡通化程度、轮廓粗细与轻重、上色方式、阴影和材质 | 人物身份、年龄、职业、服装、动作、道具 |
| 色彩饱和度、明暗与冷暖关系、主辅色职责 | 对应本次内容的实际色值与主题意象 |
| 标题的圆润/硬朗、字重、描边、阴影、强调方式 | 标题、正文、拼音、数字、公式、教材信息 |
| 景物概括程度、透视、景深、前中后景层次 | 具体环境、物品、故事情节与插画位置 |
| 内容容器的形状语言、留白、边缘处理与层级 | 每页内容分区、对象数量、排列、对应关系与布局骨架 |

用户只说参考风格时，不从截图读取课程内容用于新课。若用户另外明确要求提取内容或沿用角色，再标明这些输入的新职责；不能从风格参考自动推断。

## 每个项目建立style-spec

记录下列决定；只写观察到和本项目实际选用的特征，不为了填满字段补造元素。

- 参考职责与艺术特征：哪些图用于风格，哪些另有明确的内容/身份职责。描述具体画法，不能只写“卡通、精美、统一”。
- 造型与媒介：可为圆润Q版、漫画人物、较自然比例的卡通人物、绘本淡彩、明亮平涂或带体积的插画；按当前参考选择，不固定头身比、描边颜色或纸纹。
- 色彩系统：当前项目底色、主色、辅助色、强调色的职责与明度对比。可以鲜亮或柔和、冷色或暖色，不强制奶油底、低饱和或特定色系。
- 字体系统：主标题、页标题、正文、注释/拼音/数字的层级、尺寸和可用字体；描边与阴影按当前风格选择。长正文优先阅读性，不因封面艺术字而全套都用艺术字。
- 场景与材质：背景细节、透视、景深与主体质感如何协同。可按参考采用简洁场景或较丰富的卡通场景；局部实物照片/质感插图仅在教学内容需要且与整体协调时使用。
- 组件语言：当前项目采用的容器、标注、图标、装饰和互动提示的共同形状规则。组件随任务组合，不固定卡片、图钉、书页、边框或某个标题牌。
- 项目角色与主题意象：按内容决定有无角色、多少角色、身份与服装；仅在本套内保持所需一致性。不是每页必须放人物，也不默认是小女孩。
- 布局节奏：封面、解释、操作、比较、练习等页面各自如何分配焦点与信息密度；用统一视觉语法形成一套，不复制参考的具体轮廓。

无参考图时，根据当前年龄、学科和内容提出并采用清楚、有亲和力的卡通系统；不调用历史课题、角色和内置样图。用户指定或明确认可的风格优先，不因每次换课就擅自换画法。

## 两项检查同时通过

风格匹配：对照当前所选参考检查人物造型、线条、上色、色彩组织、场景层次、标题性格。不能只改了配色却换了画法，也不能只因无错字就认定视觉合格。

内容与构图独立：忽略文字后，新页不能仍是旧参考人物、物品、容器和位置关系的整体复刻。抽象的层级与组件语言可以迁移，具体内容和组合由本次任务设计。此检查不宣称绝对原创或无版权风险。

保持风格无需禁止一切写实体积、景深或实物材质；是否合适由当前风格和教学准确性决定。也不把某种装饰的出现作为风格合格或失败的单一判断标准。
