# 输出模板：诊断报告 + 完整教学设计

本文件提供两类产物的结构模板：
1. **诊断报告**——指出原稿不足（对应 SKILL.md 第 3 步）。
2. **完整教学设计**——改出可直接使用的成品（对应 SKILL.md 第 4 步）。

两份产物都作为文档交付给用户（Word/飞书文档均可），命名建议：`《课题》智能体融合课·诊断报告`、`《课题》智能体融合课·教学设计（修订版）`。

---

## 模板一：诊断报告

### 一、总体评价（2-3 句）

先肯定原稿 1-2 个真实亮点（具体到环节），再一句话点出最核心的问题。例：
> 原稿在"智能体功能设计"上考虑较细（如……），但存在一个致命短板：全程没有说清它要解决的课堂真实痛点，学生参与与成效佐证几乎空白，容易在评审中被判为"花架子"。

### 二、分维度诊断表

| 维度 | 评级 | 原稿现状（引原文） | 具体问题 | 改进方向 |
| --- | --- | --- | --- | --- |
| 痛点 | ★★ | 引原稿相关句 | 问题描述（具体到环节） | 怎么改 |
| 创新 | ★★★ | ... | ... | ... |
| 机制 | ... | ... | ... | ... |
| 落地 | ... | ... | ... | ... |
| 参与 | ... | ... | ... | ... |
| 成效 | ... | ... | ... | ... |
| 闭环 | ... | ... | ... | ... |
| 规范 | ... | ... | ... | ... |

### 三、问题分级清单

- **关键问题（必须改）**：1-3 条，每条写明"问题 + 为什么致命 + 怎么改"。
- **重要问题（建议改）**：若干条，影响拿高分但不致命。
- **次要问题（可改可不改）**：打磨级细节。

### 四、修改方向总览

按实施顺序排列（先补骨架，再补细节）。例：
1. 先补"教学痛点 + 场景"：……（对应诊断 1）
2. 再补"智能体角色与机制"：……（对应诊断 2）
3. 最后补"成效证据"：……（对应诊断 3）

## 模板二：完整教学设计（修订版）

以下为修订版骨架。**必须从原稿继承**：课题、篇目、学情、教材内容、已写好的合理环节。只对诊断出的不足做补强/重写。每个板块标注其回应了哪个评审维度，方便用户对照。

### 一、课题与基本信息

- 课题名称 / 学科 / 年级 / 课时 / 授课环境（是否机房、平板、手机端）
- 说明：沿用原稿，缺则补。

### 二、教学痛点与选题背景【痛点】

- **真实痛点**：用一两句说清"本课学生在哪一步遇到了什么具体困难"（尽量引用原稿学情或教材分析）。
- **场景交代**：这节融合课发生在什么课堂环境下（哪个单元、哪个环节引入智能体）。
- **为什么选它**：这个痛点为什么适合用智能体解决（而非普通工具）。

### 三、智能体角色与设计思路【创新】【机制】

- **角色定位**：智能体在课堂上扮演什么身份（如朗读陪练、思辨辩友、作文诊断师、诗词问答官等）。
- **与常规/同类方案的区别**：至少 1 条可验证的差异化创新点（具体到机制）。
- **核心机制**：输入 → 加工 → 输出 的工作链路；用到的模型/知识库/提示词设计思路/数据来源（可复现）。
- **与教学内容深度融合的说明**：智能体的判断标准、反馈逻辑如何对齐教材与课标。

### 四、教材与学情分析（沿用原稿并补强）

- 教材分析：本课在单元中的位置、重难点。
- 学情分析：学生的认知基础、信息技术素养水平、对本课内容的已知与易错点。

### 五、教学目标【闭环】

- 三维目标或核心素养目标（按原稿学科惯例）。
- 每条目标尽量可测量，能与后面的"成效评估"挂钩。

### 六、智能体功能与流程设计【机制】【落地】

- **核心功能清单**：3-5 个功能点，每个写明触发指令/输入与输出。
- **工作流程**：用文字或图示描述一次完整的学生使用流程。
- **意外应对预案**：网络中断、回答跑偏、生成不合规内容时的教师兜底方案。
- **局限说明**：如实写智能体做不好的情况，及教师如何弥补。

### 七、教学过程设计（课前/课中/课后）【参与】【闭环】

| 环节 | 教师活动 | 学生活动 | 智能体介入点 | 设计意图 |
| --- | --- | --- | --- | --- |
| 课前 | ... | ... | ... | ... |
| 课中-导入 | ... | ... | ... | ... |
| 课中-探究 | ... | ... | ... | ... |
| 课中-展示 | ... | ... | ... | ... |
| 课后 | ... | ... | ... | ... |

- **学生参与设计**：至少一个"学生亲手操作智能体"的具体任务，写明指令示例与产出物。
- **素养引导**：安排学生批判性看待智能体回答、辨别信息真伪的环节（呼应【规范】）。

### 八、成效评估设计【成效】

- **量化证据**：前后测、正确率、作品评分、用时对比等（写明怎么测、样本是什么）。
- **质性证据**：学生反馈原话、作品样例、课堂观察记录。
- **评价工具**：评价量表、问卷、访谈提纲等。

### 九、创新点与推广价值【创新】【闭环】

- **创新点**：2-3 条，具体到机制，不堆形容词。
- **推广价值**：可在哪些学科/学段/学校场景复用，需要什么条件。

### 十、局限、安全与规范【落地】【规范】

- 局限与兜底（详见第六板块，此处汇总）。
- 学生数据/作品上传的隐私处理与去标识化。
- 生成内容审核机制、平台合规说明。
- 学生 AI 素养与网络素养引导。

### 十一、支撑材料清单【闭环】

列出配套材料：智能体设计文档、操作指南/提示词手册、学生作品样例、课堂实录、调查问卷、量表等（说明是否已有/待补）。
