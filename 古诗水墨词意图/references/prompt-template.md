# Prompt 模板与风格规范

## 一、风格基因清单（写进每一次 prompt）

- **材质**：宣纸本白（极浅米灰）底色，带轻微纸纹；墨分五色（焦、浓、重、淡、清）。
- **笔触**：树干、石头、土坡用焦墨枯笔写出，带飞白；柳叶、花叶、云气用没骨法晕染，不见勾勒线；人物衣纹一笔到位。
- **人物**：简笔点景，宽袍大袖，五官极简（几点墨代替眉眼），不画特写脸；比例约占画面 1/10。
- **光影**：柔和漫射天光，无硬阴影，色薄而透纸。
- **整体气质**：温润、含蓄、松弛、怀旧；不要火气、不要艳色、不要写实照片感。

## 二、色彩配方

| 角色 | 色值倾向 | 用途 |
|---|---|---|
| 底色 | 宣纸本白 / 极浅米灰 | 天空、留白、水面高光 |
| 主色 | 墨色 + 灰豆绿 / 嫩粉绿 | 树、柳、远山、春草 |
| 压重色 | 赭石 + 焦墨 | 树干、土坡、石头、屋墙 |
| 强调色 | 淡朱红、粉白、鹅黄（极薄一层） | 桃花、李花、菜花、枫叶、夕阳 |
| 远景 | 淡青灰绿平涂 | 推远空间 |

整体低饱和、高明度、冷暖弱对比；暖色只在树干和小面积花/叶上出现。

## 三、构图四法（按诗意选一）

1. **左右夹景**（田园、庭院、小园）：左右树木/山石夹出画面中央的舞台，上方留 1/4 空白天空。
2. **纵深推进**（桥、路、江、古道）：近景点景人物 → 中景桥/舟/路 → 远景山/村/城，视线由近及远。
3. **对角线动势**（飞雁、流水、孤帆、风）：用一条斜线（鸟群轨迹、水流、帆影）贯穿画面。
4. **压角留白**（独坐、怀古、禅意）：人物或主景压在一角，其余大面积留白，制造空寂。

## 四、Prompt 骨架

```
参考[img0]作为风格母本，延续其宣纸本白底色、焦墨枯笔写出的粗壮枝干、没骨法淡彩晕染、简笔点染且五官极简的人物、低饱和高明度配色、赭石墨色压底、淡青灰远景平涂、上方大面积留白、松松软软带飞白的笔触。将原画面中的儿童放风筝场景全部替换为【本幅诗意的完整画面描述，按从远景到近景、从左到右的空间顺序写】。构图采用【左右夹景/纵深推进/对角线动势/压角留白】，【人物位置与动势】，【视觉焦点在哪里】，上方约四分之一留作空白天空。整体保持【情绪词：温润烂漫/清寂悠远/苍凉开阔/恬静闲适】的气息，柔和漫射天光、无硬阴影、水墨晕染自然、色薄而透纸。画面采用纯视觉表达，不出现任何文字。关键主体完整置于画面内，四周边距均衡。
```

## 五、意象→画面 对照示例

- "桃花红，李花白，菜花黄" → 园中三色花并置，红、白、黄三块色点在墨绿枝叶间。
- "小桥流水人家" → 小石拱桥横亘中景，桥下溪流，桥后一两间茅屋白墙。
- "孤帆远影碧空尽" → 画面右侧一叶小舟渐小，大江横陈，上方大片留白天空。
- "大漠孤烟直" → 平沙漫漫，远处一缕笔直炊烟，地平线压低，天空占大半。
- "独钓寒江雪" → 压角构图：江面大片空白（留白雪意），右下角一小舟一渔翁披蓑。
- "明月松间照" → 上方一轮淡墨圆月，松枝从右上角垂入，中景山泉石上。
- "风吹草低见牛羊" → 低矮草坡横向展开，三五头牛点状散布，远景远山。

## 六、范例

### 范例 1：田园（《行香子》上阕）

> 参考[img0]作为风格母本，延续其宣纸本白底色、焦墨枯笔写出的粗壮柳干、没骨法淡嫩绿晕染柳丝、简笔点染人物、低饱和高明度配色、赭石墨色压底、淡青灰远景、上方大面积留白。将原画面中的儿童放风筝场景全部替换为：绿树环绕的江南小村，一方陂塘春水涨满，一位身着米白长衫、头戴东坡巾的宋代文人背手立于塘边；中景低矮园墙内，桃花嫣红、李花雪白、菜花金黄三色并置；远景淡青绿色田畴平野。构图采用左右夹景，文人位于左下部，花景居中偏右，上方约四分之一留空。整体温润烂漫，柔和漫射天光、无硬阴影、水墨晕染自然。纯视觉表达，不出现任何文字。

### 范例 2：山水（《望庐山瀑布》）

> 参考[img0]作为风格母本，延续其宣纸本白、焦墨枯笔山石皴法、没骨法淡彩晕染、简笔点染人物、低饱和高明度、赭石墨色压底、淡青灰远山、上方大面积留白。将原画面中的儿童放风筝场景全部替换为：一座高大青灰色绝壁从中景拔起，一道白练般的瀑布从山腰直泻而下，水雾以留白表现；山脚下苍松斜出，一位身着白衣的宋代文人立于松下仰头望瀑；远景淡青蓝色层峦推远。构图采用纵深推进，瀑布作为纵向动势贯穿画面，文人在右下角成为观景点。整体清寂悠远，柔和漫射天光、水雾轻笼、水墨晕染自然。纯视觉表达，不出现任何文字。

### 范例 3：边塞（《使至塞上》）

> 参考[img0]作为风格母本，延续其宣纸本白、焦墨枯笔、没骨法淡彩、简笔点染人物、低饱和高明度、赭石墨色压底、淡青灰远景、上方大面积留白。将原画面中的儿童放风筝场景全部替换为：一片赭黄色平沙大漠横向铺展，地平线压得很低，远处一缕笔直的青烟袅袅升起；一条长河在沙原上蜿蜒，远方一轮浑圆落日以淡朱红点在天际；一位披斗篷的骑马旅人小小身影位于左下角，正向远方行去。构图采用压角留白，大漠与天空占画面九成，孤烟与落日成为视觉焦点。整体苍凉开阔，柔和漫射天光、无硬阴影、墨色干燥飞白。纯视觉表达，不出现任何文字。
