# 古诗水墨词意图

把用户给的古诗/古词，转成 16:9 横版中国写意水墨淡彩画。

## 风格母本

风格、构图、色彩一律以 `assets/style-mother.png`（一幅"春郊儿童放风筝"的水墨淡彩小品）为锚点。该图的 CDN 地址为：

```
https://aka.doubaocdn.com/s/XRZgLkPEOA
```

调用 `image_edit` 时，把此 URL 放进 `image_reference_url_list`。若该 CDN URL 失效，先用 `FileBatchUpload` 上传本地 `assets/style-mother.png` 拿到新 URL，再继续。

## 执行流程

1. **确认文本**：用户给篇名时，先联网核对原文与作者，避免错字漏句；用户直接给诗句时以用户给的为准。
2. **分幅规划**：
   - 五言/七言绝句：默认 1 幅；
   - 律诗：首联颔联一幅、颈联尾联一幅，共 2 幅；
   - 词：上阕一幅、下阕一幅，共 2 幅；
   - 长篇古风：按用户指定或按意境段落拆 2–4 幅。
   用户另有要求时从其要求。
3. **提炼意象**：从每句中提取可见景物、人物、季节、时辰、情绪，写成画面元素清单。不堆砌所有意象，挑 3–5 个最有画面感的落幅，其余虚化推远。
4. **生成图片**：调用 `image_edit`，参数固定：
   - `model_version`: `seedream_5.0_pro`
   - `image_reference_url_list`: 仅传入风格母图 URL
   - `width`: `2048`，`height`: `1152`（16:9）
   - `prompt`: 按 [references/prompt-template.md](references/prompt-template.md) 的骨架填写
5. **交付**：每幅图生成后用 `present_files` 单独交付，并在文字中点出该画对应了哪几句诗。

## Prompt 硬约束（每次必须写进 prompt）

- 必须写明"参考[img0]作为风格母本，延续其宣纸本白、焦墨枯笔树干、没骨法淡彩晕染、简笔点染人物、低饱和高明度、赭石墨色压底、淡青灰远景、上方大面积留白"。
- 必须写明"将原画面中的儿童放风筝场景全部替换为……"（即清空母图原内容，只借风格）。
- 必须写明"纯视觉表达，不出现任何文字"。
- 必须写明"柔和漫射天光、无硬阴影、水墨晕染自然、色薄而透纸"。
- 人物一律简笔点景：宋代文人/农人/渔父等，宽袍大袖，五官极简，不画特写脸。
- 不写品牌、不写题字、不加印章（除非用户明确要求加书法题款）。
