# 奖励卡绘图

一句话：**给一个奖励项目，出一张能直接打印发给学生的水墨淡彩手绘卡。**

## 成品长什么样

一张 1:1 的卡，四个固定构件，缺一个就不像：

| 区 | 占比 | 内容 |
|---|---|---|
| 插画区 | 上 55–60% | 焦墨枯笔 + 清水淡彩的 Q 版小人／拟人化物件／小动物，单主体，四周大片留白 |
| 金句区 | 中 20–25% | 手写行楷，≤2 行，墨黑 #2B2B2B，字距松、行距紧 |
| 奖励项目 | 金句上方或下方 | 朱红 #B33A2B 手写，全卡最大字号，是视觉落点 |
| 落款区 | 下 12% | 右下朱红印章（2–4 字），左下小字「姓名 · 日期」 |

## 风格铁律（十条，破一条就废）

1. 纸是宣纸白 `#FBF8F1`，不是纯白 `#FFFFFF`，带极淡纤维颗粒与轻微不均匀。
2. 线是焦墨枯笔：中锋、起笔重、收笔枯、允许断笔与飞白；**禁止**均匀矢量描边、禁止 3D 描边、禁止钢笔平滑线。
3. 色只用 3–5 色，湿画水彩，色块**不填满**线内，边缘留水痕与晕散。
4. 大面积留白：插画区空白 ≥ 40%，整卡空白 ≥ 30%。宁可空，不可满。
5. 脸必有两团胭脂腮红（`#E8A9A6`），这是整套风格的签名，不能省。
6. 五官极简：一条闭眼弧线 + 一笔笑嘴，**不画鼻子**，耳朵夸张大，耳环是青/绿小圈。
7. 人物 2.5–3 头身，光头或三根毛，宽袍大袖；动物用同款简笔。
8. **无**投影、无渐变、无高光反射、无发光、无 3D 渲染感、无滤镜。
9. 文字必须是手写毛笔行楷，字略歪、大小不一、字距松，墨色 #2B2B2B；不能是电脑字体感。
10. 画面里**不出现**二维码、logo、水印、署名、花边、边框贴纸、emoji。

## 工作流（按序执行，不跳步）

### Step 1 收要素

- 必填：**奖励项目**（如「作业全对」「进步之星」「朗读小达人」）
- 可选：金句、学生姓名、日期、班级、落款人、主色倾向、版式（L1/L2/L3）
- 缺失项用默认值，不要追问：金句自写；日期用当天；**没给姓名就不画姓名位**（留白比编造好）。

内部先定这张卡的「一句话立意」：这张卡在夸什么具体行为。想不清就别生图。

### Step 2 写金句

读 `references/copywriting.md`，按三式之一写：具体行为式 / 比喻式 / 小反转式。
硬约束：主句 ≤ 12 字、最多 2 行；不喊口号；不用比较词（最强/学霸/第一名）；不丧、不自嘲。

### Step 3 定版式与构图

默认 **L1 经典式**（上图下文）。三种版式见 `references/prompt-templates.md`：

- **L1 经典式** — 上 58% 插画，下 42% 文字；主体中心偏下，头顶留白 ≥ 15%。
- **L2 楹联式** — 左侧竖排大字占 30% 宽，右下角小画，适合 4–8 字的强奖励名。
- **L3 徽章式** — 中央一圈枯笔圆环／方框包住主体，下方一行短句，适合「星级」「勋章」类。

文字块整体居中、左对齐；印章右下距边 6%；姓名日期左下距边 6%。

### Step 4 生图

用 `image_gen`，`width=height=1440`（1:1），一次只出一张、一次只给一个 prompt。

- 首选 `model_version="seedream_5.0_pro"`。**若提示「会员专属模型」不可用，直接降级到 `seedream_5.5` 继续，不要停下来问用户**；5.5 的水墨淡彩表现同样可用。
- prompt 里所有要出现的字必须用中文引号标出，并写清 **位置 + 字体气质 + 颜色 + 行数 + 字号关系**。模板见 `references/prompt-templates.md`。
- 字多（金句 2 行 + 奖励项目 + 姓名 + 日期 + 印章）时，**不要赌模型**，直接走 B 模式。

### Step 5 验图（必做，不可省）

逐字读图核对，通过 `references/prompt-templates.md` 的 QA 表。任一条不过就修：

- 错字／缺字／糊字 → 改 B 模式，或把字数压到 6 字内重出 A
- 画面变满、出现背景场景 → 加 `90% empty paper, single subject, plain white background`
- 脸崩、多指、多手 → 主体减到 1 个，加 negative
- 出现二维码／署名 → 加 negative `QR code, watermark, signature, artist name`

### Step 6 交付

用 `<RichMediaCard>` 发图（图片类交付物一律走媒体卡，不走 present_files）。
配一句说明：这张卡保留了哪几条核心特征、可换什么。

## 两种出字模式

| 模式 | 做法 | 何时用 |
|---|---|---|
| **A 全自动** | 提示词要求模型直接写中文 | 字少（≤12 字）、追求笔触自然、随手看 |
| **B 稳妥（默认）** | 生图时要求「文字区完全空白」，再用 `scripts/render_card_text.py` 叠行楷字＋印章＋姓名日期 | 字多、要零错、要批量统一、正式发给学生 |

B 模式是零错率的唯一保证。**正式发给学生的卡默认走 B。**

## 脚本用法

```bash
python scripts/render_card_text.py \
  --image illustration.png \
  --reward "作业全对" \
  --quote "你把每个字|都写得很认真" \
  --name "李子涵" --date "2026.11.18" \
  --seal "进步" --out card.png
```

- `--image` 传无字插画（脚本会做底色匹配与边缘羽化，居中嵌入宣纸底；`--layout l2` 时自动靠右）。
- `--quote` 用 `|` 分行，每行 ≤ 12 字，最多 2 行。
- `--layout l1|l2|l3`，`--accent` 可换朱红主色（默认 #B33A2B）。
- 字体自动降级：`STXINGKA`（华文行楷）→ `STKAITI` → `simkai`。缺字体时脚本会打印实际使用的字体。
- 运行条件：本机 Python + Pillow + 任意一款中文字体。**若当前环境没有 Pillow 或中文字体（例如纯云端 Linux），不要强行跑脚本，改用 A 模式让模型直接写字**，并在交付时说明。
- `python scripts/render_card_text.py -h` 查看全部参数。
- 基准样张：`assets/target-look-example.png`，输出质量以它为准绳。

## 常见故障速查

| 症状 | 处置 |
|---|---|
| 字错、笔画糊成一团 | 转 B 模式；或字数减半、字号写大、要求「每个字清晰分开」 |
| 整张图像海报、太设计 | 删掉所有版式词，只留「一张纸、一个小人、两行字」 |
| 线条太干净像矢量 | 加 `dry brush, broken strokes, rough ink edges, no clean vector outline` |
| 色彩过艳 | 指定 `muted low-saturation watercolor, pale wash, 3 colors only` |
| 太像某张参考图 | 换主体（拟人化物件／动物），去掉参考图特有道具与题款 |
| 人物像写实小孩 | 加 `2.5 head proportion, chibi, stick-like limbs, no realistic anatomy` |
