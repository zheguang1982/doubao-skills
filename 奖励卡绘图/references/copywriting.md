# 金句与文案规则

卡片的说服力 80% 来自「这句话是不是真看见了那个孩子」。风格可以抄，句子必须自己长出来。

## 一、三条硬规则

1. **一张卡只夸一个具体行为。** 不写「学习认真、团结同学、热爱劳动」，那是评语不是卡。
2. **主句 ≤ 12 字，最多 2 行；奖励项目 4–8 字。** 字多了模型必错，人也不看。
3. **不比较、不喊口号、不自嘲。** 不出现「最」「第一」「学霸」「别人家的孩子」；不出现「加油」「努力吧」这类空转的动词。

## 二、三句话式（选一种，别混）

### A 具体行为式（最稳，推荐占七成）
先看见动作，再给意义。
> 你把橡皮屑 / 都扫进了手心
> 你读错的那句 / 又读了一遍
> 你举手的时候 / 手举得比别人慢，但没放下

### B 比喻式（用于抒情，占两成）
把行为比成一件小东西，不要比成太阳、星星、翅膀（太滥）。
> 你像一支 / 自己会亮的笔
> 你的字 / 站得比昨天的直
> 你说话的声音 / 像刚烧开的水

### C 小反转式（小林式骨架，占一成）
前半句平铺，后半句轻轻拐弯，**但落点必须是暖的**，不能是自嘲或贬损。
> 世界很大 / 你的字很小 / 可它一笔一笔都到了

> 别急着长大 / 先把这篇课文读完

## 三、奖励项目命名

- 4–8 字，名词短语，能贴在墙上被念出来。
- 优先「具体动作 + 身份」：「作业全对」「朗读小达人」「书写小楷手」「值日小管家」「进步之星」「专注一刻」「第一声举手」「帮人一把」「擦得最干净」。
- 避免泛词：优秀、突出、标兵、先进、三好（除非学校硬性要求）。
- 同系列保持命名结构一致（都 4 字，或都「XX小XX」）。

### 通用收尾句（任何场景都能搭）
- 这件事很小 / 但它会长大

- 慢慢来 / 你已经在路上

## 五、禁用词表

| 类别 | 禁用 |
|---|---|
| 比较 | 最、第一、超过、别人家的、学霸、卷王、逆袭 |
| 空洞 | 你真棒、好孩子、优秀、加油、努力、奋斗、拼搏（单独出现时） |
| 压力 | 不要辜负、必须、下次要、不许退步 |
| 自嘲／丧 | 摆烂、躺平、牛马、穷、没人要（原作常用，**学生卡禁用**） |
| 网络梗 | yyds、绝绝子、emo、栓Q |

## 六、落款规范

- **姓名**：只写名字，不带「同学」「小朋友」（占位太宽）；2–3 字最佳，最多 4 字。
- **日期**：`2026.11.18` 或 `2026年11月18日`，全系列统一一种。没给日期就用当天。
- **印章文字**：2 字最稳（进步、勇气、专注、开心、坚持、好奇、温暖、加油）；4 字用成语（「日有所长」「慢慢长大」）时确认字形简单。
- **落款人**：默认不写。要写时用小字放在印章左侧，「李老师」即可，不写全名与职务。

## 七、自检（写完句子先问三句）

1. 这句话能不能只属于这一个孩子？不能就重写。
2. 去掉「你真棒」式的形容词后，还剩具体动作吗？没有就重写。
3. 念出来会不会让班里其他孩子难受？会就改。
