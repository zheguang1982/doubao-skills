# 风格 DNA：水墨淡彩手绘漫画卡

> 归纳自 29 张参考图（800×1200 与 1000×1400 竖版为主）。本文档只记录**跨图共性**，不逐张描述。

## 0. 一句话定位

**宣纸白底上的焦墨枯笔淡彩漫画：2.5 头身的 Q 版小人 + 一句手写毛笔金句 + 一枚朱红印章。**

## 1. 风格聚类

| 簇 | 占比 | 特征 | 代表 |
|---|---|---|---|
| **A 市井段子型**（主风格） | 约 70% | 上方插画（单主体、无背景场景）+ 下方 2–7 行手写金句 + 右下角小二维码与署名 | 白描小人举石、刷短剧、相亲、算命 |
| **B 文人小品型**（分支） | 约 30% | 满版构图，插画与题款同在画面内，竖排大字题款（含干支纪年小字）+ 2 枚朱红印章 + 花鸟／山水点景 | 静待花开、花开如梦、事事如意、荷花开 |

两簇共用同一套线条、设色、人物语言；差别只在**版式与题款位置**。奖励卡取 A 簇版式骨架，取 B 簇的印章与题款气质。

## 2. 十四维特征

### 2.1 媒介与风格
纸本水墨 + 水彩淡彩，手绘漫画。非数字绘画、非 3D、非矢量插画、非 AI 写实。笔触保留纸纹与渗化，允许脏边、允许留白未上色。

### 2.2 构图与取景
- 主体单点，居中略偏下，占画面宽 35–55%。
- 平视或正俯视，无强透视、无广角畸变。
- 背景几乎为零：最多 1–2 个极简道具（一根竹竿、一座远山、一条桌沿）。
- 留白率 55–75%（B 簇满版除外）。空白即构图，不是没画完。
- 不用三分法框死，靠「主体 + 一大片空」形成呼吸感。

### 2.3 色彩系统

| 角色 | 色 | HEX | 用法 |
|---|---|---|---|
| 纸底 | 宣纸白 | `#FBF8F1` | 全底，带极淡纤维颗粒 |
| 主墨 | 焦墨 | `#2B2B2B` | 轮廓线、金句字 |
| 次墨 | 灰墨 | `#6E6E6E` | 远山、水痕、次要结构 |
| 肤色 | 肉粉 | `#F2DCD2` | 脸、手、脚 |
| 腮红 | 胭脂 | `#E8A9A6` | 两颊晕团（**必有**） |
| 点缀 1 | 朱红／印红 | `#B33A2B` | 印章、奖励项目字、少量果实 |
| 点缀 2 | 石绿／灰绿 | `#8FA37E` | 袍子、荷叶、竹叶 |
| 点缀 3 | 雾蓝／天青 | `#9CB0C0` | 袍子、远山、耳环 |
| 点缀 4 | 赭石 | `#A97B4F` | 木器、竹竿、面包 |

- 色温偏暖，明度高，饱和度低（约 25–40%），对比度中低。
- 水彩湿画，边缘留水痕与晕散；色块常故意**溢出线外**或**未填满线内**。
- 全卡色数控制在 3–5 个，绝不出现大面积高饱和。

### 2.4 光影
- 无明确光源。只有「腮红」和「衣褶淡影」两处暗示体积。
- 无投影落地（少数有极淡一片水痕当影子）。
- 无轮廓光、无体积光、无反射高光。

### 2.5 材质与纹理
纸纤维颗粒、水彩沉淀边（咖啡环）、枯笔飞白、墨点飞溅、印章斑驳缺角。整体做旧度低，卡片干净。

### 2.6 细节与清晰度
- 细节密度低：一个主体 + 0–2 个道具。
- 边缘「毛」而非「锐」，线头有粗细变化。
- 景深无虚化，全画面同一清晰度。

### 2.7 形状与语言
- 有机形为主，圆润、手绘不规整。
- 线条中锋，2–4px@1080，起笔重、行笔稳、收笔枯。
- 手、脚简化为「小钩子」「小括号」，五根手指通常只画 3–4 根。
- 重复符号少；装饰仅靠印章与题款。

### 2.8 主体规则
- 2.5–3 头身，头大身小，四肢细如树枝。
- 光头或三根歪毛；耳朵夸张大（招风耳）；耳环为青/绿小圈。
- 宽袍大袖，袍子一色平涂 + 淡影。
- 表情：闭眼弧线笑（最常见）、张嘴大笑、呆滞圆眼、皱眉鼓腮。四种足够。
- 常配一只同款小猫／小狗／小牛作陯衬，位置在主体脚边，尺寸不超过主体 1/3。
- 允许「拟人化物件」当主角：一张饼、一个包子、一只牛头、一颗心。

### 2.9 背景规则
- 默认零背景。
- 需要交代环境时，只用一个「符号级」元素：一条远山剪影、一根竹竿、一盏吊灯、一排天际线简笔。
- 不画天空渐变、不画云朵体积、不画地面透视。

### 2.10 平面与版式（奖励卡直接沿用）
- **A 簇骨架**：插画 55–60% 在上，文字块 25–30% 在下，底边留 8–12% 空。
- 文字块整体居中、左对齐，行数 2–7，行距紧（约 1.15 倍），字距松。
- 印章：右下角或题款末尾，尺寸约画面宽 6–8%，朱红，2–4 字，边缘斑驳。
- 姓名日期：左下角，字号为金句的 45–55%，灰墨。
- **B 簇骨架**：竖排题款贴左或贴右，占宽 18–25%，含一行大字 + 一行干支小字 + 印章。

### 2.11 情绪与叙事
- 温和、松弛、带一点俏皮或自嘲；不说教。
- 叙事靠「一个具体瞬间」：抬头看花、被人举石头、蹲在路边吃猪脚饭。
- 象征符号极省：花=期待，山=远方，猫=陪伴，饼=承诺。

### 2.12 后期与渲染
- 无 LUT、无色差、无辉光、无锐化。
- 允许极轻的纸纹叠加与边缘轻微污渍，模拟扫描件。
- 不做暗角。

### 2.13 负面特征（参考图中**不出现**的东西）
写实照片感、3D 渲染、赛璐璐厚涂、渐变背景、霓虹、金属高光、投影、贴纸白边、卡通描边加粗、满版花纹、艺术字渐变、二维码以外的任何码、署名与 logo、emoji、表情包字体。

### 2.14 稳定 / 可变分离

| 必保留（核心） | 可随主题替换 |
|---|---|
| 宣纸白底 + 大留白 | 主体身份（小孩／动物／拟人物） |
| 焦墨枯笔线 | 主体动作与道具 |
| 3–5 色淡彩 | 点缀色（绿／蓝／赭／粉） |
| 胭脂腮红 | 场景符号（山／竹／桌／灯） |
| 极简五官（无鼻） | 金句内容 |
| 手写行楷字块 | 版式（L1／L2／L3） |
| 朱红印章 | 印章文字（2–4 字） |
| 无背景 | 是否加伴生小动物 |

## 3. 权重表

### 核心特征（0.8–1.0）
1. 宣纸白底、大留白（0.95）
2. 焦墨枯笔线、断笔飞白（0.95）
3. 低饱和淡彩、色块不填满（0.9）
4. 胭脂腮红（0.9）
5. 极简五官、不画鼻子（0.85）
6. 手写毛笔行楷文字块（0.85）
7. 朱红印章（0.8）
8. 无背景场景（0.8）

### 推荐特征（0.4–0.7）
- 光头／三根毛（0.6）
- 宽袍大袖（0.6）
- 夸张大耳 + 小青耳环（0.55）
- 伴生小猫／小狗（0.5）
- 拟人化物件当主角（0.45）
- 一两个符号级道具（0.5）

### 可选特征（0.1–0.3）
- 竖排题款 + 干支纪年小字（0.3）
- 墨点飞溅（0.2）
- 淡影水痕（0.2）
- 双印章（0.15）

### 可变特征
主体类型、动作、道具、金句、奖励项目、姓名、日期、印章文字、点缀色、版式。

## 4. 生成时的硬提醒

1. 参考图里的**二维码、右下角署名、干支纪年**是原作的水印与年代标记，**一律不要复刻**。
2. 不要复刻任何一张参考图的具体构图与文案，只取规律。
3. 若主体是受保护角色／品牌，改成通用描述（「一只圆脸小牛」「一个戴斗笠的老人」）。
4. 风格相似度不够时，优先加「枯笔」「留白」「腮红」三个词，它们权重最高。
