# 「一图看懂天下事」视觉风格规范

## 一、整体风格定位

**国风历史信息图 / 知识科普长图**——融合中国传统水墨山水画意境与现代信息图设计，以"华史图谱"系列为品牌调性，将复杂知识压缩为一张结构清晰、视觉精美的竖版长图。

**适用题材**：中国历史事件、人物、制度、文化现象、地理路线、思想流派等一切可做知识梳理的主题。

---

## 二、画幅与比例

- **竖版长图**，比例约 **9:16**（宽度 1264px 级，高度按内容 1600–2800px 不等）
- 适合手机端阅读、社交媒体竖屏传播
- 内容密度：5–7 个编号模块 + 顶部标题区 + 底部总结区

---

## 三、色彩系统

| 用途 | 色值参考 | 说明 |
|------|----------|------|
| 背景底色 | 米黄/宣纸色 `#F5F0E1` ~ `#EDE6D3` | 做旧纸张质感，略带纹理 |
| 主标题 | 深墨黑 `#2B2B2B` + 朱红 `#C0392B` | "一图看懂"墨黑，主题名朱红，书法体 |
| 章节横幅 | 深墨绿 `#2D5A4A`、赭石棕 `#8B4513`、藏蓝 `#1E3A5F`、暗红 `#8B2500` | 编号模块标题栏，白字，圆角矩形 |
| 卡片强调色 | 朱红 `#C0392B`、赭黄 `#D4A017`、青绿 `#2D8B7E`、灰蓝 `#5B7B9A` | 不同类别卡片边框/标签 |
| 正文文字 | 深褐墨色 `#3A3A3A` | 清晰易读，不使用纯黑 |
| 装饰线条 | 淡墨灰 `#999` | 分割线、箭头、边框 |

**配色原则**：暖底 + 朱红主调 + 墨绿/藏蓝辅助，整体古朴典雅，不使用高饱和度现代亮色。

---

## 四、版式结构（从上到下）

### 1. 顶部标题区（约占高度 15–20%）

- **主标题**：超大书法字体，"一图看懂"四字 + 主题名（朱红色更大字）
- **副标题**：一行小字概括，如"上古传说时代的人物体系、常见版本与文明主线"
- **标签胶囊**：3 个关键词，竖线分隔，放在棕色圆角条内，如"贸易之路｜文化之路｜宗教传播之路"
- **右上角印章**：红色方形篆体印章，白字"华史图谱"（竖排两列）
- **左上角/两侧竖排小字**：如"以图见史｜以史明智"、"读历史看中国"
- **背景装饰**：淡墨山水远景（远山、云雾、旭日），两侧点缀古建筑/人物剪影

### 2. 正文编号模块（约占高度 60–70%）

每个模块结构：
- **模块标题栏**：深色圆角横幅，左侧白色圆形数字编号（①②③…），右侧白色粗体问题式标题
- **模块内容**：根据内容性质选择以下版式之一或组合

#### 常用版式类型

| 版式 | 适用场景 | 视觉特征 |
|------|----------|----------|
| **横向时间线** | 制度演变、朝代发展、事件经过 | 多个等宽卡片横排，卡片间用红色箭头连接，每卡含朝代/年份+要点+小插画 |
| **人物/卡片矩阵** | 人物介绍、学派列举、并列概念 | 彩色边框卡片矩阵，每卡有标题、关键词标签、要点列表、底部标签条 |
| **流程图/因果链** | 原因分析、发展过程、逻辑推导 | 圆形/方形节点 + 箭头串联，节点下方配小字解释 |
| **思维导图/放射图** | 中心概念、分类关系 | 中心圆形主题 + 向外辐射的彩色分支卡片 |
| **路线地图** | 地理路线、行军路线、贸易路线 | 水墨风格地图底图 + 彩色虚线/实线标注路线 + 节点城市标注 |
| **对比双栏** | 异同比较、前后对比 | 左右两栏卡片，中间箭头或"VS"标识 |
| **纵向树状图** | 谱系、分支传承、层级关系 | 顶部根节点 + 向下分支，每支有名称和说明 |

### 3. 底部总结区（约占高度 10–15%）

- **"一张图记住XXX"**：深绿/红色横幅标题，下方用流程箭头串联核心记忆点（如：制度演变 → 考试流程 → 殿试前三）
- **口诀/金句**：底部居中一行红色/棕色大字口诀，如"秀才过乡试成举人，举人过会试成贡士，贡士过殿试定进士"
- **"XXX看什么？"**：右侧小字编号列表，5 条阅读指引
- **页脚**：最底部居中一行小字，如"以史为鉴｜知古鉴今｜华史图谱｜让历史更清晰"

---

## 五、装饰与插画元素

- **山水背景**：淡墨远山、松树、云雾，透明度 20–30%，作为底纹不干扰正文
- **建筑插画**：城楼、宫殿、文庙、钟楼等线描风格小图，点缀在标题区和模块旁
- **器物插画**：竹简、青铜器、书卷、笔架、古地图等，与内容主题对应
- **人物剪影**：车马、骆驼队、古人骑乘等水墨剪影，增加画面故事感
- **祥云纹样**：淡灰色云纹装饰在连接线旁
- **红色印章**：除右上角主印章外，模块角落可加小型红色印章点缀

---

## 六、文字内容规范

### 标题
- 主标题格式："一图看懂 + 主题名"
- 副标题：一句话概括本图核心内容（15–25字）
- 模块标题：问题句式，如"XXX是什么？""XXX为什么会出现？""XXX主要有哪些？"

### 正文
- 每条要点控制在 8–15 字，用圆点项目符号
- 关键词用竖线分隔："仁｜礼｜德治｜民本"
- 避免长段落，信息高度提炼

### 注释
- 涉及有争议的话题，加小字说明："本图采用常见说法，不同古籍版本略有差异"
- 底部页脚统一放此类免责声明

---

## 七、内容叙事框架（认知路径）

每张图按以下逻辑递进，根据主题选择 5–7 个模块：

1. **是什么**（定义/概述）——这个概念/事件/人物是什么
2. **为什么**（背景/原因）——它为什么会出现/发生
3. **核心内容**（主体展开）——关键构成要素、主要人物、主要派别、发展阶段
4. **关系/对比**（结构梳理）——各要素之间的关系、异同、传承脉络
5. **影响/意义**（价值判断）——它带来了什么改变、留下了什么
6. **总结记忆**（一张图记住）——浓缩为口诀/流程图
7. **阅读指引**（看什么）——告诉读者从哪些角度理解

## 八、图片生成 Prompt 模板结构

生成图片时，prompt 需包含以下要素（按顺序）：

```
一张竖版国风历史科普信息图，宣纸米黄色背景，中国传统水墨山水画风格。

顶部：超大书法字体主标题"一图看懂[主题]"，其中"一图看懂"为墨黑色，主题名为朱红色大字。副标题一行概括。右上角红色方形印章"华史图谱"。背景有淡墨远山、云雾、古建筑剪影。

正文分为[数量]个编号模块：
[逐个描述每个模块的标题、布局类型、核心内容要点、配色和插画元素]

底部："一张图记住[主题]"总结区，流程箭头串联核心记忆点，底部一行金句口诀。

整体配色：米黄底 + 朱红 + 墨绿 + 藏蓝 + 赭石，古朴典雅，信息层级清晰，适合手机竖屏阅读。
```

**关键要求**：
- 所有图中出现的文字必须清晰可读，使用中文
- 模块之间有明确的视觉分隔
- 插画为水墨/线描风格，与整体色调统一
- 信息密度适中，不拥挤也不空旷
