# 一图看懂天下事

根据用户主题，联网搜集资料 → 提炼为 5–7 个知识模块 → 生成国风历史信息图。

## 工作流程

### 第 1 步：明确主题与范围

- 用户给出主题后，确认图的核心叙事线。主题可能是：人物、事件、制度、朝代、思想流派、地理路线、文化概念等。
- 若用户只给了宽泛主题（如"唐朝"），自行选取一个有足够信息密度的切入角度（如"一图看懂唐朝科举"），并在生成前简短说明。

### 第 2 步：联网搜集资料

使用 `general_search` 围绕主题检索，建议拆 2–3 组关键词并行搜索：

1. **基础事实**：`"[主题] 是什么 简介"` —— 获取定义、时间、核心人物/事件
2. **展开细节**：`"[主题] 发展历程 关键节点 代表人物"` —— 获取过程、阶段、要点
3. **对比/影响**：`"[主题] 历史意义 影响 评价 争议"` —— 获取因果关系和评价

要求：
- 事实性内容（年份、人名、事件名、制度名称）必须来自搜索结果，不可臆造
- 有争议的说法，采用最通行版本，并在图中加小字注释"本图采用常见说法"
- 搜集完成后，将内容整理为下方「内容框架」所需的模块

### 第 3 步：按内容框架组织素材

从以下模块中选取 5–7 个最契合主题的模块（不必全用），每个模块提炼 3–5 条要点：

| 模块序号 | 模块标题句式 | 内容要点 | 推荐版式 |
|----------|-------------|----------|----------|
| ① | [主题]是什么？ | 定义、时间范围、核心关键词 | 左文右卡片 |
| ② | [主题]为什么会出现？ | 背景、原因链、推动因素 | 因果流程图 |
| ③ | [主题]核心内容/主要构成？ | 主要人物/派别/阶段/路线 | 卡片矩阵/时间线/地图 |
| ④ | [各要素之间是什么关系？] | 对比、传承、分支、异同 | 对比双栏/树状图/放射图 |
| ⑤ | [主题]意味着什么/影响了什么？ | 历史意义、长远影响、后果 | 纵向流程图 |
| ⑥ | 一张图记住[主题] | 浓缩为 2–3 行流程箭头 + 一句口诀 | 总结横幅 |
| ⑦ | "[主题]"看什么？ | 3–5 条阅读视角引导 | 编号列表 |

**选模块原则**：
- 人物类主题 → ①是什么 ②为什么出现 ③是谁 ④靠什么成/做了什么 ⑤意味着什么 ⑥总结 ⑦看什么
- 制度类主题 → ①是什么 ②怎么发展的（时间线）③流程是什么 ④功名/层级如何分 ⑤考什么/内容 ⑥改变了什么 ⑦为什么退出 ⑧总结
- 路线/地理类 → ①是什么 ②怎么形成的 ③路线怎么走（地图）④交换了什么 ⑤意义 ⑥补充路线 ⑦总结
- 思想/学派类 → ①是什么 ②为什么出现 ③有哪些派别（放射图）④在争什么 ⑤留下了什么 ⑥总结 ⑦看什么
- 战争/事件类 → ①时间线（每次行动）②总图（地图）③打到哪里 ④结果 ⑤为何成败 ⑥总结

### 第 4 步：撰写图片生成 Prompt

读取 [references/style-guide.md](references/style-guide.md) 获取完整视觉规范，然后按以下结构撰写 prompt：

```
一张竖版国风历史科普信息图，宣纸米黄色做旧背景，中国传统水墨山水画风格，长宽比约9:16。

【顶部标题区】
- 超大书法字体主标题："一图看懂[主题名]"，"一图看懂"为墨黑色，主题名为朱红色大字
- 副标题：[一句话概括，15-25字]
- 棕色圆角标签条：[3个关键词用竖线分隔]
- 右上角红色方形篆体印章，白字"华史图谱"
- 背景装饰：淡墨远山、云雾、[与主题相关的建筑/人物剪影]

【正文模块】（逐个描述）
模块1（深墨绿横幅标题栏，白色编号①和标题）：
- 版式：[时间线/卡片矩阵/流程图/放射图/地图/对比双栏]
- 内容：[用自然语言描述每个卡片/节点的标题、要点、颜色标签]
- 插画：[描述与内容配套的水墨小插画]

模块2（藏蓝/赭石/暗红横幅）：
...

【底部总结区】
- 深绿色横幅"一张图记住[主题]"
- 流程箭头串联：[核心记忆点A → 核心记忆点B → 核心记忆点C]
- 底部居中红色大字口诀：[一句好记的总结语]
- 页脚小字："以史为鉴｜知古鉴今｜华史图谱｜让历史更清晰"

【整体要求】
- 配色：米黄底 + 朱红 + 墨绿 + 藏蓝 + 赭石，古朴典雅
- 所有中文文字清晰可读，信息层级分明
- 模块间有明确视觉分隔，适当留白
- 插画为水墨/线描风格，色调统一
```

**重要**：
- Prompt 中所有图中需要出现的文字（标题、卡片文字、标签）必须用中文引号明确写出
- 不要在 prompt 中写"按照参考图风格"之类的模糊表述，要把视觉特征直接描述出来
- 每个模块的内容要具体到卡片标题和要点，不能只写"展示XX的内容"

### 第 5 步：生成图片

使用 `image_gen` 工具生成：
- `model_version`: `seedream_5.0_pro`（用户偏好优先使用 Pro 模型）
- `width`: 1264（或根据比例调整）
- `height`: 根据内容模块数量估算，通常 1800–2800（竖版 9:16 或 2:3 比例）
- `prompt`: 上一步撰写的完整 prompt

**尺寸参考**：
- 5 个模块：约 1600×2400
- 6 个模块：约 1600×2700
- 7 个模块：约 1600×3000

### 第 6 步：检查与交付

- 生成后查看图片，确认：标题正确、模块完整、文字无乱码/错字、风格统一
- 若文字出现明显乱码或关键内容缺失，调整 prompt 重新生成（最多重试 1 次）
- 将生成的图片通过 `present_files` 交付给用户

## 注意事项

- **事实准确性**：年份、人名、地名、制度名等硬事实必须基于搜索结果，不可编造
- **内容克制**：每个模块 3–5 条要点即可，不要堆砌过长文字
- **风格统一**：所有装饰元素必须是中国传统水墨风格，不混入现代扁平插画
- **竖版构图**：始终保持竖版长图比例，适合手机阅读
