# 知识梳理和海报生成

## 核心能力

接收用户的任意文字信息，先做知识理解与结构化拆解，再生成一组**手绘蜡笔/彩铅风格**的竖版知识海报，将抽象文本转化为可视化、易传播的干货长图。

## 风格规范（必须严格遵循）

### 1. 整体视觉风格
- **手绘蜡笔/彩铅质感**：所有文字、图形、背景均呈现蜡笔涂抹、彩铅手绘的颗粒质感，非光滑矢量风
- **米白/奶油色底色**：背景为浅米白色，带有不规则蜡笔涂抹的彩色色块（黄、蓝、绿、粉、紫）
- **童趣活泼感**：整体氛围轻松、温暖、有亲和力，类似手账/黑板报手绘风
- **9:16竖版比例**：所有图片统一竖版，适合手机阅读和社交媒体传播

### 2. 字体规范
- **主标题**：大号粗体，手写蜡笔感，带白色描边/外发光阴影，颜色为橙色+深蓝色组合
- **编号**：蓝色圆角方块内白色粗体数字，左上角带黄色放射光线装饰
- **正文**：清晰易读的无衬线字体，黑色或深灰色
- **关键词高亮**：核心词汇用橙色、蓝色、绿色等彩色加粗，部分带下划线（黄色波浪线）
- **提示词区域**：绿色圆角框内，带灯泡/手指图标前缀

### 3. 配色方案
| 用途 | 颜色 |
|------|------|
| 背景底色 | 米白 #FFF8E7 / 奶油色 |
| 主标题色 | 橙色 #FF6B35 + 深蓝 #1A3A5C |
| 编号底色 | 蓝色 #2B7DE9，白字 |
| 强调色1 | 橙色 #FF6B35 |
| 强调色2 | 绿色 #4CAF50 |
| 强调色3 | 蓝色 #2196F3 |
| 强调色4 | 粉色 #E91E63 |
| 强调色5 | 紫色 #9C27B0 |
| 装饰色块 | 黄、蓝、绿、粉、紫的蜡笔半透明涂抹 |
| 正文文字 | 深灰/近黑 #2C2C2C |

### 4. 配图元素
- **卡通人物**：手绘风格的女生形象（棕色短发、绿色上衣）作为叙事主角，表情丰富（困惑→开心）
- **机器人助手**：白色圆润机器人，蓝色耳机/装饰，笑脸屏幕，作为"智能助手"符号
- **简笔图标**：星星（黄色四角星）、灯泡（创意）、箭头（蓝色粗箭头，引导流程）、对话框（圆角气泡）、对勾、爱心
- **手绘图表**：柱状图、折线图、饼图、对比表格，均为蜡笔手绘风
- **装饰元素**：闪光点点、波浪线、放射光线、便签纸、剪贴板、铅笔图标
- **避免**：真实照片、3D渲染、赛博朋克、极简商务风

### 5. 页面结构（单张内容页标准布局）
```
┌─────────────────────────────┐
│ [蓝色编号方块] 大标题（橙+深蓝） │  ← 顶部标题区，黄色波浪下划线
├─────────────────────────────┤
│  痛点/场景描述   →   解决方案   │  ← 左右对比区，蓝色箭头连接
│  (困惑人物插图)     (机器人/成果)│
├─────────────────────────────┤
│ 💡 参考提示词/核心方法（绿色框） │  ← 方法/提示区
├─────────────────────────────┤
│     效果展示 / 流程图 / 表格     │  ← 可视化展示区
├─────────────────────────────┤
│ ⭐ 总结金句（黄色星星+彩色文字）  │  ← 底部金句区
└─────────────────────────────┘
```

### 6. 封面页结构（系列第一张）
- 居中大标题，蜡笔手写体，白色描边
- 背景为大面积彩色蜡笔涂抹色块（黄、蓝、绿、粉、紫交织）
- 散落星星、闪光装饰
- 可包含数字（如"8个要点""3步法"），数字用橙色超大号

## 工作流程

### 第一步：文本理解与知识拆解
1. 通读用户提供的全部文字
2. 提炼核心主题和关键信息
3. 拆分为 **3~8个** 独立知识要点（根据内容量灵活决定）
4. 每个要点对应一张海报，为每张海报拟定：
   - 标题（简洁有力，可含数字）
   - 核心观点/方法
   - 示例或提示词
   - 总结金句

### 第二步：规划图片序列
- 第1张：**封面页**（主题大标题+装饰性背景）
- 第2~N张：**内容页**（每个知识要点一张，按上述标准布局）
- 如内容较少（仅1-2个要点），可省略封面页直接做内容页

### 第三步：生成图片
- 使用 `image_gen` 工具，`model_version` 必须为 `seedream_5.0_pro`
- 尺寸：`width=1152, height=2048`（9:16竖版）
- 每张图独立生成，prompt中必须包含完整的风格描述和该页的具体内容
- 生成后逐张检查：风格是否统一、文字是否清晰、布局是否合理

### 第四步：交付
- 按顺序通过 `present_files` 逐张交付图片
- 简要说明每张图对应的知识要点

## 注意事项

1. **文字内容必须来自用户提供的文本**，不得编造用户未提及的事实或数据
2. 如用户文本信息不足，可基于常识补充合理的示例和解释，但需与主题相关
3. 每张海报的文字量要适中，避免过密导致AI生成乱码；核心信息优先，次要信息可简化
4. 系列图必须保持风格统一：相同的配色、字体感、人物形象、布局逻辑
5. 如用户指定了图片数量，按用户要求执行；未指定时根据内容量自主决定3~8张
6. 优先保证标题和关键词的清晰可读，正文小字可适当简化
7. 生成的图片中如出现明显乱码或布局问题，应重新生成该张
