# 水彩周报

把给定文本变成一张手绘水彩风格的信息图周报。

## 工作流

### 1. 读取并理解输入文本

- 用户直接粘贴文本：直接分析。
- 用户上传文件（.docx/.txt/.pdf/.md）：先读取全文，再分析。
- 若文本过长，优先提取：标题、时间范围、核心数据、工作板块、成效、问题、计划。

### 2. 提取信息图要素

从文本中提炼以下内容（缺失项用合理概括或省略，不要编造具体数字）：

| 模块 | 提取内容 |
|------|---------|
| 标题 | 单位+事项+周期，如"XX小学2026年上半年电教工作总结" |
| 日期范围 | 文本中的时间跨度 |
| 3个核心数据 | 总量、覆盖数、达成率/零事故类，各配一个图标 |
| 路线图站点 | 4—8个主要工作板块/阶段，按逻辑排序，每个配图标 |
| 彩旗标注 | 2—3个文本中的关键特点/趋势 |
| 节奏柱状图 | 按时间周期的分布，标注峰值和最忙时段 |
| 主要成效 | 3—5条 |
| 存在问题 | 3—5条 |
| 下一步打算 | 3—5条 |

### 3. 构建生图 Prompt

读取 [references/style-guide.md](references/style-guide.md) 中的「Prompt 构建模板」，将提取的要素填入占位符，生成完整 prompt。

风格关键词必须包含：**手绘水彩、蜡笔质感、米黄纸张纹理底、中文手写体、童趣温暖、非扁平设计**。

### 4. 生成图片

调用 `image_gen`：
- `model_version`: `seedream_5.0_pro`
- `width`: 1152，`height`: 2048（9:16 竖版）
- `prompt`: 上一步构建的完整 prompt

### 5. 交付

用 `present_files` 交付生成的图片，附简短说明（标题、数据来源、可调整项）。

## 风格参考

参考样图见 [assets/style-reference.png](assets/style-reference.png)。完整风格规范、配色、布局、映射规则、Prompt模板和质检清单见 [references/style-guide.md](references/style-guide.md)。

## 注意事项

- 不要编造文本中不存在的具体数字；无数据时用文字描述代替数字。
- 若首次生成风格偏离（如变成扁平矢量/纯白底），在 prompt 中追加强调手绘水彩质感后重试，最多重试2次。
- 文本内容涉密或敏感时，先提示用户确认再生成。
