# 水彩周报 · 风格与 Prompt 规范

## 一、视觉风格定义

- **画种**：手绘水彩 + 蜡笔/彩铅质感，儿童插画感
- **底色**：米黄色粗糙纸张纹理（warm cream / #F5EFE0 系），非纯白
- **线条**：手绘抖动线条，非机械直线
- **字体感**：中文手写体，标题粗黑手写，正文圆润手写
- **吉祥物**：右上角配一个卡通小角色（机器人/动物/文具拟人），戴眼镜或持教鞭，微笑挥手
- **装饰元素**：四周散落堆叠书本、绿色盆栽、铅笔、小星星、爱心、咖啡杯、小太阳、回形针、胶带贴纸
- **整体气质**：温暖、治愈、童趣、不严肃

## 二、配色方案（低饱和水彩）

| 用途 | 色感 |
|------|------|
| 标题/强调 | 墨黑 + 红色下划线 |
| 数据指标1 | 暖红（对话气泡） |
| 数据指标2 | 蓝色（电脑/文档） |
| 数据指标3 | 绿色（人群/盾牌） |
| 路线图站点 | 红→蓝→绿→橙→黄→紫 循环 |
| 柱状图 | 多彩圆柱，每根不同色 |
| 底部三栏标题 | 红/橙/绿 横幅 |
| 点缀 | 黄、粉、青 |

原则：色彩明快但不刺眼，水彩透明感，可叠色。

## 三、标准布局（自上而下五段式）

```
┌─────────────────────────────────┐
│ ① 标题区：大标题 + 黄色丝带日期横幅 + 吉祥物 │
├─────────────────────────────────┤
│ ② 三栏核心数据：图标 + 大数字 + 标签     │
├─────────────────────────────────┤
│ ③ 成长路线图：蜿蜒小路 + N个站点(编号+图标+名称) │
│    路旁插小彩旗标注关键特点/节点           │
├─────────────────────────────────┤
│ ④ 节奏柱状图：N根彩色圆柱 + 峰值标注 + 云朵说明 │
├─────────────────────────────────┤
│ ⑤ 底部三栏：成效✓ / 问题! / 计划→        │
└─────────────────────────────────┘
```

## 四、文本→信息图映射规则

从输入文本中提取以下要素，填入对应模块：

1. **标题**：取文档主标题或单位+事项+周期
2. **日期横幅**：取时间范围（如"2026年1月—6月"）
3. **三栏核心数据**：从文本中提炼3个最有冲击力的量化指标
   - 优先选：总量、覆盖数、零事故/达成率类
   - 每个配一个手绘图标（对话气泡/电脑/盾牌/奖杯/人群等）
4. **路线图站点**：取文本中的主要工作板块/阶段（4—8个），按逻辑顺序排列
   - 每个站点：圆形编号 + 手绘小图标 + 简短名称（≤12字）
   - 路旁彩旗：提炼2—3个文本中的关键特点/趋势
5. **节奏柱状图**：按时间周期（月/周/日）画柱子，标注峰值和最忙时段
   - 若文本无明细数据，用相对高低示意并配文字说明
6. **底部三栏**：
   - 左栏「主要成效」：从成效/成果段提取，每条前打✓
   - 中栏「存在问题」：从问题/不足段提取，每条前带!
   - 右栏「下一步打算」：从计划/打算段提取，每条前带→

## 五、Prompt 构建模板

生成图片时，将以下模板中的 `{{占位}}` 替换为从文本提取的实际内容，然后调用 `image_gen`。

```
一张竖版手绘水彩蜡笔风格的信息图周报，米黄色粗糙纸张纹理背景，整体童趣温暖，儿童手绘插画质感。

顶部区域：黑色手写粗体大标题《{{标题}}》，标题下方黄色丝带横幅写着"{{日期范围}}"，右上角一只戴眼镜的卡通{{吉祥物}}挥手微笑，旁边有红色爱心和星星装饰。

第二行三栏核心数据，每栏配手绘图标：{{指标1图标}}图标+大字"{{指标1数值}}"（{{指标1说明}}），{{指标2图标}}图标+大字"{{指标2数值}}"（{{指标2说明}}），{{指标3图标}}图标+大字"{{指标3数值}}"（{{指标3说明}}）。

中部标题"成长路线图式工作周记"，一条蜿蜒的彩色小路从左下延伸到右上，路上{{站点数}}个站点依次排列，每个站点有圆形编号和手绘小图标：{{逐个列出站点：编号+名称+图标}}。小路旁插{{彩旗数}}面小彩旗分别写着"{{彩旗文字1}}""{{彩旗文字2}}""{{彩旗文字3}}"。

中下部"工作节奏"区域：{{柱数}}根彩色手绘圆柱代表{{时间单位}}，{{峰值描述}}，旁边云朵对话框写着"{{最忙时段说明}}"。

底部三栏并排，每栏有彩色标题横幅：
左栏红色横幅"主要成效"，内容：{{成效列表，每条前打勾}}；
中栏橙色横幅"存在问题"，内容：{{问题列表，每条前带感叹号}}；
右栏绿色横幅"下一步打算"，内容：{{计划列表，每条前带箭头}}。

画面四周散落手绘装饰元素：堆叠的书本、绿色盆栽植物、铅笔、小星星、爱心、咖啡杯、小太阳、回形针，低饱和度水彩配色（红、蓝、绿、橙、黄），所有文字为中文手写体，整体风格统一为温暖治愈的儿童手绘信息图。
```

## 六、生图参数

- **模型**：`seedream_5.0_pro`
- **比例**：9:16 竖版（width=1152, height=2048）
- **工具**：`image_gen`
- **数量**：单次1张

## 七、质量检查清单

生成后对照检查：
- [ ] 底色是米黄纸张纹，非纯白
- [ ] 标题有手写感且带日期丝带
- [ ] 三栏数据有图标+大数字
- [ ] 路线图蜿蜒且站点编号清晰
- [ ] 柱状图存在且有峰值标注
- [ ] 底部三栏标题横幅颜色区分（红/橙/绿）
- [ ] 四周有手绘小装饰
- [ ] 整体水彩/蜡笔质感，非扁平矢量

若风格偏离明显，在 prompt 中追加强调"手绘水彩质感、蜡笔笔触、米黄纸张底、非扁平设计"后重试。
