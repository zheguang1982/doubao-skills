# 真人照片 / 复杂背景抠图管线

`prepare_sprites.py` 的四角泛洪只适用于**白底扁平素材**（图标、插画、水果）。真人生活照背景是夜景、车内、泳池、街道时，泛洪完全无效，走本管线。

## 环境

```bash
pip3 install rembg onnxruntime      # Pillow/numpy 一般已有，无 cv2/mediapipe 也能跑
```

首次 `new_session("u2net_human_seg")` 会自动下载模型（约 176MB）到 `~/.rembg/models/`，之后离线可用。单张约 1–2 秒。**用 `u2net_human_seg` 而不是通用 u2net**，人像边缘（发丝、肩线）明显更准。

## 标准管线（每张依次执行）

1. **合集先切图**：2×5 这类拼贴合集，先检测白色间隙行列，按列块/行块精确切成单张；注意排除底部编号条。不要均分，拼图内边距常常不均匀。
2. **粗裁 PREFRAME（按需）**：画面里有旁人、座椅、头枕等干扰时，先按内容 crop 掉。坐标逐张看图决定，**禁止套用别的图的坐标**，换图必须重新 Read。
3. **rembg 分割**：`remove(png_bytes, session=sess)` 得 RGBA。
4. **alpha 阈值拉伸**：`alpha = clip((a-16)*255/(240-16),0,255)`，压掉半透明灰雾。
5. **连通域过滤**：只保留面积 ≥ 最大连通域 8% 的块，去掉与主体断开的背景残留（座椅、头枕、旁人身体）。注意：抱着的物体（如狗）与人体相连会被保留，属正常。
6. **内缩 + 羽化**：`MinFilter(3)` 内缩 1px 吃掉背景镶边，再 `GaussianBlur(0.6)` 柔化边缘。
7. **方裁（关键，分两种构图）**：
   - **脸部大特写**（bbox 基本贴满画面、头顶和下巴都靠边）：按 **bbox 几何中心**方裁（bias 0.5），用偏上的头肩 bias 会把下巴切掉。
   - **窄长全身/半身照**（高 > 1.3 宽）：side = 宽×1.28，中心取 y0+0.24×高，聚焦头肩——否则缩到 80px 后人脸只剩几个像素。
   - 越界区域用透明填充，不许缩小主体来迁就画布。
8. **椭圆遮罩修边角（按需）**：发际线和暗背景粘连、四角残留抠不净时，在**方裁之后**叠加头部椭圆遮罩，椭圆外清零、边缘羽化；脸在画面里偏一侧时椭圆中心要同向偏移（如 cx=0.44W），半径按残留位置收放。顺序必须是「先方裁、后遮罩」，遮罩才和最终正方形对齐。
9. 输出透明方形源图，再交给 `prepare_sprites.py --no-bg-removal` 做 10 级尺寸适配。

## 验收

- 每张做**棋盘格背景预览**并实际 Read 查看，重点看四角、发际线、下颌、肩膀外缘。
- 量化指标：主体覆盖率（alpha>128 的占比）参考 0.28–0.80；特写偏高、全身照偏低；>0.9 往往是背景没抠掉，<0.2 主体会太小。
- 最终游戏尺寸下（最小 80×80）残留若不可见可接受，但用户明确指出不干净时必须按第 8 步修到干净。
- 换单张后：重生成该级 sprite → 多维表格先删旧附件再传新的（append 语义）→ 重建游戏 → 浏览器核对该级渲染。

## 已验证的坑

- 环境没有 cv2/mediapipe 不影响，Pillow + numpy + rembg 足够；连通域用 numpy 手写 BFS/并查集即可。
- 分割模型对「皮肤 vs 暖橙色物体」容易粘连（橙色救生衣、座椅），优先用 PREFRAME 粗裁而不是事后修 alpha。
- 眼镜镜片、白发、白衣服是半透明/浅色但属于主体，阈值拉伸别超过 lo=16/hi=240，避免镂穿。
