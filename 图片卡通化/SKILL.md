# 图片卡通化风格转换

## 风格定义（基于参考样例提炼）

### 线条
- 清晰、均匀的黑色/深棕色轮廓描边，粗细适中
- 内部细节（衣物褶皱、头发丝）用更细的线条
- 线条干净利落，不使用素描排线或手绘抖动效果

### 人物处理
- 卡通化但保留辨识度：眼镜、发型、体型、服装款式均严格还原原图
- 眼睛适度放大并简化，黑色/深棕色瞳孔，带白色高光点
- 鼻子简化为小点或短线，嘴巴简化为弧线
- 表情自然友好，多为微笑，不夸张变形
- 肤色：暖粉橘基调，脸颊带淡淡红晕
- 头发：保留原图发色，增加明快的高光块面
- 多人合影时，每个人的面部特征要区分开，避免千人一面

### 上色方式
- 赛璐璐平涂为主，皮肤、头发、衣物褶皱处加柔和渐变
- 阴影边缘清晰但不锐利，阴影色偏冷（紫灰/蓝灰调）
- 高光明快，眼睛、头发、金属/玻璃物品有明显高光点
- 不使用厚涂或油画质感

### 背景处理
- 保留原图场景的空间结构、透视关系和主要物品
- 简化冗余细节，用色块概括
- 背景饱和度和对比度略低于人物，突出主体
- 背景中的文字（活动背景板、标识等）尽量保留内容，可适当简化笔画

### 整体色调
- 高明度、中高饱和度，画面干净通透
- 室内场景偏暖：米黄、浅棕、木色为主
- 室外/活动场景保留原场景色调倾向但统一提亮
- 夜景：深蓝/深紫天空 + 暖黄灯光的冷暖对比
- 整体不发灰、不暗沉

## 标准转换 Prompt

每次调用 image_edit 时使用以下 prompt（可根据图片具体场景微调最后一句）：

```
将这张真实照片转换为日系现代动漫插画风格。严格保持原图的人物数量、构图、姿势、表情、服装和场景完全不变，不添加或删除任何主要人物和物品。应用以下风格特征：清晰均匀的黑色轮廓描边，赛璐璐平涂加柔和渐变上色，人物卡通化但保留辨识度（眼镜、发型、体型、服装款式均还原原图），眼睛适度放大带白色高光，鼻子简化为小点，嘴巴简化为弧线，暖粉橘肤色带脸颊红晕，头发保留原色并增加明快高光块面，阴影偏冷紫灰色且边缘清晰，背景保留空间结构和透视但简化细节用色块概括，整体高明度中高饱和度干净通透。人物面部特征要区分开，避免千人一面。
```

## 工作流

1. **接收照片**：确认用户上传的真实照片本地路径。若用户一次上传多张，逐张处理。
2. **上传获取 URL**：通过 FileBatchUpload 上传用户照片，获取可访问的 URL。
3. **调用 image_edit**：
   - `model_version`：使用 `seedream_5.0_pro`
   - `image_reference_url_list`：必须传入用户照片的 URL（核心参考图）
   - `prompt`：使用上方"标准转换 Prompt"
   - `height` / `width`：按原图比例设置，**保持原图比例不变**，不强制改为 9:16 或其他比例
4. **交付结果**：通过 present_files 将生成的卡通图交付给用户。

## 多图批量处理

- 用户上传多张照片时，逐张独立调用 image_edit，每张保持各自原图比例
- 不要将多张照片合并为一张
- 生成完成后统一交付，可按原图顺序命名

## 风格参考图

`assets/` 目录下存放了 3 张风格参考样例：
- `style_ref_group_photo.jpg` — 多人活动合影场景
- `style_ref_office.jpg` — 室内办公协作场景
- `style_ref_casual.jpg` — 三人休闲合影暖色调场景

如需增强风格一致性，可将对应场景的参考图一并传入 `image_reference_url_list`（用户原图在前，参考图在后），但用户原图必须始终包含在内。

## 注意事项

- 必须以用户上传的原图为核心参考图，不可脱离原图凭空生成
- 保持原图比例，不要裁剪、拉伸或改变画幅
- 人物的位置、朝向、动作必须与原图一致
- 原图中的文字、Logo 等标识尽量保留，不可随意替换
- 若原图分辨率较低，生成时可适当放大但保持比例
