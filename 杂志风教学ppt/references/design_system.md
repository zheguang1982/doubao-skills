# 杂志风教学PPT - 视觉设计系统

## 配色方案

| 用途 | 颜色名 | RGB值 | 示例场景 |
|------|--------|-------|---------|
| 页面背景 | 米黄 | rgb(255, 248, 240) | 所有页面默认背景 |
| 主色 | 桂花黄 | rgb(245, 215, 110) | 栏目标签、标题装饰、重点节点 |
| 辅色1 | 暖粉橘 | rgb(240, 168, 138) | 次要标签、对话气泡边框、强调文字 |
| 辅色2 | 薄荷绿 | rgb(168, 216, 185) | 赏析区、正确答案、积极元素 |
| 辅色3 | 淡紫 | rgb(201, 182, 228) | 拓展区、第三分支、装饰 |
| 文字主色 | 深棕 | rgb(107, 68, 35) | 标题、正文 |
| 文字辅色 | 浅棕 | rgb(140, 110, 80) | 说明文字、次要信息 |
| 页码色 | 灰棕 | rgb(180, 150, 120) | 页码、装饰线 |

半透明背景常用：`rgba(245, 215, 110, 0.2)` ~ `0.35`，营造杂志贴纸感。

## 杂志元素规范

### 栏目标签
- 尺寸：120×30，圆角15
- 位置：左上角 (40, 24)
- 文字：12-13px，bold，居中
- 颜色：各栏目对应主色填充，白色或深色文字

### 年级单元标签（仅封面）
- 尺寸：180×30，圆角15
- 位置：左上角 (40, 24)
- 文字：12-13px，bold，居中
- 内容格式："语文五年级上册 · 第一单元"（年级册别+单元）
- 颜色：主色填充，深色文字

### 页码
- 位置：右下角 (880, 494-500)
- 尺寸：60×24
- 文字：14px bold，右对齐
- 颜色：rgb(180, 150, 120)

### 对话气泡
- 圆角矩形，圆角16-20
- 白色填充 + 彩色边框(2-3px)
- 内部文字：16-18px bold，居中
- 用于引用课文原句、人物语言

### 动作链圆点
- 圆形节点：44-70px直径
- 节点间用 → 箭头连接（文字形状，24-32px）
- 每个节点内2行文字（动作名+说明）
- 颜色渐变：粉橘→黄→绿→紫

### 时间线
- 主轴：横向粗线(3-4px)，位于节点下方
- 节点：32px圆形，线上方
- 节点下方：标题(11px bold) + 说明(10px)
- 注意：线不要穿过节点圆圈，否则lint报错

### 思维导图
- 中心节点：椭圆形，170×80，主色填充
- 分支节点：圆角矩形，160×80，半透明填充+彩色边框
- 连接线：line元素，2-3px
- 分支文字：标题16px bold + 说明11px

## 典型页面版式模板

### 封面页
```
[年级单元标签：语文X年级X册 · 第X单元]
[大标题 72px bold]
[装饰线 120×6]
[副标题 22px]
[信息行 14px]
          [主视觉图 400×300 圆角]
[标语条 圆角矩形]
                              [页码]
```

### 段落赏析页（对比双栏）
```
[栏目标签]  [标题]  [段落标签]
[左栏：课文原文 圆角卡片]  [右栏：赏析 圆角卡片]
[底部：对比卡片或重点总结]
                              [页码]
```

### 场景页（图文+动作链）
```
[栏目标签]  [标题]  [段落标签]
[课文摘录卡片]          [场景插图 圆角]
[动作链：5个圆点+箭头]
[对话气泡：引用句]
[底部赏析区]
                              [页码]
```

### 练习页
```
[栏目标签]  [标题]
[选择题卡片：题号标签+题目+ABC选项]
  正确选项：绿色半透明填充+绿色边框+绿色文字
  错误选项：灰色半透明填充+灰色文字
[填空题卡片：题号标签+题目+答案]
                              [页码]
```

### 教学目标页（核心素养四宫格）
```
[栏目标签：学习目标]  [标题：本课核心素养]
[四宫格卡片 2×2 布局，每格 380×160 圆角]
  左上：文化自信 — 粉橘色标签 + 目标文字
  右上：语言运用 — 桂花黄色标签 + 目标文字
  左下：思维能力 — 薄荷绿色标签 + 目标文字
  右下：审美创造 — 淡紫色标签 + 目标文字
每格：维度名标签(圆角矩形 80×24) + 1-2句具体目标(14px)
                              [页码]
```
注意：禁止使用"知识与技能/过程与方法/情感态度价值观"三维目标框架，必须按学科核心素养维度呈现。其他学科替换为对应核心素养名称。

### 封底页
```
          [总结标签]
[大标题 40px bold]
[装饰线]
[核心收获卡片 圆角]
  - 内容理解
  - 写作手法
  - 字词积累
[下期预告条]
                              [页码]
```

## 插图生成Prompt模板

```
儿童水彩插画风格，[场景描述]，[人物动作/表情]，
背景是[环境描述]，[色调描述，如：暖色调/柔和明亮]，
水彩晕染质感，笔触柔和，[氛围词，如：治愈温馨/清新自然]，无文字
```

关键要素：
- 必须包含"儿童水彩插画风格"
- 必须以"无文字"结尾（避免生成图中出现文字）
- 人物描述要具体（发型、服装、动作、表情）
- 场景描述要具体（地点、物品、季节）
